## 三、剩余5个失败项分析

### 失败项 #5: 邀请码生成间歇性404

**现象**: 有时返回201，有时返回404

**可能原因**:
1. svc-homeos服务不稳定，偶尔崩溃或未启动
2. 路由注册问题（gin的参数化路由 `/:family_id/invites` 可能在某些情况下未匹配）

**排查步骤**:
```bash
# 检查服务是否运行
ps aux | grep svc-homeos

# 直接测试端点
curl -X POST http://localhost:8080/api/homeos/families/{family_id}/invites \
  -H "Authorization: Bearer {token}" \
  -d '{"role":"member"}'
```

### 失败项 #8: 成人成员加入家庭返回403

**现象**: 即使邀请码创建成功，接受邀请时返回403 Forbidden

**可能原因**:
1. 邀请码未正确保存到数据库
2. AcceptInvite handler中的权限检查逻辑有问题
3. 成人成员的token没有正确的session

**依赖关系**: 此测试依赖于#5的成功执行

### 失败项 #19: 成人成员越权删除未被拒绝

**现象**: 成人成员可以删除管理员创建的流水（期望403，实际200）

**根本原因**: DeleteTransaction handler中的权限检查代码存在，但可能：
1. 成人成员实际上已经加入了家庭并获得了有效token
2. 权限检查逻辑有bug（isAuthor/isOwner判断条件）
3. 流水的CreatedBy字段未正确设置

**代码位置**: `server/services/svc-finance/internal/handler/finance.go:405-413`

### 失败项 #21: L3私密流水未被过滤

**现象**: 成人成员可以看到其他成员标记为 `visibility="private"` 的流水

**根本原因**: ListTransactions handler中的L3过滤逻辑可能：
1. 未正确实现过滤循环
2. 成人成员的session role不是预期的"member"
3. 私密流水的visibility字段未正确保存

**代码位置**: `server/services/svc-finance/internal/handler/finance.go` ListTransactions方法

### 失败项 #24: 软删除流水到回收站HTTP 500

**现象**: DELETE请求带 `soft_delete=true` 参数时返回500错误

**可能原因**:
1. GORM软删除实现问题（之前修复过但未完全解决）
2. deleted_by字段更新与软删除事务冲突
3. 乐观锁版本号冲突

**代码位置**: `server/services/svc-finance/internal/repo/finance.go` SoftDeleteTransaction方法
