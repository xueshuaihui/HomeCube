05 十个全局态

十个态在全部面共用同一组件与同一文案库，业务面不得自造第四套降级文案。四个降级词各管一层：「未启用」= 本家庭没挂载；「即将上线」= 面还没出生；「暂不可用」= 面已启用但服务不可达；「依赖未就绪」= 本面可用、但该功能依赖的另一面没出生。

即将上线 / 未启用
只出现在开通页与深链落地，不出现在导航与首页。
hc-state-disabled
管理员多一个「去开通」引导
暂不可用
面已启用但服务不可达；显示最后一次值与「截至 HH:MM」。
hc-state-offline-service
重试只重发 home/summary，不清缓存
依赖未就绪
只作用在受影响的那个控件上，不禁用整面、不报错。
hc-state-dep-missing
说明要等到哪一期
无权限
不显示任何数据片段，只给「无权访问」与返回。
hc-state-denied
不出现「申请权限」之类假入口
空
给一个可点的引导动作，不写「暂无数据」了事。
hc-state-empty
引导动作必须可执行

06 使用规则

应该 只引用 var(--*)；金额符号在货币符号之前；数字用等宽；空态给可执行动作；同一个态在全部面用同一组件；亮暗只换令牌值。
不应该 页面里写死色值；为某个面自造一套降级文案；用 emoji 当图标；把「未启用 / 即将上线 / 暂不可用 / 依赖未就绪」混成一个态；页面级覆盖主题。
这份页面是原型的设计源：新增页面时先在这里确认有没有可复用组件；确实需要新组件时，先补进本页再落屏。
