怎么看 原型工具层不属于产品 UI

切换主题右上角「跟随系统 / 亮 / 暗」。暗色与亮色组件、文案完全一致，只换令牌值。
看交互每屏左上「交互标注」：图上出现 ①②③ 热区，右侧列出每个热区的触发与反馈。URL 加 ?annotate=1 可直接打开。
看异常左上「页面状态」下拉，或 URL 加 ?state=loading / empty / error 等直接落到该帧。
看说明每屏的屏卡写交互表、状态矩阵与文案校验；接口与数据契约另卷，暂不混写。
