**一屏说清**：待办列表是**日历面待办的唯一入口**（面内二级 Tab「待办」；导航路径：首页 C 区日历格 → 日历面 → 二级 Tab「待办」→ 本页），把「分配给我 / 我创建的 / 已归档」三段放在同一页切换。勾选**不直接改状态**——先弹「完成待办」确认层，确认后才发出完成回写；列表不承担编辑与新建以外的写操作。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 分段条 +「分配给我」列表：已逾期 / 今天 / 本周三个视觉分组，组内按截止升序；勾选框、截止、来源、头像齐备 |

## 字段与校验（页面级硬规则）

- **三段口径互斥**：分配给我 = 负责人为本人且未归档；我创建的 = 创建人为本人；已归档 = 已完成或已归档、本人可见。同一条不重复出现在两个未归档段里。
- **完成不直改**：勾选只打开确认层；确认后发出完成回写（`calendar.todo.completed`），未收到回执前不展示为「已归档」，回写失败进对账并回滚本地标记。
- **状态只进不退**：完成是单向的，列表不提供「取消完成」；误操作只能通过新建一条来修正（3.4.4 完成状态幂等）。
- **排序**：逾期在前，其次按截止时间升序，无截止的排最后；分组标题只是视觉分组，不改变排序口径。
- **来源标记唯一形态**：面名 + 面色令牌，取 registry；P1 只会是「日历」（17.4 表里 `finance.*` 四行注册的是 Reminder 与 CalendarEvent，不含 Todo），未出生面没有标记，也不许为它建待办。
- **子任务只读进度**：列表显示「子任务 x/y」，勾选在详情或完成确认后发生。
- **已归档只读**：归档段不显示勾选框，只显示完成时间与来源，不提供恢复与删除。

## 边界与不做

- 本页**不做**批量完成、批量归档、滑动删除；P1 待办没有删除，只有归档。
- 本页**不改**标题、负责人、截止：这些在详情与编辑页。
- 服务端裁掉的待办不返回、不占位，也不显示「无权限查看」。
- 不在这里拼「今日 N 项」等聚合数字：那是首页 B 区与到期中心的口径。
- 本分包不得出现第二处面入口或面切换器（⑫）；切面回首页点格，恒定 3 步。

## 待复核

- 空态时原型隐藏了分段条；实做建议保留分段，空态文案随段替换（三段共用一套空态组件）。
- 原型确认完成后把该条在本页标为「已完成」而非立即移出分段；实做应在收到回执后移出。
- 已归档段是否需要「恢复 / 删除」未在 PRD 定义，本版不做。
- 样例数据与首页 B 区「接女儿放学 16:30」保持同一条（两处都是日历面原生待办）；到期中心「交物业费 20:00」是 `finance` 账单经 17.4 注册的项，**不属本页对象**，两处不共用一条样例。
- 17.4 的 P1 财务注册行只有 Reminder 与 CalendarEvent，因此本页 P1 的来源标记不会出现「财务」；若日后财务需要注册待办，必须先给 17.4 加行，本页才允许出现该面色标记。
