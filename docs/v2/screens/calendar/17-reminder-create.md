# 17 · 新建提醒

| 项 | 值 |
|---|---|
| 路由 | `calendar/reminder/create` |
| 期 | ① |
| 权限 | 管理员与成人成员可新建自己的提醒；儿童可建自己的；访客入口不出现 |
| 原型 | [reminder-create.html](../../prototypes/reminder-create.html) |
| 状态帧 | [默认](../../prototypes/reminder-create.html) · [渠道降级](../../prototypes/reminder-create.html?state=fallback) · [标题为空](../../prototypes/reminder-create.html?state=error) · [保存中](../../prototypes/reminder-create.html?state=submitting) |

**一屏说清**：新建提醒是日历面「提醒」段下的写页（导航路径：首页 C 区日历格 → 二级 Tab「提醒」→ 新建），只收五件事——标题、时间、周期、提前量、渠道。「保存」不等于「已上日历」：提醒落库后由本面 30s 扫描纳入到期，到点由底座投递，页面不承诺保存完立刻生效。渠道不可用时**降级、不阻断**：推送关了就走站内信，保存照常可用。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 取消 | 点击 | 回提醒列表；已填内容丢弃，不落草稿、不入离线队列、不产生动态 | 提醒列表（`calendar/reminder/index`） |
| ② | 标题 | 输入 | 必填、≤40 字；为空时保存只给红框 + 行内「请填写标题」，不弹全局错误层 | 留在本页 |
| ③ | 时间 | 点击 | 上拉常用时刻；周期为每天 / 每周 / 每月时只取时分，日期由周期决定 | 时间选择层 |
| ④ | 周期 | 点击 | 不重复 / 每天 / 每周 / 每月四选一；选每周取今天星期、选每月取今天日号，底部「下次触发」即时重算 | 留在本页 |
| ⑤ | 渠道 | 点击 | 推送 / 站内信 / 两者三选一；推送不可用时该选项置灰并自动落到站内信，行内提示「推送不可用，将改为站内信」 | 留在本页 |
| ⑥ | 保存 | 点击 | 标题非空才提交；提交中按钮变「保存中…」且表单只读；降级态保存仍可用，成功后 toast 并回列表 | 提醒列表（`calendar/reminder/index`） |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 标题「吃药」、时间 08:00、周期每天、提前量准时、渠道两者；底部预览「下次触发：明天 08:00 · 准时 · 推送 + 站内信」 |
| 渠道降级 | 本机推送不可用（权限关闭 / 通道未接入） | 顶部提示「推送不可用，将改为站内信」；「推送」置灰划掉、选中项落到站内信；保存按钮照常可点，保存文案改「已保存，改由站内信送达」 |
| 错误 | 保存时标题为空 | 仅标题字段红框 + 行内「请填写标题」，其余字段与底部说明不动；不弹全屏错误、不 toast |
| 保存中 | 提交请求在途 | 保存按钮变「保存中…」且不可点，表单与取消整体降透明度锁定；顶部提示提醒落库后由本面 30s 扫描纳入到期、到点由底座投递 |

## 字段与校验（页面级硬规则）

- **标题**：必填、≤40 字，只做首尾空白裁剪；错误落在字段上，不用 toast / 弹层。
- **时间**：按家庭时区解释；周期提醒只取时分。不重复提醒才带具体日期。
- **周期**：四选一，不做自定义间隔、不做「跳过 / 顺延」（那是周期任务的口径）。
- **提前量**：准时 / 提前 10 分钟 / 1 小时 / 1 天；只影响触发时刻，不改周期。
- **渠道**：推送 / 站内信 / 两者。推送不可用 → 自动落站内信并明示降级，**保存不被阻断**；渠道字段只是**投递偏好**，实际投递一律由底座完成（本面不直连推送通道）；站内信落「消息 → 提醒」分组，与推送同源不重复计数。
- **保存承诺**：提醒落库后由本面 30s 扫描纳入到期，成功文案固定「已保存」；到点由 `calendar.reminder.fired` 交底座投递，页面不承诺保存完立刻生效，不得写「已加入日历」。

## 边界与不做

- 本页**不收**地点、参与人、备注、附件：位置提醒在 P6 前只有手动地点，字段在编辑页内维护。
- 不做「保存并再建一条」，不做「一次建多条」。
- 不在此页设暂停：新建出来即启用。
- 不在客户端算下次触发时间：预览句只按当前表单推导，落库后以服务端为准。

## 待复核

- 提前量对周期提醒是否同样生效（PRD 未分单次 / 周期），原型按全部生效。
- 渠道的默认值（两者 / 站内信）未定，原型默认「两者」。
- 推送不可用的判定时机（进入页面查一次 vs 保存时才发现）未定，原型按进入页面即降级。
