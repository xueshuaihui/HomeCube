# 18 · 编辑提醒

| 项 | 值 |
|---|---|
| 路由 | `calendar/reminder/edit` |
| 期 | ① |
| 权限 | 提醒归属人可改；管理员可改家庭内全部；儿童只能改自己的；访客只读（保存与删除置灰） |
| 原型 | [reminder-edit.html](../../prototypes/reminder-edit.html) |
| 状态帧 | [默认](../../prototypes/reminder-edit.html) · [已暂停](../../prototypes/reminder-edit.html?state=paused) · [版本冲突](../../prototypes/reminder-edit.html?state=conflict) · [删除确认](../../prototypes/reminder-edit.html?state=deleted) |

**一屏说清**：本页是日历面提醒的编辑页（`calendar/reminder/index` → 条目 → 本页），与新建同构，多了三件事——**暂停开关即时生效**（停触发、留规则）、**删除走弹层：直写删除 + 服务端级联失效其到期项**、**保存带 `version`**，版本不一致就三选一，不静默覆盖。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 回提醒列表；未保存的改动丢弃、不做草稿；暂停的改动已即时生效，不因返回回滚 | 提醒列表（`calendar/reminder/index`） |
| ② | 暂停 | 点击 | 即时生效、不等保存：关掉后不再触发但周期 / 时间 / 渠道原样保留，恢复后按原规则继续；不产生新版本 | 留在本页 |
| ③ | 字段 | 输入 / 选择 | 标题、时间、周期、提前量、渠道五项与新建同构；改动只在本页，保存才提交 | 留在本页 |
| ⑦ | 位置 | 输入 | 可选、≤30 字：只存用户填的地点文字，P6 前不接地图与地理围栏、不做到达判定、不保证触达；留空即普通时间提醒。本字段只在编辑页维护，新建页是否开放见 §待复核 | 留在本页 |
| ④ | 保存 | 点击 | 带 `version` 提交；标题为空只给字段红框；版本不一致不覆盖，弹冲突层；成功后整条更新本面到期项，旧项随对象失效（原生对象不发 `{code}.due.revoked`） | 留在本页 / 冲突层 |
| ⑤ | 删除 | 点击 | 不即时删除，先弹确认层：说明删除后不再触发、规则不可恢复，且**本面到期项随之级联失效、移除** | 删除确认层 |
| ⑥ | 冲突弹层 | 保存返回版本不一致 | 默认隐藏；展示修改人与差异，给「查看最新 / 覆盖保存 / 放弃修改」三选一，不做字段自动合并 | 列表 / 本页重载 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 版本标签「版本 3」+ 上次修改人；暂停开关为开；字段为这条提醒的现值；底部删除按钮与保存口径说明 |
| 已暂停 | 暂停开关关闭 / 从列表带暂停态进入 | 顶部「已暂停」说明（不触发、规则保留、打开即继续）；版本标签变「版本 3 · 已暂停」；开关为关，其余字段仍可改 |
| 版本冲突 | 保存时服务端版本已变 | 弹出冲突层：你打开版本 3、服务器版本 4，列出妈妈的改动（08:00 → 09:00）与你的改动；表单降透明度锁定；保存不可点 |
| 删除确认 | 点「删除提醒」 | 弹出确认层：条目摘要 + 「删除后本面到期项随之级联失效」，主按钮「删除提醒」，取消可退回 |

## 字段与校验（页面级硬规则）

- **保存带 `version`**：对象级乐观锁；409 时弹三选一，不静默覆盖、不自动合并字段。
- **暂停即时生效**：开关是独立写路径，不等保存；暂停只停触发，不改周期、不清历史，也不产生新版本号。
- **删除语义**：确认后直写删除并由服务端级联失效其到期项；本面原生对象**不发** `{code}.due.revoked`（该事件只属于他面注册项），已排期的触发一并取消；已同步到到期中心的条目随之移除，已发出的站内信不撤回（投递归底座）。
- **字段校验与新建一致**：标题必填 ≤40 字；时间按家庭时区；周期四选一；提前量四档；渠道三选一并支持推送不可用降级。
- **改时间 / 周期 / 提前量**：直写更新本面对象，整条到期项随对象更新，旧项随对象失效，不发撤销事件（原生对象不经 17.4），不由客户端删日历条目。
- **位置**：可选，≤30 字；只存用户填的地点文字，**P6 前不接地图与地理围栏、不做到达判定、不保证触达**，位置类提醒不计入到达率（5.5.3、5.5.8）。留空即普通时间提醒。

## 边界与不做

- 本页**不改**归属人（`owner_id`）：提醒归属创建人，P1 不提供转移。
- 不做「另存为新提醒」「复制周期」；不做提醒触发历史列表。
- 删除不提供回收站、不可撤销：误删只能重建。
- 不做地图选点、半径与到达判定（P6 地图 SDK 出生期随该面复验时再开放，20.1）；位置**只接受手动文字**。

## 待复核

- 暂停是否需要「暂停到某日自动恢复」：PRD 只写暂停，原型不做定时恢复。
- 冲突层的「覆盖保存」在原文档 §6.5 要求文案不出现「覆盖」字样（针对财务对象），提醒是否同口径未定；本轮按任务口径保留按钮名。
- 删除后是否留在列表并给出 toast，PRD 未写；原型直接回列表，建议实做补一条「已删除」提示。
- 版本冲突时的差异字段由服务端给出还是客户端对比未定，原型取服务端双版本 payload。
