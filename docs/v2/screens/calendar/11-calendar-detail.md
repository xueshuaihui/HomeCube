**一屏说清**：事件详情把一条注册项还原成「什么时候、来自哪个面、对应哪个对象、谁参与」。本页是日历面 `calendar/calendar/index` 的下钻页（导航路径：首页 C 区日历格 → 到期中心 → 本页），只读摘要，唯一动作是「前往源对象」——`source_system` / `source_id` 决定深链，源面不可用时按钮禁用但摘要照给，不白屏。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 财务来源的到期项 | 大时间 + 标题 + 来源 / 状态徽标；关联对象带金额；主按钮「前往源对象」指向财务面（后续） |
| 日历面原生源 | 注册项来自日历面自带对象（待办 / 提醒 / 日程） | 标题、时间、来源、关联对象与提醒随之切换；主按钮进本面待办详情或提醒编辑页，不出现财务深链 |
| 源面不可用 | 源面服务不可达 | 按钮置灰禁用，按钮上方说明「该面暂不可用，先看摘要」；摘要、时间、参与人照常 |
| 离线 | 无网 | 顶栏下细条 +「摘要为缓存 · 截至 HH:mm」；按钮保持可用性判断，不因离线改写来源 |

## 字段与校验（页面级硬规则）

- **深链只由注册字段决定**：`source_system` + `source_id` 决定「前往源对象」，客户端不按标题、金额反推源对象。
- **日历面自带对象**（待办 / 提醒）回本面内对应页（`calendar/todo/detail`、`calendar/reminder/edit`）；业务面对象走该面深链；未出生面只提示后续交付，不伪造路由。
- **源面不可用不白屏**：禁用按钮 + 一句可读说明，摘要至少包含标题、时间、来源、关联对象摘要。
- **参与人只读**：来自注册时快照；改名只改成员档案，不回写已注册项的历史参与人。
- **提醒设置只读**：时间、提前量、渠道在日历面提醒页维护（`calendar/reminder/edit`）；本页不提供编辑，也不承诺「保存即生效」。
- **状态与完成**：本页不设完成按钮；完成在源对象或待办详情里走 `done_returns_to` 回写，回写失败不影响本页展示。

## 边界与不做

- 不做完成、归档、删除：这些动作属于源对象或待办，详情只读。
- 不做评论、附件、@：留言板（底座）与源对象负责，本页不复制入口。
- 不做「重复规则编辑」：周期只在日历面提醒页改，改期由源面重新发 `{code}.due.registered`；日历面原生对象的暂停与删除走同一条撤销语义（五章 5.5.6），不另立事件。
- 不展示 L3 内容；被服务端裁掉的字段整行不渲染，不显示「无权限查看」。
- 本分包不得放面切换器（⑫）；回首页只走 ① 返回或 D 行「首页」。
