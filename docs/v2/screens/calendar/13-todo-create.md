# 13 · 新建待办

| 项 | 值 |
|---|---|
| 路由 | `calendar/todo/create` |
| 期 | ① |
| 权限 | 管理员与成人成员可创建；儿童只能创建负责人为自己的待办；访客不出现创建入口 |
| 原型 | [todo-create.html](../../prototypes/todo-create.html) |
| 状态帧 | [默认](../../prototypes/todo-create.html) · [标题为空](../../prototypes/todo-create.html?state=error) · [保存中](../../prototypes/todo-create.html?state=submitting) · [离线](../../prototypes/todo-create.html?state=offline) |

**一屏说清**：新建待办是日历面「待办」段下的写页（导航路径：首页 C 区日历格 → 二级 Tab「待办」→ 新建；也可从全局「＋」进），只收四件事——标题、负责人、截止、来源面，外加一句备注。「保存」不等于「上日历」：对象落库即由本面（`svc-calendar`）纳入到期中心——原生对象不经 17.4 注册事件、不发 `{code}.due.registered`，页面不承诺保存完立刻在日历上看到。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 取消 | 点击 | 直接回待办列表；未保存内容丢弃，不落草稿、不入离线队列、不产生动态 | 待办列表（`calendar/todo/index`） |
| ② | 标题 | 输入 | 必填、上限 60 字；为空时保存只给红框 + 行内「请填写标题」，不弹全局错误层 | 留在本页 |
| ③ | 负责人 | 点击 | 上拉本家庭成员选择，默认本人；选中后头像与姓名即时更新，被指派者会出现在其「分配给我」 | 成员选择层 |
| ④ | 截止时间 | 点击 | 上拉快捷时间（今天 / 明天 / 本周内）；只写一个时间点，不做重复规则 | 时间选择层 |
| ⑤ | 保存 | 点击 | 标题非空才提交；提交中按钮变「保存中…」且表单只读；成功后 toast「已保存」并回列表 | 待办列表 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 标题带示例值，负责人为我，截止为今天 20:00，来源面只读显示日历 · 待办，备注可空 |
| 错误 | 保存时标题为空 | 仅标题字段红框 + 行内「请填写标题」，其余字段与底部说明不动；不弹全屏错误、不 toast |
| 保存中 | 提交请求在途 | 保存按钮变「保存中…」且不可点，表单整体降透明度锁定；顶部提示对象落库即由本面纳入到期中心（原生对象不经 17.4 注册事件） |
| 离线 | 无网 | 顶栏下细条 + 顶部「当前离线」说明：保存后先存本机并入队，联网自动提交，重试不重复登记 |

## 字段与校验（页面级硬规则）

- **标题**：必填、≤60 字，只做首尾空白裁剪；为空时红框 + 行内错误，错误落在字段上，不用 toast / 弹层。
- **负责人**：默认本人，只能选本家庭成员；改负责人是「指派」，不改变创建人；一条待办只有一个负责人。
- **截止时间**：单一时间点，按家庭时区解释；不做重复规则、不做提前量（周期与提前量属于提醒）。
- **来源面**：只读，取值日历（本面原生对象）；由创建入口决定，编辑也不改。到期项的 `source_system` / `source_id` 随对象一起写入。
- **备注**：≤200 字，仅本家庭成员可见，不进入通知正文。
- **保存承诺**：对象落库即由本面纳入到期中心；原生对象不经 17.4 注册事件、不发 `{code}.due.registered`；成功文案固定「已保存」，不得写「已加入日历」。

## 边界与不做

- 本页**不建**子任务、附件、重复规则、提醒渠道：子任务在详情勾选，附件在详情查看。
- 不做「一次指派给多人」；不做「保存并再建一条」。
- 离线保存不报失败：入队并说明，联网后带幂等键重放。
- 不在此页选择业务面对象：待办只归日历面（`calendar_todo`），业务面事项由该面按 17.4 自己注册到期项。

## 待复核

- 成人成员能否把待办指派给他人（16.3「日历」行写作「自己的」）：原型允许选择全部成员，需按权限矩阵复核（㉚ 后时间语义在 16.3「日历」行）。
- 保存成功后落到列表哪一段：原型回到默认段，实做建议切到「我创建的」并高亮新条目。
- 自定义日期时间是否精确到分钟、是否复用系统组件，未定。
