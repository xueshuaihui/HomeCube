# 13 · 新建待办

| 项 | 值 |
|---|---|
| 路由 | `calendar/todo/create` |
| 期 | ① |
| 权限 | 管理员、成人成员、儿童成员都可创建，并都可把负责人指派给**本家庭任一成员**（含其他成人与儿童）；访客不出现创建入口、也不能指派。无账号成员由监护人代管，代管写入才带 `on_behalf_of` |
| 原型 | [todo-create.html](../../prototypes/todo-create.html) |
| 状态帧 | [默认](../../prototypes/todo-create.html) · [标题为空](../../prototypes/todo-create.html?state=error) · [保存中](../../prototypes/todo-create.html?state=submitting) · [保存失败](../../prototypes/todo-create.html?state=fail) · [离线](../../prototypes/todo-create.html?state=offline) |

**一屏说清**：新建待办是日历面「待办」段下的写页（导航路径：首页 C 区日历格 → 二级 Tab「待办」→ 新建；也可从全局「＋」进），收五件事——标题、负责人、截止、**重复规则**、来源面，外加一句备注。**「周期性提醒某位家人做某事」这一场景由本页承载（5.5.2 ㉛）**：待办的创建与分配、周期规则两项都定在 P1-M1，所以本页**既能把待办指派给任一家庭成员、又能勾选重复规则**，二者缺一即本页不通过。保存成功回待办列表（新建保存 → 回来源列表）；到期与重复的时间由服务端按家庭时区安排，本页不预告触发时刻。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 取消 / 返回 | 点击 | **有未保存内容时先弹「放弃？」确认**（与新建日程页同口径），无改动直接回待办列表；放弃后不落草稿、不入待同步队列、不产生动态 | 待办列表（`calendar/todo/index`） |
| ② | 标题 | 输入 | 必填、上限 60 字；为空时保存只给红框 + 行内「请填写标题」，**不发请求**、不弹全局错误层 | 留在本页 |
| ③ | 负责人 | 点击 | 上拉本家庭成员选择，默认本人；**本家庭任一成员都可选（含其他成人与儿童）**，选中后头像与姓名即时更新，被指派者会出现在其「分配给我」；层内一句写明对方权限：可勾选完成、可回应，不可改本体、截止与重复规则，不可归档删除 | 成员选择层 |
| ④ | 截止时间 | 点击 | 上拉快捷档 + **页面内自绘的月历与时分步进**（精确到分钟；不用浏览器原生日期控件的默认外观）；只写一个时间点，按家庭时区解释；到点只呈「到期」、不自动发通知 | 时间选择层 |
| ⑤ | 重复 | 点击 | 周期规则选择器：**不重复 / 每天 / 每周 / 每月 / 每年 / 自定义**六档（5.5.3 的封闭枚举）；「工作日」不是与它们并列的档位，而是「自定义」里的一个预设快捷（周一至周五五条周规则）；每周在段内**多选星期**、每月在段内**选日号**、自定义在段内设**每 N 天 / 周 / 月 + 结束条件**；**只存规则，不预生成任何实例** | 重复选择层 |
| ⑥ | 保存 | 点击 | 标题非空才提交；提交中按钮变「保存中…」且表单只读；成功后 toast「已保存」并回列表；服务端拒绝（400 / 5xx）留在本页、保留输入、给可重试条；离线时先存本机、联网自动提交 | 待办列表 / 留在本页 |
| ⑦ | 失败重试 | 点击 | 顶部红色条「保存没有成功，请检查网络后重试——你填的内容都还在」；字段值与所选周期原样保留，重试沿用同一请求标识、不产生第二条待办 | 留在本页 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 标题带示例值「倒垃圾」，负责人为爸爸（演示指派），截止为今天 19:00，重复为「每天」，来源面只读显示日历 · 待办，备注可空 |
| 错误 | 保存时标题为空 | 仅标题字段红框 + 行内「请填写标题」，其余字段与底部说明不动；不弹全屏错误、不 toast |
| 保存中 | 提交请求在途 | 保存按钮变「保存中…」且不可点，表单整体降透明度锁定；顶部说明到期与重复的时间由服务器按家庭时区安排，本页不预告触发时刻 |
| 保存失败 | 服务端拒绝 / 网络错误 | 顶部红色条「保存没有成功，请检查网络后重试——你填的内容都还在」+「重试」；标题、负责人、截止、重复规则、备注全保留，重试不产生第二条 |
| 离线 | 无网 | 顶栏下细条 + 顶部「当前离线」说明：保存后先存本机，联网自动提交，重试不重复登记 |

## 字段与校验（页面级硬规则）

- **标题**：必填、≤60 字，只做首尾空白裁剪；为空时红框 + 行内错误，错误落在字段上，不用 toast / 弹层。
- **指派（Q4 判定句）**：任何可创建待办的角色（管理员 / 成人 / 儿童）都可把待办派给**本家庭任一成员，含其他成人与儿童**；访客不可创建、不可派。默认本人；改负责人是「指派」，不改变创建人；一条待办只有一个负责人。被指派的参与人**可勾选完成、可回应**，**不可改本体、截止与重复规则，不可归档删除**——写权只在创建人与管理员手里（5.5.7 ㉛）；参与人已完成的那一期创建人**不可重开**（3.4.4 只进不退），要重做只能新建一条。**本页不得出现「只能指派自己」这类收窄形态**。
- **无账号成员的代管**：家庭成员里没有账号的（如奶奶），由监护人代管，选择她时写入携带 `on_behalf_of`；成人 / 儿童之间的正常指派**不带**该字段。选择层里给这一位标注「无账号 · 由某某代管」，其余成员不出现代管字样。
- **截止时间**：单一时间点，按家庭时区解释；自定义日期与时间是**页面内自绘的选择器**（月历格 + 星期表头 + 时分步进），不依赖浏览器原生日期控件的默认外观；**待办截止不自动产生提醒投递**——`due_at` 只把该待办登记为到期对象，要投递必须由用户显式挂一条提醒（档位恰为四档：准时 / 提前 10 分钟 / 1 小时 / 1 天，5.5.4 ㉛）。
- **重复规则（5.5.3 封闭枚举）**：**不重复 / 每天 / 每周 / 每月 / 每年 / 自定义**，六档之外不出现第七档；**「工作日」不是档位**，它是「自定义」段内的一个快捷：点一下把间隔置为「每 1 周」并勾上周一至周五五条周规则，落在自定义档内。提醒与待办同一套档位；`RecurringRule.applies_to` 含待办（5.7），**本页不得出现「不做重复规则」的写法**；只写规则行、**不预生成实例**；跳过与顺延是实例动作、不在本页（只在编辑页）。
- **自定义段**：三个部分——①间隔：每 N 天 / 每 N 周 / 每 N 月（N 为正整数，上限 30，单位三选一）；②按单位的细节：每周多选星期、每月选日号 1–31；③**结束条件：永不 / 到某日（自绘日期选择）/ 共 N 次**（N 为正整数）。档位摘要以人话回显，如「每 3 天 · 共 12 次」「工作日 · 周一至周五 · 永不结束」。
- **每周与每月**：每周在周期段内**多选星期**（不取「今天的星期」），每月在段内**选日号 1–31**（不取「今天的日号」）——周四也要能把这条设成每周一。
- **异常时间 · 每月日号不存在（与 19 卡逐字同句，只把「该日程」换成「该待办」）**：每月重复取 29 / 30 / 31 日而该月没有这一天时，**该月不生成、不顺延、页面不报错**；规则行保持原日号，是否落补到别日**只认服务端回显**，本页与客户端一律不推算、不自顺延。「每年」档取 2 月 29 日同此口径。
- **异常时间 · 节假日与调休**：本页**不判节假日与调休**——不顺延、不提前、不置灰、不弹确认；自定义里的「工作日」快捷只按周一至周五，放假日照常到期；展示与保存一律按用户所选的原值。
- **周期待办的完成语义（必给判据）**：**逐次完成**——勾选只完成到期的那一期，本期落 `done` 后服务端按规则行的 `next_at` 生成下一期（新行、新 id），重复规则与其余字段随原对象带过去；**没有「勾一次就把整条周期规则关掉」的整体完成形态**。要终止后续期次，只有两条：把重复改回「不重复」（编辑页，仅创建人与管理员），或归档（归档同时置规则 `is_active = false`，不再产生下一期）。
- **下次触发 / 到期时刻一律取服务端按家庭时区计算的回显**：本页不显示任何本地推算的触发预览行；客户端不得自行推算。
- **来源面**：只读，取值日历（本面原生对象）；由创建入口决定，编辑也不改。到期项的 `source_system` / `source_id` 随对象一起写入。
- **备注**：≤200 字，仅本家庭成员可见，不进入通知正文。
- **保存承诺**：对象落库即由本面聚合到日历上（原生对象不经 17.4 注册事件、不发 `{code}.due.registered`，5.8 末注）；成功文案固定「已保存」并回待办列表，不得写「已加入日历」，也不承诺保存瞬间可见。

## 边界与不做

- 本页**不建**子任务与附件：子任务在详情新增与勾选（5.5.2 的待办能力行含子任务）；**P1 待办没有附件字段**（5.5.2 能力行与 5.7 的 Todo 行都没有附件位），故本页也不出现附件入口。
- 不做「一次指派给多人」；不做「保存并再建一条」；不做草稿箱。
- 不做跳过 / 顺延：实例动作只在编辑页。
- 离线保存不报失败：入队并说明，联网后带幂等键重放。
- 不在此页选择业务面对象：待办只归日历面（`calendar_todo`），业务面事项由该面按 17.4 自己注册到期项。
- 不在本页建提醒：到期不自动投递，需要提醒请去 `calendar/reminder/create` 显式挂一条。

## 待复核

- 「自定义」的间隔上限本页取 N ≤ 30（天 / 周 / 月同），PRD 只给档位名未给参数边界；「共 N 次」的 N 上限同取 99。
- 「工作日」快捷勾出的五条周规则是否在保存后合并显示为「周一至周五」，取决服务端回显形态；本页只保证档位不另立一项。
- 结束条件选「到某日」时，早于截止日期的取值是否拒绝，PRD 未写死；本版不拦，按服务端回显。
