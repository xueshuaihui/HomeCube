| 项 | 值 |

**一屏说清**：本页是日历面待办的状态唯一改动页（导航路径：首页 C 区日历格 → 二级 Tab「待办」→ 条目 → 本页）。完成与归档各自弹确认层；完成发出本面事件 `calendar.todo.completed` 后**页面不等结果**，完成状态只进不退；归档只把它从提醒与列表里移走，不是删除。**还没有人认领的待办，底部给一步「认领」**。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 回待办列表并保持进入前的分段；本期完成后这一期不再出现在「分配给我」，下一期照常来 | 待办列表（`calendar/todo/index`） |

| ④ | 添加子任务 | 点击 | 一行标题、上限 40 字、即时保存；不做排序、不指派、不起止时间；只在创建人与管理员可见 | 留在本页 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 状态「待处理」、截止「10 月 29 日 周四 19:00 · 还有约 9 小时」；子任务 1/3；详情五行（这一期 / 重复 / 负责人 / 参与人 / 提醒）+ 来源一行；底部「完成这一期 / 归档」 |
| 待认领 | 负责人为空、未归档 | 状态「待认领」、负责人行写「还没有人认领」；底部「认领」+「归档」（归档只给创建人与管理员）；一句说明「认领后这条进你的『分配给我』」 |
| 已完成 | 回写成功或他人已勾选 | 状态变「这一期已完成」、截止处换成完成时间；子任务全勾且锁定；「完成」置灰显示「已完成」，「归档」仍可用 |
| 回写中 | 确认完成后的在途 | 「完成」按钮转圈、「归档」置灰；顶部说明回写中、可离开、失败会进对账重试；不阻塞返回 |
| 回写失败 | 回写非 2xx / 超时 | 顶部失败条「完成没有记上」+ 说明状态已退回待处理、内容与勾选保留 +「再试一次」；重试同一条，不产生第二条 |
| 已归档 | 归档成功或深链 | 顶部归档条说明已移出列表与提醒、不再提醒、完成状态不变；底部换成「取消归档 / 删除这条待办」 |
| 已不存在 | 深链指向软删对象（404 或 `deleted_at` 非空） | 整页「该条已不存在」+ 说明 +「回到待办列表」；不渲染半截字段、不报系统错误 |
| 离线 | 无网 | 顶栏下细条 +「显示本机缓存 · 截至 HH:mm」；确认完成改为入队提示（「已记在本机，联网后自动提交」），不假装已回写成功 |

## 字段与校验（页面级硬规则）

- **完成只进不退**：完成是单向的（3.4.4），本页不提供撤销；回写失败由对账重试，不把状态改回待处理。被指派的负责人完成之后，创建人也不能重开。
- **UI 不等回写**：确认后立即离开或停留都不影响结果；完成经本面事件 `calendar.todo.completed` 刷新，`done_returns_to` 由来源面消费（5.5.6）。
- **认领（Q5 判定句）**：认领 = 成员把一条**未指派**的待办取为自己的，一步完成、记操作人，认领后进「分配给我」。**已被他人认领的条目二次认领必须失败**，提示「已由某某认领」。管理员 / 成人 / 儿童可认领，访客不可。入口只有两处：列表的「未指派」段行内与本页底部。
- **归档不等于删除**：归档只把它移出提醒与列表，**不改完成状态**、不删对象；创建人与参与人都能在「已归档」查到，可取消归档。**删除只在「已归档」态出现**，确认后软删并记操作人，仅创建人与管理员可见；被软删对象重进本页落「该条已不存在」态。
- **子任务独立**：勾选即时生效，与主状态解耦；完成后子任务锁定，避免「已完成还有未勾子任务」的二次编辑。新增只在本页给最小入口（一行标题、上限 40 字、即时保存），不做排序与指派；被指派的负责人可勾选、不能新增。
- **附件**：P1 待办没有附件字段，本页**不留附件空入口**，也不出现「暂无附件」这类占位。
- **来源只读**：取创建时的 `source_system` / `source_id`；来源为日历面时到期项由本面聚合，其余业务面不自建定时器、不得改写。
- **时间格式**：按家庭时区格式化；剩余时间由客户端计算，跨 0 点后重新取一次详情，不靠本地定时器改状态。
- **样例数据单源**：本页与列表（12）、编辑（14）共用「倒垃圾（每天 19:00，参与人 爸爸 / 小满）」，负责人爸爸、创建人我。

## 边界与不做

- 不做评论、@ 与动态展开：这些归底座的留言板与动态流。
- 不做批量操作、复制为新待办；删除仅有「已归档 → 软删」这一条路径。
- 不做子任务的排序与指派：本页只勾选与新增一行标题。
- 不做跳过 / 顺延：实例动作在编辑页。
- 被服务端裁掉的字段整行不渲染，不显示「无权限查看」。

## 待复核

- 原型在回写中态用 1.8 秒自动流转到已完成，仅用于演示；实做应以回执为准。
- 「待认领」是否需要在列表与详情同时常驻一个红色提示，PRD 未写死；本版只在详情状态徽章与底栏体现。
- 参与人（除负责人外的共同参与成员）是否都计入「分配给我」，PRD 只写「责任归属算负责人」；本版按负责人聚合，共同参与成员可勾选但不入「分配给我」。
