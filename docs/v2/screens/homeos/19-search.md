**一屏说清**：全局搜索只做一件事——用一个关键词，跨面找家里已经有的对象。结果按面分组，**只出现这个家庭已开通、且当前角色看得见的面**；没开通的面不出现、不出空组、不占位。搜索不是面内列表的替代品，点结果回到源对象。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进页无输入 / 输入后有命中 | 无输入：最近搜索（本机最多 8 条）+ 可搜范围；输入后：按面分组的结果，组头带命中数。不设热门搜索（PRD 无数据源与口径） |
| 加载 | 请求未返回 | 结果区骨架（贴合组头与行高）；搜索框、清空、取消保持可操作，不整页遮罩 |
| 失败 | 请求超时 / 非 2xx | 整页失败态：图标 +「搜索没有完成」+ 一句人话原因 + ⑧「重试」；不渲染旧结果、不拿缓存冒充成功，关键词保留 |
| 无结果 | 关键词零命中 | 「没有找到与『X』相关的内容」+「换个更短或更常见的词试试」+ 建议词；不渲染空组标题，不显示「无权限查看」 |
| 离线 | 无网 | 顶栏下细条「当前离线」+「只显示本机缓存结果 · 最多 30 条 · 截至 HH:mm」；只展示本机缓存，不再发远程请求 |

## 字段与校验（页面级硬规则）

- **只调一个搜索接口**：`GET /api/homeos/search`；不按面并行请求各服务，也不由客户端合并多份响应。
- **分组集合由服务端给出**：已开通 ∩ 当前角色可见 ∩ 有命中；没开通、未启用与私密对象**不出组、不出空组、不出占位行**。已开通面零命中也不出组。面级降级提示只属于面目录与开通页，不进入搜索结果。
- **分页与组内全量**：首屏每组先给前 3 条 + 组头命中数；点「查看更多」进入该组第一页（20 条），续读用游标，不出现页码、总页数与跳页控件。
- **结果行四件套**：标题、所属面、时间、来源对象；金额有则加在行尾。四件均取服务端返回值，客户端不补字段、不拼摘要。
- **深链**：点行按 `homecube://{code}/{entity}/{id}` 打开源对象；可见文案写「打开这条流水 / 打开这条待办 / 打开这条家庭留言」，不展示协议串。源对象已删除时以服务端返回为准，行内标「已不存在」且不渲染链接。
- **空查询不发请求**：输入为空或仅空白时停留在最近搜索，不进入结果页；输入变化才触发搜索。
- **最近搜索只存本机**：最多 8 条，按最近使用排序，可一键清除；不跨设备同步。
- **私密内容不进搜索**：L3 内容不参与搜索，页面底部固定说明「私密内容不会出现在搜索结果里」。
- **金额口径**：财务条目金额用 `.amount`，符号在货币符号之前（`-¥380.00`）。
- **排序与分组顺序**：分组按 registry 顺序（当前 HomeOS → 财务 → 日历），随当期已开通面动态增减；组内按相关度、同分按时间倒序。
- **用户文案不出现工程术语**：不写协议串、错误堆栈与技术黑话，统一用人话描述对象与动作。

## 边界与不做

- P1 **只做关键词搜索**，自然语言搜索与 AI 语义召回在 P6。
- **不做**结果筛选器、排序切换与页码翻页；组内全量只用「查看更多 + 游标续读」。
- **不做**热门搜索、搜索历史云端同步、搜索建议接口。
- **不做**第二个搜索入口；面内列表筛选不算全局搜索，也不复用本页。
- **不搜索**图片与附件正文，不在结果里展示私密对象的模糊占位。
- **不为未开通或未启用的面做任何提示、空组或占位**；搜索结果只呈现已开通面的命中。
- **不保留死链**：源对象已删除时只给「已不存在」提示，不把整行做成仍可点击的链接。

## 已定口径（本轮收口）

- 18.2#7 与 18.6 / 18.8 的差异按后者执行：搜索结果不为未开通或未启用的面出组，面级降级文案不进入结果页。
- 最近搜索 8 条、只存本机、可一键清除；保留时长不写死，清除即全部删除。
- 分组顺序按 registry（HomeOS → 财务 → 日历），随当期已开通面动态；组内相关度优先、同分按时间倒序。
- 分页定为游标、每页 20 条；首屏每组前 3 条，组内全量从「查看更多」进入。
- 300ms 防抖与「回车立即搜」为交互口径；空查询不发请求、不进结果页。
