**一屏说清**：隐私页只做两件事——家庭级的 L2/L3 可见性开关（关闭前先过一层影响预览），和本人的私密流水（作者与家庭管理员可读，㉛）。紧急卡是 P4 才出生的开关，P1 只给禁用态占位，不让用户误以为已经能开。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认（管理员） | 管理员进入 | L2 / L3 开关可写且默认开启；私密流水开；删除请求可点；紧急卡为禁用占位 |
| 非管理员只读 | 成人 / 儿童 / 访客 | 两个家庭级开关置灰、锁说明展开、标记转警示色；私密流水与删除请求仍可操作；本人有处理中的删除申请时状态条照常显示（属本人） |
| 删除请求 | 点「申请删除我的数据」或 `?state=delete` | 弹层列明 30 天内完成、处理完成前可撤回、已导出文件不在删除范围、家庭共有数据保留；主按钮为危险色且非默认焦点 |
| 申请进行中 | 提交成功后或 `?state=deletion_pending` | 「数据与删除」分组顶部状态条：「删除申请处理中 · 剩余 26 天 · 处理完成前可撤回」+「撤回申请」按钮；下方保留一行说明「已导出到设备的文件不会被删除，需要自行保管或删除」 |
| 关闭预览 | 管理员把 L2 开关切向关，或 `?state=l2preview` | 预览弹层——变什么：「其他成员将看不到彼此填写的金额、备注和账户名」；不会变：「你自己写的内容全部照常，各项合计与统计的口径不变，私密记录的标记也不受影响」；脚注「随时可以重新开启」；默认焦点在「取消」 |
| 加载 | 拉取可见性配置 | 骨架屏贴合分级卡与三组列表 |

## 字段与校验（页面级硬规则）

- 家庭级开关只有管理员可写；非管理员不隐藏行——用户需要知道当前家庭策略，只读比消失更可解释。
- **L2 总开关关闭必须过影响预览（本轮定版）**：一步切换即全家互相看不到金额，属高影响可逆操作；预览层列「变什么 / 不会变什么」、写明可逆（「随时可以重新开启」）、默认焦点不在危险按钮；「仍要关闭」点击后开关才置灰保存。开启方向不需预览。
- 私密流水是行级可见性，口径按 16.3 / ㉛ 定版为**作者与管理员可读**（不是「仅本人」）：命中行在服务端 SQL 层过滤，客户端不做二次过滤；私密流水**计入家庭合计与报表总量**，明细行按读者可读范围裁剪，合计位注明「含 N 条你无权查看的记录」（㉛）——因此「成员看到的合计多于他能打开的明细」是既定表现，页面与说明块须给中性文案解释，不得写成故障或权限缺陷。排除范围**只有** AA 分摊与跨面归集；导出默认排除、可勾选包含（30 数据页）。
- 删除请求（本轮定版：可撤回）：提交后 30 天内完成处理；**处理完成前可撤回**——撤回入口为同页「申请进行中」状态条上的「撤回申请」，可测窗口 = 提交至处理完成（≤30 天），撤回即时生效、无需二次危险确认，撤回后状态条消失、入口恢复；处理完成后撤回按钮不再渲染。**不可撤回的部分必须单列**：已导出到设备/下载目录的文件不在删除执行范围内，弹层与状态条都要写明「导出的文件需要你自行删除」。家庭共有的流水与清单保留并标记「已退出成员」，个人偏好与私密内容随删除清除。
- 紧急卡：P1 只有禁用占位，不展示任何紧急数据；P4 开启后锁定屏仅显示姓名、血型、过敏与紧急电话，默认关闭且需二次确认。
- L3 读取 = 本机设备锁 + 会话内二次确认；跳过设置 PIN 不免除二次确认。

## 边界与不做

- P1 不做通用对象级 ACL 与家庭级覆盖（随 P6）；本页只落私密流水一个行级实例 + L2/L3 两个总开关。
- 不做按成员逐个配置可见性的矩阵。
- 紧急卡在 P1 不开放真实开关、不出现「即将上线」以外的假入口。
- 删除请求不等于解散家庭；解散家庭在家庭治理流程里。

## 待复核

- L2 / L3 两个家庭级总开关的默认值与关闭后的确切范围，PRD 16.4 只给字段默认可见范围，未定义总开关语义；本页按「默认可见、关闭后他人不可读（L2 私密行仍由作者与管理员按 16.3 读取）」执行，预览层文案随本条一并复核。
- 删除处理时限取 30 天（对齐 22.4 家庭数据冷存窗口），个人删除请求的法定时限未在 PRD 单列；撤回窗口随该时限定版。
