# 23 · 成员治理

| 项 | 值 |
|---|---|
| 路由 | `homeos/family/detail` |
| 期 | ① |
| 权限 | 仅管理员；非管理员不可达（治理动作全部在此页） |
| 原型 | [family-detail.html](../../prototypes/family-detail.html) |
| 状态帧 | [默认](../../prototypes/family-detail.html) · [角色变更确认弹层](../../prototypes/family-detail.html?state=roleconfirm) · [移除弹层](../../prototypes/family-detail.html?state=remove) · [最后一名管理员](../../prototypes/family-detail.html?state=lastadmin) · [加载](../../prototypes/family-detail.html?state=loading) |

**一屏说清**：这是「对这个成员做什么配置」的唯一页面——角色、该成员的面可见性授权、数据范围、代管关系与移除。它与成员公开页是两屏：这里能写，公开页只读。角色可见性授权是 `scope=module` 的逐成员授予，**不是**家庭启用哪些面。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 回家庭成员；未确认的改动不落库 | 家庭成员（`family.html`） |
| ② | 成员头 | 点击 | 进只读公开页；治理页与公开页不合并，一个答「这个人是谁」，一个答「对他配置什么」 | 成员主页（`member-detail.html`） |
| ③ | 角色选择 | 点击另一档 | 不直接写，先弹确认层说明这一档能做什么；确认后才提交并即时生效 | 角色变更确认弹层 |
| ④ | 角色可见性授权 | 拨开关 | 逐面授予/收回 `scope=module` 的可见性；家庭未启用或未出生的面不可授予 | 留在本页（toast） |
| ⑤ | 数据范围 | 查看 | P1 取角色默认矩阵，只读；家庭级覆盖与对象级 ACL 随 P6 | 留在本页 |
| ⑥ | 代管关系 | 查看 | 展示监护对象与代管人；代写标注代管关系，内容归属被记录成员 | 留在本页 |
| ⑦ | 移除成员 | 点击 | 打开移除确认层，不直接移除 | 移除弹层 |

| ⑨ | 移除弹层 | 确认 / 取消 | 确认后回成员列表并提示历史内容保留；取消不改变任何状态 | 家庭成员（`family.html`） |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 治理一位成人成员 | 成员头 + 角色 + 逐面授权 + 数据范围 + 代管关系 + 移除，六段完整 |
| 角色变更确认弹层 | 选了另一档角色 | 说明新角色能力、变更前后与生效时机；确认按钮不置危险色（非破坏性） |
| 移除弹层 | 点「移除成员」 | 危险确认：历史内容保留、作者显示已退出成员；个人偏好与私密账本随退出删除 |
| 最后一名管理员 | 治理自己且是唯一管理员 | 降级被拦并给提示，成员/只读两档置灰；移除按钮置灰为「不能移除自己」，文案指向先转让 |
| 加载 | 首屏请求中 | 成员头与分节骨架；不显示任何可写控件 |

## 字段与校验（页面级硬规则）

- **角色三档**：管理员 / 成员 / 只读；任何变更都走二次确认，确认后下一次请求即按新角色判定。
- **家庭至少一名管理员**：最后一名管理员不能降级、不能移除自己；换管理员必须先转让。
- **角色可见性授权 ≠ 家庭挂载**：这里只授予「TA 能看到哪些面」（`scope=module`）；家庭启用哪些面的唯一入口是 `homeos/family/modules`，本页不出现家庭级面开关。
- **不可授予的面**：家庭未启用或服务未出生的面，开关置灰并说明原因，不隐藏、不改写规则。
- **数据范围**：P1 只读，取角色默认；不为没有写路径的覆盖层提前做控件。
- **代管关系**：无账号被记录成员由 `guardian_id` 指向的监护人代管，代写携带 `on_behalf_of`；代管数据归属被记录成员。
- **移除**：软删 + 该成员令牌即刻失效 + 落审计；其历史内容保留在家庭，作者显示「已退出成员」；个人偏好与私密账本内容随退出删除。

## 边界与不做

- 与 `homeos/member/detail` **不合并**：公开页全角色只读，本页仅管理员。
- 本页**不做**家庭面挂载开关，也不做「哪些面可用」的家庭级配置。
- 本页**不做**转让管理员、退出家庭、解散家庭。
- 本页**不做**逐成员数据范围自定义，也不做对象级 ACL。
- 本页**不做**监护对象的增删（代管关系只读）。
- 移除**不做**在按钮上直接执行，必须弹层确认。

## 待复核

- 角色变更是否需要额外验证（PRD 只要求确认弹层，本屏未加密码）。
- 数据范围是否允许 P1 逐成员配置（本屏按只读处理）。
- 监护对象能否在本页增删（PRD 未定，本屏只读）。
- 移除成功后是回列表还是留在本页（原型 toast 后回列表）。
- 角色变更对「最后一名管理员」的判定是否也覆盖访客与儿童档（本屏只覆盖降级）。
