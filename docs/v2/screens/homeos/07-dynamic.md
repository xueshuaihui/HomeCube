**一屏说清**：动态流是首页 D 区的展开页，把七面变更与完成记录按天混排。只读、只展示服务端发下来的条目；按面筛选与游标分页都在本页完成，不进任何面的二级 Tab。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 面筛选 | 点击 chips | 只列本家庭已启用且已出生的面（P1 = 全部面 + 财务 + 日历）；选中财务后列表只留财务条目，分组计数与「加载更多」余量同步按筛选后口径 | 当前页切换，不跳路由 |
| ② | 日期分组头 | 滚动经过 | 今天 / 昨天 / 更早三组；分组头吸顶显示当前日期与条数，点击不跳转 | 留在本页 |
| ③ | 动态条目 | 点击 | 整行可点，不在动态页展开详情；财务流水与预算调整走财务深链，日历条目进待办详情 / 日程详情 / 提醒编辑，底座条目进留言板 | 财务面（后续）/ `calendar/todo/detail` / `calendar/calendar/detail` / 留言板 |
| ④ | 加载更多 | 点击 | 游标续读并追加到底部，不重排已读条目；末页后按钮消失并显示「没有更多了」；续读失败只在底部重试 | 当前页追加 |
| ⑤ | 空态行动 | 点击 | 零条时给可执行动作「去记一笔」，筛选条保留 | 全局＋ |
| ⑥ | 底部五项 | 点击 | 一级页无栈互切；动态为当前项；消息位红点与顶栏同源 | 首页 / ＋ / 消息 / 我的 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 首屏成功 | 按天分组，今天 / 昨天 / 更早；底部「加载更多 · 还有 N 条」；筛选条默认「全部面」 |
| 加载 | 首屏请求中 | 分组头与条目的骨架屏贴合列表形状，不用 spinner 遮内容；筛选条暂时隐藏 |
| 空态 | 本家庭零条动态 | 「还没有家庭动态」+「去记一笔」；筛选条保留，可切回全部面 |
| 按面筛选 | 点击某面 chip | 只留该面条目，分组头计数与加载余量同步；该面零条时走空态并保留清除筛选入口 |
| 离线 | 无网 | 顶栏下常驻细条「当前离线 · N 项待同步」；列表显示本机缓存与最后更新时间，不阻塞浏览 |
| 错误 | 首屏请求失败 | 整页错误态 + 重试；筛选条隐藏；重试只重发动态首屏；续读失败才在底部重试并保留已加载内容 |

## 字段与校验（页面级硬规则）

- **动态只由事件总线写入**：客户端与本页都不产生动态，页面只读。
- **整句由服务端拼好**：人名、动作、对象摘要在服务端成句；客户端只做相对时间格式化（按家庭时区），不拼动词、不二次聚合。
- **图标与面色只取 registry**：条目前的标记复用面图标与面色令牌，不引入第二套「事件类型」图形。
- **可见性由服务端裁剪**：被裁掉的条目不返回、不占位、不显示「无权限查看」；客户端收到什么就显示什么。
- **筛选集合五处同源**：与首页矩阵、「＋」目标对象、搜索分组、到期中心注册项读同一份面集合；未启用与未出生的面不出现在 chips 里。
- **游标分页**：以服务端返回的游标为准，同一游标重复请求幂等，不重复插入；首次失败才是整页错误，续读失败不清空已加载列表。
- **金额口径**：财务条目金额用 `.amount`，符号在货币符号之前（`-¥128.00`；预算调整等非交易金额不带符号）。
- **相对时间**：`N 分钟前` / `今天 HH:MM` / `昨天 HH:MM` / `MM 月 DD 日 HH:MM`，一律按家庭时区。

## 边界与不做

- 动态页**不做**点赞、评论、@、转发；协作讨论在留言板。
- 动态页**不做**编辑、删除、撤回；源对象的状态变更在源对象页完成。
- 动态页**不做**成员筛选、关键词搜索、按面跳转；搜索统一走全局搜索。
- 动态页**不做**自动无限滚动，P1 固定为「加载更多」按钮。
- 动态页**不出现**未读红点或未读数；未读只属于通知口径，与动态无关。
- 不把「更早」折叠成二级入口，也不按周 / 月再分组。

## 待复核

- 日期分组以家庭时区 `00:00` 为界；跨日条目归入发生日，不做「刚刚 / 今天」之外的自然语言分组。
- 「全部面」固定第一，其余按 registry 登记顺序（财务 → 日历 → HomeOS，日历行在 17.1 的插入位以定版 ㉚ 落盘为准，若顺序不同需同步本页与搜索分组）；各面条目在同一组内按发生时间混排，不按面分段。
- 预算调整类动态显示正数金额是否与财务面口径一致，待财务面走查确认。
- 每页条数 PRD 未写死；原型按每页 20 条、末页剩 6 条演示。
