# 02 · 创建家庭

| 项 | 值 |
|---|---|
| 路由 | `homeos/auth/family-create` |
| 期 | ① |
| 权限 | 已登录但没有任何家庭 |
| 原型 | [family-create.html](../../prototypes/family-create.html) |
| 状态帧 | [默认](../../prototypes/family-create.html) · [重名](../../prototypes/family-create.html?state=error) · [提交中](../../prototypes/family-create.html?state=loading) |

**一屏说清**：给家庭起名并定下时区与币种，然后进入「选择要开通的面」的强制引导。家庭是数据边界，创建后账目、成员与权限都只在本家庭内可见。**「P1 唯一可选面是财务面、开通后方可进入」这件事必须在点创建之前就说清**——判据不放宽，但预期管理必须在最前面。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 家庭名称 | 输入 | **输入侧即拦 2–20 字**（满 20 字不再录入，不靠提交后才报错）；提交时校验不少于 2 字与同账号下不重名，错误显示在字段下方 | — |
| ② | 家庭头像 | 点击色块 | 五色可选、不传图片；选中项描边高亮，仅影响 App 内标识 | — |
| ③ | 时区 | 选择 | 默认取系统时区；决定「今天」的边界，影响到期中心与提醒 | — |
| ④ | 币种 | 选择 | 默认人民币；只做符号与展示，不换算汇率 | — |
| ⑤ | 创建并继续 | 点击 | 名称为空或不足 2 字 → 提示并中止；正常 → 按钮加载，成功后弹出「下一步选择要开通的功能」，弹层文案与本页上方说明区同一口径，用户可见文案：『家庭已创建 · 下一步选择要开通的功能：现在只有「记账与预算」可以开通，开通后才能进入；之后可以在「我的」里随时调整』 | 面目录引导态（第 4 批，`homeos/family/modules` 的一页两用途，不另开路由位）；**选面步骤不可跳过** |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 名称输入框聚焦，头像默认第一色，时区/币种取默认值；**标题下的说明区恒渲染一句选面预期**（见「字段与校验」的页面级硬规则），不在点创建之后才第一次告知 |
| 重名 | 提交后服务端判定同名 | 名称字段错误样式 + 「你已有一个同名家庭，请换一个名称」 |
| 提交中 | 点击创建 | 按钮内联 loading，表单只读，防重复提交 |
| 网络失败 | 请求失败 | 停留在本页，已填内容不丢，提示可重试 |

## 字段与校验

| 字段 | 规则 | 失败文案 |
|---|---|---|
| 家庭名称 | 必填，**2–20 字**（输入侧 `maxlength` 拦上限、提交侧拦下限，与交互表①同一个数） | 「请填写家庭名称」/「家庭名称至少 2 个字」/「你已有一个同名家庭，请换一个名称」 |
| 头像 | 五选一，默认第一色 | — |
| 时区 | 默认系统时区，可改 | — |
| 币种 | 默认 CNY，可改 | — |

**页面级硬规则（选面预期管理）**：

- **进入本页即呈现、不可关闭、不随输入消失**的一条说明，位置在标题下方说明区（第一屏内、创建按钮之上），用户可见文案：『创建后需要开通至少一个功能才能进入，现在可以选择的是「记账与预算」。之后可以在「我的」里随时调整。』——**「面 / 服务 / 开通」这类内部词不得写进引号内的用户文案**。
- **判据不放宽**：「至少启用 1 个面、不可跳过」与「按可选面集合判、原断言不放宽」都是已锁判据（18.8、导航文档 §6.11），本页只负责**在点创建之前把预期说清**，不得改成可跳过、不得给出「0 个可选面」的样例、不得在文案里暗示可以先不选。
- 说明区的文案与 ⑤ 的弹层文案**同一口径、两处不各写一份**：都是「现在可选的是记账与预算 → 开通后方可进入 → 之后可在「我的」里调整」三段。

## 边界与不做

- **创建后不是直接进首页**：必须经过「至少选 1 个面」的引导；本屏只负责把用户送到那里，并把预期提前讲清。
- 账号最多加入 5 个家庭（上限提示由服务端返回，客户端只展示）。
- 不做邀请成员：创建者即管理员，邀请在成员管理里发起。
- **未登录时经邀请链接进来的用户不落本页**：邀请上下文的回跳优先（01），本页只在「确实没有任何家庭」时才到达。
