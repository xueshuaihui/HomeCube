# 02 · 创建家庭

| 项 | 值 |
|---|---|
| 路由 | `homeos/auth/family-create` |
| 期 | ① |
| 权限 | 已登录但没有任何家庭 |
| 原型 | [family-create.html](../../prototypes/family-create.html) |
| 状态帧 | [默认](../../prototypes/family-create.html) · [重名](../../prototypes/family-create.html?state=error) · [提交中](../../prototypes/family-create.html?state=loading) |

**一屏说清**：给家庭起名并定下时区与币种，然后进入「选择要开通的面」的强制引导。家庭是数据边界，创建后账目、成员与权限都只在本家庭内可见。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 家庭名称 | 输入 | 最多 20 字；提交时校验非空与同账号下不重名，错误显示在字段下方 | — |
| ② | 家庭头像 | 点击色块 | 五色可选、不传图片；选中项描边高亮，仅影响 App 内标识 | — |
| ③ | 时区 | 选择 | 默认取系统时区；决定「今天」的边界，影响到期中心与提醒 | — |
| ④ | 币种 | 选择 | 默认人民币；只做符号与展示，不换算汇率 | — |
| ⑤ | 创建并继续 | 点击 | 名称为空 → 提示并中止；正常 → 按钮加载，成功后弹出「下一步选择面」 | 面目录引导态（第 2 批）；或先用默认面进入首页 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 名称输入框聚焦，头像默认第一色，时区/币种取默认值 |
| 重名 | 提交后服务端判定同名 | 名称字段错误样式 + 「你已有一个同名家庭，请换一个名称」 |
| 提交中 | 点击创建 | 按钮内联 loading，表单只读，防重复提交 |
| 网络失败 | 请求失败 | 停留在本页，已填内容不丢，提示可重试 |

## 字段与校验

| 字段 | 规则 | 失败文案 |
|---|---|---|
| 家庭名称 | 必填，2–20 字（原型暂定） | 「请填写家庭名称」/「你已有一个同名家庭，请换一个名称」 |
| 头像 | 五选一，默认第一色 | — |
| 时区 | 默认系统时区，可改 | — |
| 币种 | 默认 CNY，可改 | — |

## 边界与不做

- **创建后不是直接进首页**：必须经过「至少选 1 个面」的引导；本屏只负责把用户送到那里。
- 账号最多加入 5 个家庭（上限提示由服务端返回，客户端只展示）。
- 不做邀请成员：创建者即管理员，邀请在成员管理里发起。
