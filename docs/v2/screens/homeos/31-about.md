## 字段与校验（页面级硬规则）

- **求助路径（本轮定版）**：P1 唯一可达出口 = 「联系家庭管理员」，落点为家庭留言板（`homeos/message/board`，底座能力、恒在）——跳转自动带入对管理员的提及，发送即留言 + 管理员收到一条 `system` 类站内通知（09 页口径）；不可用兜底 = 留言板离线待同步队列（保留草稿、联网重发，同 09 离线态），不新增第二套反馈通道。常见问题 / 使用指南 / 反馈与客服三行保留，但点击必须给出提示文案并指路联系管理员，任何角色下都不得渲染为无响应的死行。
- 版本号取当前 wgt 版本，登录后静默检查一次；未登录冷启动不检查（3.4.8、㉕）。
- 有新版本不打断当前操作；更新引导只在「关于」和下次冷启动各出现一次且可跳过；仅 `min_compat` 高于当前版本才强制。
- 隐私政策 / 用户协议在文本定版前显示「文本待定版」；不跳外部链接、不展示未定稿条款、不伪造全文入口；政策弹层对用户只说日常语言（收集哪些信息、保留多久、定版后怎样展示全文），`min_compat`、门禁、字段清单、埋点字典等技术口径只出现在本节。
- 定版属 P1 末附加门禁：首次登录展示确认并留痕；正文需与 L2/L3 字段清单、埋点字典、数据保留期底稿逐项一致，不新增未登记字段。
- 检查失败不弹窗、不阻断，只在本行显示「检查失败，可重试」。

## 边界与不做

- 不做外链打开政策、不做应用商店评分引导、不做强制更新弹窗（`min_compat` 除外）。
- P1 不做多语言与英文条款；不展示开源许可列表。
- 帮助中心与反馈入口在 P1 末上线，当前只作说明行并指路联系管理员，不出现假表单。
- 不在本页展示任何家庭数据。
