**一屏说清**：首页是「家庭服务矩阵」的承载页，也是全 App 唯一的面入口。首屏只发一个请求；未启用与未出生的面**不出现、不占位**——P1 已启用 2 面（财务 + 日历），矩阵就是两格。日历面是面目录里的**必选面**，它的格子恒在、不渲染启用开关，也不提供停用路径（定版 ㉚ §7）。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 首屏成功 | A 家庭区 → B 今日区 → C 面矩阵 → D 动态区，顺序恒定；C 区两格（财务 + 日历）；A 区不呈现任何到期计数 |
| 骨架 | 首屏请求中 | 骨架屏贴合四区形状，不用 spinner 遮内容 |
| **首屏失败** | 聚合请求非 2xx / 超时（**不是**某一面不可达，那是「面不可用」） | **整页失败态**（§八 `hc-state-error`）：图标 + 一句「没能加载首页」+ 可见错误码 + ⑪ 的「重试」主按钮；四区一律不渲染半成品、不留半格数据；重试期间回到骨架态 |
| 动态空 | D 区零结果 | 「还没有家庭动态」+「去记一笔」，A/B/C 照常 |
| 离线 | 无网 | 顶栏下常驻细条「当前离线 · N 项待同步」，内容显示最后值 |
| 面不可用 | 面服务不可达（P1 即 `svc-calendar` 不可达） | 仅该格去色 + 最后值 + 「截至 HH:MM」+ 重试；B 今日区同格出现「暂不可用」细条并保留最后一次投影值；**其余面与 A/D 区不受影响**（19.4 第 7 条）；重试只重发首页聚合请求 |
| 0 格·受限角色 | 角色可见集为空（除必选面外无可见面） | 日历格是必选面恒在，故 owner/member 不会出现真空；儿童/访客按 18.2#12① 原口径复测其 C 区是否整区不渲染，不放占位卡、不出现「无权限」字样；**A 区家庭名下方渲染一行中性引导**（见「字段与校验」） |

## 字段与校验（页面级硬规则）

- **首屏一个请求**：四区不得并行请求多个服务；抓包可直接断言。B 今日区的日历项由服务端在同一次聚合里跨服务只读调用 `svc-calendar`（17.3 方式一，超时 ≤300ms、最多重试 1 次），客户端不直连第二服务。
- **首屏失败必须有整页态**：`home/summary` 非 2xx 或超时 = 首页级失败，走 §八 的失败态（图标 + 一句说明 + 可见错误码 + 重试），**重试只重发首页聚合请求**这一条与 ⑧/⑪ 共用同一个动作口径；「面不可用」是单面降级，两者不是同一个态，不得互相顶替。
- **今日那个数只有一个权威位**：全量今日到期与待办数 = `due_today.count`，**只在 B 今日区标题行「今日 N 项」呈现**；A 区不重现这个数（A 区只有问候语、家庭名与头像排），C 区任何格的状态句也不得复述它。
- **角标口径写死**：C 区格子的角标是 `faces[].badge` = **该面的待处理数**（18.1 第 3 条、导航文档 §3.3），与 `due_today.count`（今日全量）、`unread`（顶栏与 D 行红点）**三个语义互不顶替、不共用字段**；上限 99+、>0 才渲染。日历格的状态句取「待办逾期 N 条」这一档口径（导航文档 §3.5），**不取「今日到期 N 项」**——那与 B 区标题是同一个数、同一句话，同屏出现两次就是本次走查判掉的歧义。
- **受限角色的中性引导**：可见集只剩必选面（0 格与稀疏宫格都算）时，**A 区家庭名下方一行不可点的纯文案**，由 `home/summary` 下发、客户端不拼装，用户可见文案：『这里显示你们家可用的功能』。**「不显示无权限、不显示未启用」这条安全口径一字不改**（18.2、18.7 第 4 条）——本条只加一句中性说明，把「像坏了」变成「本来如此」，位置选 A 区是因为 A 区恒渲染，不受 C 区两种断言分支影响。
- **面入口唯一**：顶栏不放面切换器；从面内回首页再点格是切面的唯一路径。
- **未启用 / 未出生不占位**：只有「已启用 ∩ 已出生 ∩ 该角色可见」的面才出现；日历面属必选面，恒满足前两项。
- **必选面不画开关**：日历格与其余面格同尺寸同结构，但不带启用/停用控件，也不进「开通更多面」的可开通列表（决策 ㉚ §7）。
- **今日区不解释归属**：小卡只按归属面取面色（财务 = 财务面色，日历 = 日历面色），不写「待办」「优先级」标签。
- **今日区不解释指派**：混排项里**不会出现「指派给他人的提醒」**——提醒的归属人恒为创建人、不可指派（定版 ㉛）；「每周提醒某位家人做某事」这一类在这一格呈现为一条带重复规则、并把该成员设为参与人的**待办**，同样由定版 ㉛ 承接。首页不为此加一句解释文案，也不加「谁指派的」标签。
- **两个红点同源**：顶栏与底栏消息位读同一份未读数，进入消息页同时清零。
- **问候语称谓**：优先 `relation`，缺值回落成员名，两者皆空时用通用称谓；不为此另调接口。
- **金额口径**：符号在货币符号之前（`-¥1,406.32`），与服务端格式化一致。

## 边界与不做

- 首页**不放**「开通更多面」入口，开通统一在「我的 → 开通更多面」。
- 首页**不放**快捷入口位、不放面切换器、不拉伸卡片撑满首屏。
- 矩阵格数不等于 6 不是缺陷；P1 定版两格（财务 + 日历）。
- 今日区**不解释**「未启用」：`svc-calendar` 不可达只能显示「暂不可用」，不得写「未启用」「未开通」。
