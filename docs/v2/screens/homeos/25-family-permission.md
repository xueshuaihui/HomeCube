## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 管理员进入 | 只读说明条 + 三行矩阵 + 边界说明卡；全页没有可改权限的控件 |
| 非管理员 | 成人成员进入 | 整页只读，矩阵只剩本人角色一行并高亮；提示条说明角色由管理员在治理页调整 |
| 加载 | 矩阵请求中 | 说明条与矩阵位置用等高骨架，不用 spinner 遮内容，不先渲染旧值 |
| 失败 | 请求失败或超时 | 整页失败态 + 重试；不回落成本地推断的矩阵 |

## 字段与校验（页面级硬规则）

- **只读边界**：不出现父级/覆盖开关、不出现对象级 ACL；`family_overrides` / `object_acls` 在 P1 恒为空且本页不为它们渲染任何控件（16.2 ㉖）。
- **列口径**：列 = 本家庭已启用且已出生的面（P1 只有财务）+ 基础能力；未启用面不进列，全量清单去面目录页看。
- **两值单元格**：单元格只有 ✓ / —，不出现「部分」「条件」等第三态；条件说明写在图例里（如财务列：成人成员本人可写、全家可读）。
- **不产生 pver**：本页任何操作都不改权限版本；唯一来源是改成员角色（`PUT members/{id}/role`）。
- **服务端裁剪**：非管理员只拿服务端裁过的可见范围，客户端不自行按角色过滤。
- **面启用状态不进本页**：本页不显示也不改「本家庭启用哪些面」，那是面目录页的唯一职责。

## 边界与不做

- 不做角色编辑、不做权限覆盖、不做对象级 ACL、不做邀请。
- 不做「先只读放着」的覆盖层占位：没有写路径就不渲染控件。
- 不为未出生的面补列、画灰格或写「即将上线」。
- 访客有效期与私密流水行级可见性不在这张表里（分别在会话校验与隐私页）。
