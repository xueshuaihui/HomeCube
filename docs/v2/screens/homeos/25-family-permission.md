**一屏说清**：把「角色默认矩阵」摊开给人看——家里每一种角色能看到哪些内容、能做哪些事。行 = 16.3 的角色全集（管理员 / 成员 / 只读里的三种人），列 = 本家庭已启用的面 + 基础能力。P1 全页只读：改角色去成员治理页，改「本家庭启用哪些面」去面目录页，本页没有第二个写入口。

## 字段与校验（页面级硬规则）

- **行集合定版（本轮定版，替换原「三行」待复核）**：矩阵行 = 16.3 的角色全集，共 5 行——管理员、成员、只读（儿童，有自己的账号）、只读（无账号成员）、只读（访客）。前两个行名与成员列表徽章逐字相同；第三种人（只读档）按 16.3 的列拆成三行，行名一律带「只读」前缀，不新造第四种称谓。**每格的 ✓/— 依 16.3 逐格落，不自行加严或放松**：儿童（有账号）与访客在「管理成员」「开通」两列恒为 —（16.3 的 HomeOS 行给这两档 `—`），在「家庭动态」「日历」两列为 ✓（协作对象行与日历行给 M：可创建自己的、可勾选完成、不可删别人的）；财务列儿童与访客为 —（16.3 财务行），儿童记账由管理员逐面开放这一件事在成员页调整、不在本页；无账号成员五格全为 —，行内小字写明『不能登录，内容由代管人代为记录』。**本表行数与 16.3 的行列结构（10 行 × 5 角色 = 50 格的逐格断言矩阵）互不折算**：16.3 是逐格断言的矩阵、不是本页的行数账；本页只是把其中与用户相关的角色行与已挂载列摆出来看，**本页行数的增减不改动那张表的任何一行、任何一格与任何一句期望值（㉛）**。
- **用户可见称谓一套词**：管理员 / 成员 / 只读。本页行名、成员列表徽章、成员治理页的角色位三处同词；「成人成员」「ward」「guest」这类工程词不得出现在引号内的用户可见文案里。
- **逐成员授权优先于角色默认矩阵（本轮定版，写在图例里）**：本页画的是**角色默认档**。管理员在成员治理页收回某位家人的某个面之后，该家人对这个面的可见范围即为不可见，而本页对应角色那一格仍显示 ✓。因此：① 图例必须常驻一句用户可见文案：『这张表是角色的默认档，每个人实际能看到什么，以成员页里的授权为准』；② **不加开关、不做覆盖层界面**（P1 无逐格写路径，㉖）；③ 可判定的一致性要求：对任意（成员, 已挂载面）二元组，走查时以成员页的授权位为事实源——成员页为收回、本页同面同角色格为 ✓，两句必须同时在场（缺一即为本屏缺陷）；本页出现任何「这一格已经改了」的暗示（就地可点、状态随某个人变、给个人名字）即为越界。**本页不是逐成员结果的展示位**，它只保证默认档不骗人。
- **列口径**：列 = 本家庭已启用的面（P1 = 财务 + 日历，日历为必选面）+ 基础能力三列，**P1 实际列数 = 5 个数据列 + 1 个角色名列 = 6 列**；未启用面不进列，全量清单去面目录页看。列名与 16.3 的对应关系（工程口径）：财务列 = 16.3 财务行、日历列 = 日历行、家庭动态列 = 协作对象行、管理成员列 = HomeOS（成员/权限/设置）行、开通列 = 面配置行的**写侧**（读侧的「查看开通清单」全角色可见，不构成格子）。
- **横向滚动结论（本轮定版，不留待复核）**：**不滚动**。判据写在列数上——角色名列 88pt + 5 个等分数据列在 375pt 视口内一屏放得下，每格只有一个 ✓ 或 — 字符，无长文本；当已启用面增长到使**数据列 > 5**（即第三个面被启用）时，改为「角色名列固定 + 表体横向滚动」，且滚动区右侧必须露出下一列 ≥16pt 作为可滑提示，不得把首列一起滚走。P1 恒 6 列，因此当前形态下不出现横向滚动条。
- **两值单元格**：单元格只有 ✓ / —，不出现「部分」「条件」等第三态；条件说明写在图例里（如财务列：成员本人可写、全家可读）。
- **只读边界**：不出现父级/覆盖开关、不出现对象级 ACL；`family_overrides` / `object_acls` 在 P1 恒为空且本页不为它们渲染任何控件（16.2 ㉖）。
- **不产生 pver**：本页任何操作都不改权限版本；唯一来源是改成员角色（`PUT members/{id}/role`）与转让流程（同在成员治理页，23）。
- **服务端裁剪**：非管理员只拿服务端裁过的可见范围，客户端不自行按角色过滤。
- **受限表达二分（与 21/23/24 同一条口径）**：① 只读但有信息价值的项（本人角色那一行的全部格子）——**展示实值**，需要别人才能改的跟一句『需管理员修改』；② 纯无权限项（别人的角色行、任何调整入口）——**整行不渲染**，不是置灰、不是加锁、不是点了报错。
- **首屏失败不展示旧数据**：失败与重试期间整页只呈现失败态或骨架（本页已有该形态，与 21/23/24/26 同一形状）。
- **面启用状态不进本页**：本页不显示也不改「本家庭启用哪些面」，那是面目录页的唯一职责。

## 边界与不做

- 不做角色编辑、不做权限覆盖、不做对象级 ACL、不做邀请。
- 不做「先只读放着」的覆盖层占位：没有写路径就不渲染控件。
- 不为未出生的面补列、画灰格或写「即将上线」。
- 不做逐成员结果视图：谁的哪些范围被收回，只在成员治理页看（23）。
- 访客有效期与私密流水行级可见性不在这张表里（分别在会话校验与隐私页）。
