**一屏说清**：这是成员公开页，回答「这个人是谁」——头像、昵称、`relation`、加入时间、代管人与 TA 的动态。深链 `homecube://homeos/member/{id}` 的落点在这里；全角色只读，没有任何治理按钮，治理动作在 `homeos/family/detail`，两屏不合并。**管理员看自己这一屏时，页面上唯一多出来的一行是「换管理员请去成员治理页」的指向**（转让的判据与流程全在 23，本页不写第二份）。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 从成员列表或动态进入 | 成员头 + 加入时间/代管人/家庭 + 按面筛选的动态 4 条 |
| 无动态 | TA 没有可见动态 | 可执行空态「还没有动态」+「去家庭动态」；筛选条不渲染，被裁掉的条目不留位 |
| 代管人视角 | 当前用户是该成员的监护人 | 成员头切换为被代管成员，显示「由你代管」；代管人一行为「我」，动态标注代管写入 |
| 管理员本人视角 | 当前用户是管理员、看的是自己这一行 | 成员头带「这是你」标记；信息区下方多出 ⑦ 的转让指引行（纯文案 + 真实链接），**没有转让按钮、没有确认层**；其余内容与别的角色看到的这一屏一致 |
| 加载 | 首屏请求中 | 成员头与动态骨架，不使用 spinner 遮内容 |
| 首屏失败 | 请求非 2xx 或超时 | 整页失败态：图标 + 一句说明 + 可见错误码 + ⑧ 的「重试」；成员头、信息与动态一律不渲染，不拿上一次读到的值顶着 |

## 字段与校验（页面级硬规则）

- **全角色只读**：不出现编辑、角色、权限、移除等任何治理控件；⑦ 是一行指向治理页的文案与链接，不是控件——判据是**本页没有可写请求**。
- **转让与退出的唯一权威页不在本页**：转让管理员的发起、前置校验、确认层与失败回滚全部定义在 `homeos/family/detail`（23）；本页只在「管理员看自己」这一视角给一行指向，不复述规则、不弹层。
- **字段按 16.4 裁剪**：只展示姓名、头像、关系、加入时间、代管人；手机号、角色与权限不在这里展示。
- **动态由服务端裁剪**：按角色矩阵、字段级可见性与分级决定某条进不进列表；被裁掉的条目不返回、不占位、不显示「无权限」。
- **受限表达二分（与成员列表、成员治理页同一条口径）**：① 只读但有信息价值的家庭级值（本屏的「家庭」行：家庭名与「家庭内称谓由管理员维护」）——**显示服务端实值**，需要别人才能改时在值后跟一句『需管理员修改』的纯文案；② 该角色完全无权限的内容（被裁掉的动态、TA 不可见的面所对应的筛选项）——**整项不渲染**，不是置灰、不是加锁图标、不是点了报错。
- **代管人**：无账号被记录成员显示实际代管人；当前用户就是代管人时显示「由你代管」。
- **称谓口径**：`relation` 是家庭内称谓（爸爸 / 奶奶），缺失时回落成员名，不在本页另算一套关系。
- **首屏失败不展示旧数据**：失败与重试期间整页只呈现失败态或骨架，不回落上一次读到的成员头与动态。
- **深链落点**：`homecube://homeos/member/{id}` 落到本页；本页不承载任何治理动作。

## 边界与不做

- 本页**不做**角色、权限、面可见性与移除——这些只在 `homeos/family/detail`。
- 本页**不做**转让管理员：只给 ⑦ 那一行指向治理页的真实链接；转让的确认层与判据只有治理页那一份。
- 本页**不做**完整动态流：只给少量条目，「查看全部」进 `homeos/dynamic/index`。
- 本页**不展示**手机号、角色、权限配置与治理字段。
- 本页**不展示**在线状态或最近活跃（PRD 未定义该字段）。
- 无动态时**不显示**「无权限查看」字样，也不拿空卡占位。

## 待复核

- 加入时间的显示粒度（日期还是精确到分钟；本屏按日期）。
- 本页动态条数（原型 4 条，PRD 未写死）。
- 访客可见字段是否与成人成员一致（16.4 把姓名/头像/关系列为全家可见）。
- 无账号成员的公开页是否对访客可达（导航文档为全角色可达，本屏据此）。
- 代管人视角是否需要在成员头外再加一条代管声明（原型只在成员头给标记）。
- 「管理员看自己」这一屏的转让指引行是否保留（本轮定为保留：它把 06 与 21 的「先转让」落成一条真入口；若走查认为公开页连指向都不该有，卡点是它与 IA §4.6「全角色只读」的边界如何措辞）。
