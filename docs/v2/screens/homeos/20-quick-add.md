# 20 · 全局「＋」

| 项 | 值 |
|---|---|
| 路由 | `homeos/quick-add/index` |
| 期 | ① |
| 权限 | 全角色；可建对象随角色与面集合裁剪，无权限项不渲染 |
| 原型 | [quick-add.html](../../prototypes/quick-add.html) |
| 状态帧 | [默认](../../prototypes/quick-add.html) · [语音识别中](../../prototypes/quick-add.html?state=recording) · [拍照识别](../../prototypes/quick-add.html?state=ocr) · [识别失败](../../prototypes/quick-add.html?state=error) · [离线](../../prototypes/quick-add.html?state=offline) |

**一屏说清**：全局「＋」是一条独立路由页，不是覆盖层。它把四种输入、目标对象选择与识别结果预览放在同一页；P1 已出生的对象只有「财务 · 记账」与日历面三类（待办 / 提醒 / 日程），未出生面不出现在选择器里。取消即丢弃，识别失败即回手输，都不新增步骤。

| # | 元素 | 触发 | 反馈 | 去向 |

| ① | 取消 | 点击 | 回到进入前页面；未保存内容直接丢弃，不落草稿、不入离线队列、不产生动态 | 进入前页面（示例首页） |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 文字输入态；金额、分类、账户、日期、备注完整可编辑；原型以已输入 128.00 演示，首次进入金额为空且保存置灰 |
| 语音识别中 | 按住说话 | 波形 + 「正在识别 00:03」+ 识别到的短句；识别完成自动填入金额与分类，仍可改 |
| 拍照识别 | 拍完小票 | 小票缩略图 + 「6/6 项」；金额、分类、账户、日期、商家、备注逐字段带「已识别 · 可改」 |
| 识别失败 | OCR / 语音无结果 | 「没识别清楚，已切回手动输入」+ 重拍；表单保持同一布局，不新增确认步骤 |
| 离线 | 无网 | 顶栏下细条「当前离线 · 保存后先排队」；保存按钮改为「保存并排队」，不阻塞填写 |

## 字段与校验（页面级硬规则）

- **目标对象集合同源**：与首页矩阵、搜索分组、到期中心注册项、动态流筛选读同一份面集合（18.8）；P1 已出生的是财务面与日历面，所以候选是「财务 · 记账」+ 日历面三类 + 底座留言（定版 ㉚ §7）。
- **无权限项不显示**：不是置灰、不是点后报错；儿童与访客的可建对象按角色裁剪后再渲染。
- **取消不落草稿**：没有「保存草稿」；未提交内容不写任何业务对象，也不进离线队列。
- **识别失败回落手输**：OCR / 语音失败必须回到同一张表单，不增加确认页、不阻塞记账主流程；识别结果必须逐字段可改。
- **金额**：大于 0，最多两位小数；默认记为支出；符号在货币符号之前（如 `-¥128.00`）。
- **分类与账户必填**：默认上次使用的分类与账户；两者缺失时保存置灰，不弹二次校验弹层。
- **保存幂等**：一次提交对应一个幂等键；离线入队后重试不产生第二笔流水。
- **动态不直写**：保存成功后由事件总线产生家庭动态，客户端不写动态、也不等待动态返回。
- **语音与拍照权限**：系统权限被拒时直接回落到文字输入，不连续弹权限墙。

## 边界与不做

- **不做** AI 自动归类（P6）：P1 目标面由用户手选，不显示「AI 自动分类」或推荐结果。
- **不做**批量记账、一次多笔、混合类型录入；一次只处理一个对象。
- **不做**模板管理：模板入口只负责带入，模板的增删改在财务面设置里。
- **不在本页做**待办 / 提醒 / 日程的字段录入：选中日历面目标即进该面对象的录入页（`calendar/todo/create`、`calendar/reminder/create`），本页不复制它们的字段与校验。
- **不做**草稿箱、分享、语音播报、连续记账；连续记账在财务面内的「记一笔」完成。
- **不出现**未出生面或家庭未启用面，也不以「即将上线」占位。
- **不在**本页复制账户管理、分类管理；这些属于财务面。

## 待复核

- 保存成功后回首页还是留在本页继续记，PRD 未写死；本页按「回首页并刷新动态」处理，连续记账走财务面。
- 模板模式在 P1 是否已有默认模板未写明；原型只用提示说明「模板管理在财务面」，不展示空模板列表。
- 语音单次时长上限与小票单张限制未定版（19.3）；原型按一次一句、一张小票演示。
- 「日历 · 日程」在 P1 的 9 页路由位里没有独立的新建页（实建 9 = 日历 2 + 待办 4 + 提醒 3），本页把它指向到期中心的日格入口承接新建，是否补独立路由位待定（见 `screens/calendar/10-calendar.md` 待复核）。
- 日期默认今天且原型不可改；补记日期是否在「＋」内开放，待与财务面记一笔的字段口径对齐。
