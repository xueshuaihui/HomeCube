# 20 · 全局「＋」

| 项 | 值 |
|---|---|
| 路由 | `homeos/quick-add/index` |
| 期 | ① |
| 权限 | 全角色；可建对象随角色与面集合裁剪，无权限项不渲染 |
| 原型 | [quick-add.html](../../prototypes/quick-add.html) |
| 状态帧 | [默认](../../prototypes/quick-add.html) · [语音识别中](../../prototypes/quick-add.html?state=recording) · [拍照识别](../../prototypes/quick-add.html?state=ocr) · [识别失败](../../prototypes/quick-add.html?state=error) · [离线](../../prototypes/quick-add.html?state=offline) · [取消确认](../../prototypes/quick-add.html?state=discard) |

**一屏说清**：全局「＋」是一条独立路由页，不是覆盖层。本页只放三样东西：四种输入、一句话速记（含识别结果预览）与目标对象选择；选定目标即带着这里写好的内容进该对象的建页——日程 / 待办 / 提醒进日历面各自的建页，记账进财务面的记一笔页，留言进留言板（定版 ㉛）。本页不承载任何对象的表单与字段校验；有内容时点取消必过一层「放弃？」确认，不再静默丢弃。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 文字输入态：一段速记输入（原型以已输入「晚饭 晚风餐厅 128」演示）+ 识别预览 + 五项目标对象；无金额键盘、无分类与账户表单（那些属于 `finance/tx/create`） |
| 语音识别中 | 按住说话 | 波形 + 「正在识别 00:03」+ 识别到的短句；完成自动填入速记线，仍可改 |
| 拍照识别 | 拍完小票 | 小票缩略图 + 「6/6 项」；金额与商家并入速记线，逐项确认在目标建页里做 |
| 识别失败 | OCR / 语音无结果 | 「没识别清楚，已切回手动输入」+ 重拍；速记线保持同一布局，不新增确认步骤 |

## 字段与校验（页面级硬规则）

- **目标对象集合同源**：与首页矩阵、搜索分组、到期中心注册项、动态流筛选读同一份面集合（18.8）；候选 = 财务 · 记一笔 + 日历面三类（待办 / 提醒 / 日程）+ 底座留言（定版 ㉚ §7、㉛）。无权限项不显示、不置灰；未启用与未出生的面不出现也不占位。
- **单选项选择器退化**：P1 只有财务与日历两个面——日历必选恒在、财务是唯一可选面，本页**不设「先选面」中间层**：目标对象列表直接列可建的对象、点了就进对应建页；任何只有一个选项的选择器一律不渲染。
- **落点全是建页（定版 ㉛）**：待办 → `calendar/todo/create`、提醒 → `calendar/reminder/create`、日程 → `calendar/calendar/create`（原「日程落到期中心日格」的写法随 ㉛ 作废——那是只读承接位，不是建页）；财务 → `finance/tx/create`（财务面的记一笔页；原「财务 · 记账留在本页填表」的写法一并作废，本页不再复制它的字段与校验）；留言 → `homeos/message/board`。保存成功后一律 `redirectTo` 该对象的详情页（18.4、18.7 第 6 条）。
- **三对象一句人话**：三个日历对象各配一行用户可见文案——日程：「哪天要发生的事」；待办：「谁要做、做完打勾」；提醒：「到点提示你一下」。一句一个概念，只帮用户选对，不解释怎么填；财务与留言也各配一句：「花了多少、买了什么」「跟家人说一声」。
- **取消有两种**：内容为空直接返回进入前页面；**有内容必须过一层「放弃？」确认**，不允许静默丢弃。「放弃」不写任何业务对象、不进离线队列，返回进入前页面后焦点落底栏「＋」；「继续编辑」关闭确认并把焦点交回速记输入框；「存为待办」是本页内容唯一的落对象路径，草稿落日历面 `calendar_todo`（18.4）。
- **内容带进目标页**：速记内容与识别结果作为预填进入目标建页，逐项可改；本页不校验金额必填、不校验分类与账户——字段校验归目标建页所有。
- **识别失败回落手输**：OCR / 语音失败必须回到同一页速记线，不增加确认页、不阻塞主流程；识别结果必须逐字段可改。
- **金额口径**：识别到的金额只做预览展示，显示 `-¥128.00`（符号在货币符号之前）；正式金额校验在财务面的记一笔页完成。
- **语音与拍照权限**：系统权限被拒时直接回落到文字输入，不连续弹权限墙。
- **动态不直写**：保存成功后由事件总线产生家庭动态；本页与目标建页都不写动态、也不等待动态返回。

## 边界与不做

- **不做** AI 自动归类（P6）：P1 目标由用户手选，不显示「AI 自动分类」或推荐结果。
- **不做**批量记账、一次多笔、混合类型录入；一次只处理一个对象。
- **不做**模板管理：模板入口只负责带入，模板的增删改在财务面设置里。
- **不承载**任何对象的表单与字段录入：记账表单属于 `finance/tx/create`，三类日历对象属于各自建页（定版 ㉛），本页不复制它们的字段、默认值与校验。
- **不设**「先选面」中间层，也不渲染只有一个选项的选择器。
- **不做**草稿箱：「存为待办」之外，本页不留任何内容；放弃即清空。
- **不出现**未出生面或家庭未启用面，也不以「即将上线」占位。
- **不在**本页复制账户管理、分类管理；这些属于财务面。

## 待复核

- 「存为待办」由谁在 18.4 建卡验收：草稿预填进 `calendar/todo/create` 时带不带「完成日期」默认值，按 `screens/calendar/13-todo-create.md` 的必填口径执行；两卡若冲突，以日历面建卡为准回写本页。
- 预填字段映射（速记文本与识别金额 → 各建页的哪个字段）PRD 未写死；各建页交付时按自己的卡回写本页 ⑤ 行。
- 模板模式在 P1 是否已有默认模板未写明；原型只用提示说明「模板管理在财务面」，不展示空模板列表。
- 语音单次时长上限与小票单张限制未定版（19.3）；原型按一次一句、一张小票演示。
- 「日历 · 日程」的落点 `calendar/calendar/create` 原型页尚未交付（属日历面批次），原型内该选项以去向说明演示；该页落地后把原型入口换成真实跳转即可，卡内口径不需要再改。
