## 字段与校验（页面级硬规则）

- 主题值只能是 `system` / `light` / `dark`；存本机 `hc-proto-theme`，不同步账号、不进数据导出（18.9）。
- **时区与币种是锁定值（本轮定版）**：两者在家庭创建时确定（3.6 `Family` 字段；3.7 `POST /api/homeos/families` 收名称、时区、币种、头像），PRD 全文没有它们的修改接口或改值路径，P1 定为不可改——本页只做「锁定值展示 + 说明文案」，不出选择器、不出编辑入口。锁定理由写进说明文案：时区决定家庭「今天」的边界，到期时间、提醒时点、连续天数与报表时间窗都按它计算（3.4.8、4.5.1、10.5.3），改动会整体改写历史报表；币种决定历史金额的展示语义，换币不改写存量数字。
- 日期格式是家庭级：写入口在本页选择层，仅管理员可写；保存后即时生效（本页立即重绘，其他界面在下次渲染时按新格式），不需要用户退出重进；非管理员不隐藏行，避免「不知道家庭当前格式」。
- 家庭切换后币种、时区与日期格式按新家庭重载；未返回前不猜默认值，防止串值。
- 免打扰只控本机的声音与横幅；通知是否产生、分型、未读红点与计数一律归底座通知口径（3.4.2 / 18.1），本页不定义投递行为。**时段分两级（3.4.8 分级）：家庭默认值由成人成员维护、写入口是本层内的「设为家庭默认」（⑩，走 `PUT /api/homeos/settings` 并记入家庭操作记录）；本机值由本人维护并可覆盖家庭默认（⑨，不上服务端）；冲突时本机优先**——两者保存即生效，跨天时段按结束时间落在次日。免打扰本质是设备级，因此「家庭级 · 成人可改」限的是默认值、不是强制下发给每台设备；**清除本机覆盖后立即回落当前家庭默认，不回落本机旧值**（3.4.8 Q12 第 ② 条）。
- 语言 P1 仅简体中文，不写「切换立即生效」这类尚未交付的承诺。

## 边界与不做

- 不做自定义皮肤与主色选择器；不做页面级主题覆盖；不做省电模式自动深色。
- 不在本页做成员角色、权限与面配置编辑。
- 不提供时区与币种的修改或代管入口；P1 唯一的更换路径是创建新家庭，改值诉求走「联系家庭管理员」。
