## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入页面 | 主题＝跟随系统；时区 Asia/Shanghai；币种 CNY；日期格式 2026-10-06；免打扰开、22:00–07:00 |
| 暗色 | 点「暗」或 `?state=dark` | 全页切暗色令牌，主题项选中「暗」，主题卡内提示已生效；组件与文案不换 |
| 非管理员 | 成人 / 儿童 / 访客 | 币种与日期格式整行置灰、显示锁图标与「需管理员」，底部说明只读原因；个人项仍可写 |
| 加载 | 拉取偏好中 | 骨架屏贴合分组形状，不用 spinner 遮内容 |

## 字段与校验（页面级硬规则）

- 主题值只能是 `system` / `light` / `dark`；存本机 `hc-proto-theme`，不同步账号、不进数据导出（18.9）。
- 币种与日期格式是家庭级：写入口只在管理员视图；非管理员不隐藏行，避免「不知道家庭当前策略」。
- 家庭切换后币种与日期格式按新家庭重载；未返回前不猜默认值，防止串值。
- 免打扰只控声音与横幅；未读红点、角标与站内信不受影响（3.4.2 / 18.1）。
- 语言 P1 仅简体中文，不写「切换立即生效」这类尚未交付的承诺。

## 边界与不做

- 不做自定义皮肤与主色选择器；不做页面级主题覆盖；不做省电模式自动深色。
- 不在本页做成员角色、权限与面配置编辑。
- 不提供家庭级设置的代管入口；非管理员只能联系管理员。
