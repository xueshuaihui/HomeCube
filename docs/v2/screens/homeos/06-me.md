# 06 · 我的

| 项 | 值 |
|---|---|
| 路由 | `homeos/me/index` |
| 期 | ① |
| 权限 | 全角色；管理员多出「开通更多面」与「权限与角色」两项 |
| 原型 | [me.html](../../prototypes/me.html) |
| 状态帧 | [管理员](../../prototypes/me.html) · [成人成员](../../prototypes/me.html?state=member) |

**一屏说清**：账号、家庭、开通更多面、设置、时间与提醒、数据、隐私、帮助八组入口集中在这里；「开通更多面」是面的唯一写入口，只对管理员渲染**可选面**的开关（日历面是必选面，不渲染开关）。定版 ㉚ 后本页不承担提醒 / 待办 / 日程的对象管理：它们归日历面；「时间与提醒」是指向日历面到期中心的**定向深链**（`calendar/calendar/index`），不是面入口、不渲染面切换器。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 账号区 | 点击 | 头像与昵称仅本人可改；手机号显示掩码，改号需旧号验证 | 个人资料（后续批次） |
| ② | 家庭与成员 | 点击 | 管理员可写、其余角色只读；显示成员数与待接受邀请数 | 成员管理（第 4 批） |
| ③ | 开通更多面 | 点击 | 只对管理员渲染；目录三态：已启用 / 可开通 / 即将上线 | 面目录（第 4 批） |
| ④ | 外观主题 | 点击 | 上拉三选一：跟随系统 / 亮 / 暗；切换即时生效并持久化 | 弹层，留在本页 |
| ⑤ | 安全与设备锁 | 点击 | 显示当前开关状态；开启后进入 PIN 设置 | 设备锁页（本批） |
| ⑥ | 帮助与关于 | 点击 | 显示版本号；登录后静默检查更新，可跳过；只有 `min_compat` 高于当前版本才强制 | 关于页（第 4 批） |
| ⑦ | 隐私 | 点击 | L2/L3 可见性开关与删除请求；家庭级开关仅管理员可写 | 隐私页（第 4 批） |
| ⑧ | 数据 | 点击 | 导出的范围与格式在这里选；导出的是筛选后的全量，不是当前页 | 数据页（第 4 批） |
| ⑨ | 时间与提醒 | 点击 | 直达日历面到期中心，深链不改变当前面上下文；不渲染面切换器、不消费 `faces[]` 全集 | `calendar/calendar/index`（日历面） |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 管理员 | 当前角色 owner | 显示「开通更多面」「权限与角色」两项 |
| 成人成员 | 当前角色 member | 上述两项整行不渲染（不是置灰） |
| 主题切换 | 点击亮/暗 | 全页即时换令牌；无闪烁、无局部未换色 |
| 版本检查失败 | 静默检查请求失败 | 不打断、不弹窗，仅在关于页显示「检查失败，可重试」 |

## 字段与校验

- 角色与权限只读展示，编辑入口在成员治理页，不在本页。
- 「开通更多面」的开关是面的唯一写入口；权限页不得重复提供面挂载开关。
- 主题是本地偏好，不依赖家庭权限。
- 「时间与提醒」是 IA §1.3 第 13 条的定向深链入口（㉚ 后只加不减），本页不因此渲染面切换器；时区与免打扰等偏好仍在设置页。

## 边界与不做

- 本页**不做**权限编辑：P1 的权限页只是角色默认矩阵的只读视图。
- 本页**不做**退出家庭、转让管理员（在成员治理页）。
- 本页**不做**日历面对象的列表或设置（日程 / 待办 / 提醒与周期规则见五章，入口在日历面）。
- 「数据」与「隐私」是两个独立入口，不合并。
- 非管理员看不到「开通更多面」，因此也不存在「点进去才发现不能改」的情况。
