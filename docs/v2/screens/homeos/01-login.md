# 01 · 登录

| 项 | 值 |
|---|---|
| 路由 | `homeos/auth/login` |
| 期 | ① |
| 权限 | 未登录（冷启动无 token 或 refresh 失效） |
| 原型 | [login.html](../../prototypes/login.html) |
| 状态帧 | [默认](../../prototypes/login.html) · [验证码错误](../../prototypes/login.html?state=error) · [登录中](../../prototypes/login.html?state=loading) · [邀请挂起·待回跳](../../prototypes/login.html?state=invite) |

**一屏说清**：手机号 + 验证码进入。没有独立注册页——未注册的手机号自动建号。登录成功后的分流**不是「有没有家庭」的二分**：先消费未登录时挂起的邀请上下文（有则直接去加入家庭），没有挂起才按有无家庭分流。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 手机号 | 输入 | 允许带空格输入，提交前去掉空格；不足 11 位时登录按钮保持可点，点击后提示而不是置灰 | — |
| ② | 获取验证码 | 点击 | 按钮变 60s 倒计时并禁用；发送失败立即恢复可点并提示原因，不静默 | — |
| ③ | 登录 | 点击 | 未勾选协议 → 页内提示并中止；已勾选 → 按钮进入加载态；**存在未消费的邀请上下文时登录按钮文案是「登录并继续加入」** | **有未消费的邀请上下文 → 加入家庭（03），优先于家庭判据**；无挂起上下文时：有家庭 → 首页；无家庭 → 创建家庭 |
| ④ | 协议勾选 | 点击 | 勾选状态本次启动内保留；协议正文在 P1 末附加门禁前显示「待定版」 | 协议页（后续批次） |
| ⑤ | 语音验证码 | 点击 | 60 秒内未收到短信时可切换；防刷口径与短信一致 | 留在本页 |
| ⑥ | 邀请待回跳提示条 | 未登录时经邀请链接进来（挂起生效即呈现） | 品牌区下方一条不可关闭的提示条，用户可见文案：『家人邀请你加入 · 登录后继续』；不可点、不跳走，只作告知 | 留在本页；登录成功后自动回跳 03 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 冷启动 | 手机号为空、验证码为空、登录可点 |
| 发送倒计时 | 点击获取验证码 | 按钮显示 `60s` 递减，期间不可重复点击 |
| 验证码错误 | 提交后校验失败 | 验证码输入框转错误样式，下方红字「验证码已过期，请重新获取」；停留在本页 |
| 登录中 | 点击登录 | 按钮内联 loading，禁止二次提交；页面其余部分可读不可操作 |
| 限流 | 短时间重复获取验证码 | 按钮恢复可点并提示稍后再试，不进入倒计时 |
| 网络失败 | 请求超时/断网 | 顶部或页内提示可重试；已填内容不丢 |
| 邀请挂起·待回跳 | 未登录用户点邀请链接进来（深链冷启动） | 提示条 ⑥ + 登录按钮文案「登录并继续加入」；本机暂存 `{邀请码, 家庭名, 邀请过期时间, 来源深链}` 四项，**不在这页做任何加入动作** |
| 回跳失败 | 登录后回跳 03 的链路异常，或邀请在挂起期间已撤销/过期 | **一律落 03，不落 02**：已撤销/过期 → 03 的「邀请失效」态；链路异常 → 03 的输入态并保留已挂起的邀请码。任何情况下都不因回跳失败回落到「创建家庭」，那会建出重复家庭 |

## 字段与校验

| 字段 | 规则 | 失败文案 |
|---|---|---|
| 手机号 | 11 位数字（去空格后） | 「请输入正确的手机号」 |
| 验证码 | 6 位数字 | 「请输入 6 位验证码」 |
| 协议 | 必须勾选 | 「请先阅读并同意用户协议与隐私政策」 |
| 邀请上下文（挂起） | 只存本机、有效期 = 邀请自身的有效期（7 天，与 03 同一个数，不在本页另立第二个时限）、**只消费一次**：登录成功即从本机清除，加入动作与邀请码本身改由 03 持有；换手机号登录即刻作废 | 用户可见文案：『邀请已过期，请请家人重新分享』 |

## 边界与不做

- **不做注册页**：未注册手机号自动建号，这是与「注册表单」最重要的差别。
- **不做密码登录、第三方登录**：P1 只有短信验证码。
- **分流判据**：服务端返回的家庭列表只在「没有未消费的邀请上下文」时才做二分；有挂起上下文一律优先落 03（03 同步声明自己是回跳落点）。客户端不自行判断有没有家庭，但**是否处于回跳分支由本机挂起的上下文决定**，这条判据在 01。
- 协议默认勾选是**原型暂定**，若合规要求改为不默认勾选，只改一处初始状态。
