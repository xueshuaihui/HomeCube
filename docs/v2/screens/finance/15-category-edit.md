**一屏说清**：本页只改「展示四件套 + 一个状态」——改名、换图标、换颜色、停用；删除与合并另设入口且**只有管理员能做**。三条硬规则：**停用可逆，历史流水照常统计**；**预置分类不可删除**；**被流水引用的分类拒绝删除，只引导改用停用**。成人成员看不到删除与合并，改名等照常保存。

## 字段与校验（页面级硬规则）

- **可改**：名称、图标、颜色、启用状态。**不可改**：父级、类型、所属家庭；要调层级只能停用后另建。
- **重名范围**：同一父级 + 同一类型；只报错，不自动改名。
- **停用**：停用后不出现在记账选择器，**历史流水、报表、筛选、预算统计一律照常**；恢复后立即可选；一级停用后其二级一起不可选，不逐个改状态。
- **删除**：预置分类恒不可删；自定义分类只要被流水引用就拒绝删除，弹层必须显示「将影响 N 笔流水」（N 来自服务端）并引导停用；**没有物理删除，也没有「仍然删除」**。
- **合并**：仅管理员；目标限同类型、未停用、非自身；合并后源分类自动停用，流水改挂目标；有二级时二级一并停用，是否改挂目标父亲见「待复核」。
- **保存冲突**：提交时带上打开页面时的记录；若已变化，必须由用户选「保留对方 / 用我的」，页面文案不出现「覆盖」「版本号」。
- **金额**：负号在货币符号之前（`-¥600.00`）；弹层里的笔数与金额取本自然月，与服务端一致。

## 边界与不做

- 不做「删除并转移流水」，也不做「删除二级」的单独入口（随父级停用）。
- 不在本页排序（排序是独立页，顺序全家共用一处）。
- 不让改父级或类型，避免历史归属变化与迁移。
- 停用、改名都不触发 HomeOS 推送。

## 待复核

- 有二级的一级被删除或合并时，二级是「一并停用」还是「改挂到目标」：本原型按**一并停用**处理，需 PRD 明确。
- 合并是否允许跨父级（如把二级并入另一个一级）：本原型只列同类型的一级目标。
- 编辑页图标集为 12 枚常用子集，全集在新建页（18 枚），数量差异是否要统一。
