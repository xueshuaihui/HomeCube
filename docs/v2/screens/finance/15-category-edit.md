| 项 | 值 |
|---|---|
| 路由 | `finance/category/edit` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员；成人成员无写权（直连返回 403，页面不渲染表单） |
| 原型 | [finance-category-edit.html](../../prototypes/finance-category-edit.html) |
| 状态帧 | [默认](../../prototypes/finance-category-edit.html) · [停用确认](../../prototypes/finance-category-edit.html?state=disable-confirm) · [重名](../../prototypes/finance-category-edit.html?state=error) |

**一屏说清**：本页只改「展示四件套 + 一个状态」：改名、换图标、换颜色、停用。核心规则两条——**停用走弹层并明说「已用该分类的历史流水不受影响」**；**预置分类不可删除**，删除入口恒为禁用。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 丢改动回分类管理并重新展开原父级 | `finance/category/index` |
| ② | 名称 | 输入 | 1-10 字符；与同级重名时名称框转错误态并给行内错误，保存不生效；改名不改历史（历史跟分类 id 走） | 留在本页 |
| ③ | 图标 | 点某枚图标 | 12 枚常用图标就地切换，选中项高亮；只影响展示，不改 id 与归属 | 留在本页 |
| ④ | 颜色 | 点色块 | 八枚令牌色任选，不提供色值输入；换色同步到记账选择器、报表图例与筛选 chips 的图标底色 | 留在本页 |
| ⑤ | 停用开关 | 拨到停用 | **不直接生效**，先弹确认层，写明「已用该分类的历史流水不受影响」与「随时可以重新启用」；取消则开关回弹 | 弹层 |
| ⑥ | 删除 | 点击 | 预置分类恒为禁用，附「预置分类不可删除」；自定义分类被流水引用时同样禁用并提示改用停用 | 留在本页 |
| ⑦ | 保存 | 点击 | 带 `version` 提交；409 弹「这条记录已被修改」并给「查看最新 / 覆盖」两条出路；成功后回列表 | `finance/category/index` |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 名称预填、父级只读「无（一级分类）· 不可改」、图标与颜色为当前值、状态「启用中」、删除禁用 |
| 停用确认 | 点停用开关 / 深链 | 底部弹层：标题「停用「餐饮」？」，正文点明历史流水不受影响、报表与筛选照常计入、可逆；给「确认停用」与「取消」 |
| 重名 | 名称改成同级已有名字 | 名称框错误态 + 行内错误；保存不生效，其余字段的改动保留在页面上 |

## 字段与校验（页面级硬规则）

- **可改字段**：`name`、`icon`、`color`、`is_active`。**不可改**：`parent_id`、`type`、`family_id`。
- **重名范围**：同父级 + 同类型；重名只报错、不做自动改名。
- **停用语义**：`is_active=false` 后不再出现在记账与编辑的选择器里；**历史流水、报表、筛选、预算统计一律照常**；停用可逆，恢复后立即可选（19.3#10 五项断言）。
- **删除语义**：预置项恒不可删；自定义项被流水引用时拒绝删除并提示改用停用——分类与账户都**无物理删除**（4.5.9）。
- **乐观锁**：`PUT /api/finance/categories/{id}` 带 `version`；409 时不得静默覆盖，必须由用户选「查看最新 / 覆盖」。
- **金额展示**：弹层里回显该分类本月笔数与金额，负号在货币符号之前（`-¥2,486.40`）。

## 边界与不做

- 不让改父级或类型（会动到历史归属与选择器位置，M1 不做迁移）。
- 不做「删除并转移流水」。
- 不在本页做排序（排序是独立页，`sort_order` 全家共用一处）。
- 停用不写审计外的任何通知，也不触发 HomeOS 推送。

## 待复核

- 有二级的一级分类改名时，是否提示「二级不受影响」：本原型不提示（二级跟父级 id 走）。
- 停用后是否要把该分类的二级一并停用：本原型按**父级停用即其二级一起不可选**理解，不逐个写 `is_active`。
- 图标集 12 枚是「编辑页常用子集」，全集在新建页（18 枚）。
