# 04 · 单笔详情

| 项 | 值 |
|---|---|
| 路由 | `finance/tx/detail` |

| 权限 | 家庭流水全员可读；私密行仅作者与管理员可读（无权限读者拿不到这一行）；编辑限作者与管理员；儿童、无账号成员、访客不进财务面（16.3 财务行、16.4） |
| 原型 | [finance-tx-detail.html](../../prototypes/finance-tx-detail.html) |

**一屏说清**：单笔详情是流水行与报表下钻的共同落点（二级页，navbar 返回），只读展示一笔的全部事实：金额大标题、分类 / 账户 / 成员 / 时间 / 账本 / 标签、备注、附件缩略图，以及**来源标注**与**转账的两笔关系**。三条硬口径在这里收口：转账两笔必须能互相跳转；附件只预览不下发新数据；私密行对无权限读者**连行都不渲染**，不展示金额、分类、成员、时间与附件，也不给编辑删除入口。底部另有「再记一笔」，方便连着记。

## 字段与硬规则

- **金额**：以「分」整数存储、按家庭币种展示；负号在货币符号之前（`-¥128.00`）；转账不带正负收支语义，不计入收支小计与预算。
- **转账两笔**：转出与转入一起生成，详情必须显示配对关系并可互相跳转；编辑与删除都一起生效，不提供单边删除。
- **来源只读**：周期规则自动入账时标「来自周期规则」并给规则入口；手动记账标「手动记一笔」。来源不改归属、不在本页改规则。
- **附件**：最多 3 张、单张 ≤5MB、只收 jpg / png / webp；附件归属家庭文件，流水只引用它，预览不产生新的业务数据。
- **私密行**：仅作者与管理员可读；无权限读者拿不到这一行，深链进来只看到「不在你的可见范围」，页内不出现金额、分类、成员、时间、备注与附件，也不出现「无权限」这类报错口吻。私密行仍计入家庭合计，只从 AA 分摊与跨面归集里排除。
- **账本口径**：账本是报表与归集分组、不是隔离域；详情页文案不得出现「私有空间」「成员看不到」等隔离措辞。
- **只读与反馈**：详情页不提供内联编辑，任何修改都走编辑页；保存反馈只在流水列表出现一次，本页不重复弹。
- **时间窗**：删除与恢复会改变对应时间窗的预算与统计（恢复说明在回收站层），详情页只展示这一笔的归属时间，不自行推算汇总。

## 边界与不做

- 不做内联编辑与就地改金额；不把「编辑」做成弹层。
- 不做单边删除转账，也不提供「解除配对 / 重新配对」。
- 不展示私密行的任何具体值（含金额、分类、备注、附件、标签与作者），只说明可见范围。
- 不做修改历史与版本回溯视图；只显示最后修改人与时间。
- 不做附件上传与重拍（在编辑页与记一笔），本页只预览。
- 「再记一笔」只打开空白新建页，不复制本笔金额、分类与标签，避免误记成两笔。

## 待复核

- 来源标注是否还需覆盖账单（`finance-bill/*`，M1 建对象但页面在 ②），本批只做了周期规则与手动两类。
- 附件是否允许下载原图未写明；原型给了「下载」入口并注明附件归属家庭文件。
- 转账详情里是否允许改「从 / 到」账户未写明；原型在编辑页也不开放改账户方向，只允许改金额、时间、备注等字段。
- 深链指向私密流水时，是显示「不在你的可见范围」还是统一显示「已不存在」以少泄露存在性，PRD 未定；本批按前者，且不带任何行内事实。
