# 04 · 单笔详情

| 项 | 值 |
|---|---|
| 路由 | `finance/tx/detail` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 家庭流水全员可读；私密行仅作者与管理员可读（他人视角只看到占位）；编辑限作者与管理员；儿童、无账号成员、访客不进财务面（16.3 财务行、16.4） |
| 原型 | [finance-tx-detail.html](../../prototypes/finance-tx-detail.html) |
| 状态帧 | [默认](../../prototypes/finance-tx-detail.html) · [成对转账](../../prototypes/finance-tx-detail.html?state=transfer) · [附件预览](../../prototypes/finance-tx-detail.html?state=attachments) · [他人看私密](../../prototypes/finance-tx-detail.html?state=private-other) |

**一屏说清**：单笔详情是流水行与报表下钻的共同落点（二级页，navbar 返回），只读展示一笔的全部事实：金额大标题、分类 / 账户 / 成员 / 时间 / 账本 / 标签、备注、附件缩略图，以及**来源标注**与**转账的成对关系**。三条硬口径在这里收口：转账两笔必须能互相跳转；附件只预览不下发新数据；私密行在他人视角下金额与分类被遮住为「私密」，编辑与删除入口整块不出现。

## 字段与校验（页面级硬规则）

- **金额**：以「分」整数存储、按家庭币种展示；负号在货币符号之前（`-¥128.00`）；转账不带正负收支语义，不计入收支小计与预算。
- **转账成对**：两笔同 `transfer_group`，详情必须显示配对关系并可互相跳转；编辑与删除都成对生效，不提供单边删除。
- **来源只读**：`generated_by` 为周期规则时标「来自周期规则」并给规则入口；手动记账标「手动记一笔」。来源不改归属、不在本页改规则。
- **附件**：最多 3 张、单张 ≤5MB、只收 jpg / png / webp；附件归属家庭文件，流水只存 `file_id` 引用，预览不产生新的业务数据。
- **私密行**：仅作者与管理员可读；他人视角下金额、分类、备注、附件一律不下发，页内只留「私密」占位与可见范围说明；不显示「无权限查看」这类报错文案。
- **账本口径**：账本是报表与归集分组、不是隔离域；详情页的文案不得出现「私有空间」「成员看不到」等隔离措辞。
- **版本**：页内显示当前 `version` 与最后修改人；编辑与删除都按该版本校验，冲突回编辑页的 409 层处理。
- **一屏只读**：详情页不提供内联编辑，任何修改都走编辑页；返回不丢数据、也不产生写请求。

## 边界与不做

- 不做内联编辑与就地改金额；不把「编辑」做成弹层。
- 不做单边删除转账，也不提供「解除配对 / 重新配对」。
- 不展示私密行的任何具体值（含金额、分类、备注、附件与标签），只显示可读的成员与时间。
- 不做修改历史与版本回溯视图；只显示当前版本号与最后修改人。
- 不做附件上传与重拍（在编辑页与记一笔），本页只预览。
- 不做「复制一笔」「再记一笔」快捷入口，避免绕过幂等键与预算累计。

## 待复核

- 来源标注是否还需覆盖账单（`finance-bill/*`，M1 建对象但页面在 ②），本批只做了周期规则与手动两类。
- 他人看私密时「你的角色 · 成人成员 · 不可读」的措辞是原型假设，PRD 只规定「仅作者与管理员可读」。
- 附件是否允许下载原图未写明；原型给了「下载」入口并注明附件归属家庭文件。
- 转账详情里是否允许改「从 / 到」账户未写明；原型在编辑页也不开放改账户方向，只允许改金额、时间、备注等字段。
