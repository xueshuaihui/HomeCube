**一屏说清**：新建目标填五件事——**名称**、**目标金额**、**期限**、**账户**、可选的**自动存入规则**（每月固定日、每次金额）。自动存入是一条周期记账规则：到日在账本里生成一条记录，**仅在记账层面记录，不会真实划转资金**，不对接银行、支付宝或微信，也不会自动扣款。保存后目标立即出现在列表；开启规则时首条记录从下个固定日生成，不补发过去月份，到期也不自动关闭或归档。

## 字段与校验（页面级硬规则）

- **名称**：去首尾空格后 1–20 字；允许同名；全家可见；不参与报表归集、不写进提醒文案。
- **目标金额**：以「分」整数存储，`> 0`；只算进度与预计达成，**不锁定账户余额、不占用预算、不产生流水**；编辑时不得低于已存金额。
- **期限**：可选；填了必须 ≥ 今天（家庭时区）；用于建议月存额与到期前 30 天提醒；到期不自动关闭、不自动归档，也不阻止继续存入。
- **账户**：必选一个未归档账户；存入与自动存入都记到该账户；账户只决定记账归属，**不代表真实资金通道**；归档账户不能作为新记录的账户，但历史记录保留。
- **自动存入规则**：`day` 1–28、`amount` 以分存储且 `> 0`；每家庭每个目标至多一条规则；按每月同日生成一条记录；**首条从下个固定日生成，不补发过去月份**；改规则只影响之后月份，不重写已生成记录；目标达成或归档时自动停用。
- **预计达成**：`剩余金额 ÷ 每次金额`，按月向上取整，从下个固定日起算；期限与预计不一致时仍照实显示，不粉饰。
- **合规说明**：整块文案常驻，不随开关显隐；必须写明「仅在记账层面记录、不会真实划转资金、不对接银行 / 支付宝 / 微信、不自动扣款」。
- **保存**：目标与规则在同一事务写入；开启规则时只生成规则，不立即生成首条记录；成功回列表，toast 标明「自动存入已开启（仅记账）」。
- **离线**：保存先排队并带幂等键；离线时不在本地预生成首条自动存入记录，联网后按固定日补生成一次。
- **金额格式**：币种符号在数字前，千分位 + 两位小数、等宽数字。

## 边界与不做

- 不提供「初始已存金额」；新目标从 0 起，首笔存入在详情页完成。
- 不做真实资金划转、银行或支付通道对接、自动扣款。
- 不做每日 / 每周 / 按笔凑整的规则，也不做多条规则叠加。
- 不做按成员拆分的共同目标出资、份额与结算；本页不设共享 / 私密开关。
- 不做目标图标选择、模板、从历史流水推荐目标金额。
- 不做到期自动关闭、自动归档、自动放弃。
- 不做利息、收益或达成概率预测。
- 不提供删除；误建目标在详情页归档。

## 待复核

- **初始已存金额**：原型新目标从 0 起；用户很可能在新建时已有部分存款，是否需要补一个「已存」字段（会同时生成一条存入记录）需定版。
- **期限是否必填**：原型按可选处理（帮助句写「可不填」），但任务把它列为必填项之一；若必填，空态与校验要补一条。
- **首条自动存入的时点**：原型按「下个固定日」处理，若当天就是固定日，是否当月生成还是顺延到下月未定；不能补发过去月份。
- **固定日 1–28**：为避开月末缺日而限制，PRD 未写；若允许 29–31 并取当月最后一天，需改校验与文案。
- **账户是否必选**：原型默认带一个账户并按必选处理；若允许先不选、存入时再选，需要补空账户态。
- **家庭共同目标的创建开关**：PRD 提到家庭共同目标，本页未给共享 / 私密选择，原型按家庭可见处理。
- **成人成员权限**：16.3 为「M 写」，原型允许成人新建目标；是否需要限制为「仅自己创建的可改」待定。
