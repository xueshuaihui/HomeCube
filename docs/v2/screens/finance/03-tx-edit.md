**一屏说清**：编辑流水与记一笔同构（二级页，navbar 返回），区别是**所有字段预填原值**、**右上角换成「删除」**、底部是「保存修改」。支出 / 收入 / 转账可互改，改类型、换账户或改金额时先给**余额影响预览**；借入 / 借出 / 报销由对应对象联动生成，这里不能改。保存成功**回流水列表并只提示一次「已保存」**；家人同时在改时先弹层让你选，不静默覆盖。编辑只改这一笔——由周期规则自动入账的流水，改完也不会回改规则。

## 字段与硬规则

- **冲突处置**：并排展示「我这一版 / 家里最新」，只给「看家里的最新 / 保存我这一版」；不自动合并、不按时间戳决胜；同一笔连弹不超过 2 次，仍冲突则提示稍后再试。用户文案不出现版本号、状态码等工程词。
- **金额型不接受静默覆盖**：冲突时不得后台重试写入，必须由用户显式选一条出路（3.4.4 对象分类表）。
- **编辑不回改来源**：由周期规则自动入账的流水，编辑只改这一笔；规则本身只读，下月仍照原样入账。
- **类型转换**：支出 / 收入 / 转账可互改，改前必须给出余额影响预览；借入 / 借出 / 报销由对应对象联动生成，普通交易不得转成这三类。
- **金额与分类**：以「分」存储、按家庭币种显示，负号在货币符号之前；改金额与分类会重算这笔的收支、预算与报表归集。
- **账户与归档**：只能换成未归档账户；已归档账户不出现在选择器里，但它过去的流水照常计入统计与净资产。
- **私密口径**：私密是行级可见性，不是账本、也不改变家庭合计；打开后只有作者与管理员可读，其他成员连这一行都收不到。管理员视图的合计位不显示注记。
- **删除是软删**：进回收站、30 天可恢复；转账删除必须两笔一起，不做单边删除。
- **离线与失败**：保存先入待同步队列并显示缓存截至时间；失败保留草稿并可重试，重放冲突同样走冲突层口径，被拒绝的写不静默丢弃。
- **保存反馈只一次**：成功只由流水列表弹一次「已保存」并高亮该行；本页不再弹成功横幅或第二份 toast。

## 边界与不做

- 不做字段级「手动合并」编辑器：本批冲突处置只有「看家里的最新 / 保存我这一版」两条出路。
- 不做自动保存与草稿；返回即丢弃未保存改动（保存失败时保留本次输入除外）。
- 不做「编辑历史 / 版本回溯」视图，只在页内显示最后修改人与时间。
- 不做附件上传后的裁剪、压缩与 OCR 重跑（重拍在记一笔与详情页）。
- 不在本页改账本定义、分类字典与账户属性，这些在「账户与设置」。
- 不在本页提供多账本切换；账本只是这一笔的报表分组。
