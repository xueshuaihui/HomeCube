**一屏说清**：账户页是账户域的唯一列表位，回答「家里有多少钱、欠多少」：顶部净资产 `¥34,918.40`、总资产 `¥42,918.40`、总负债 `¥8,000.00`（净资产 = 全部账户余额 `¥38,818.40` + 借出待收 `¥4,100.00` − 借入待还 `¥8,000.00`），下面按现金 / 银行卡 / 其他三组列 4 个账户，行内是名称、类型与币种、余额，默认账户带「默认」标签。**归档账户不出现在默认账户位，也不进账户汇总列表，但其余额仍计入净资产**——两者不是一回事，混读会错。

## 字段与校验（页面级硬规则）

- **余额只由流水累计**：本页不提供直接改余额；要调整只能记一笔调整流水或转账（4.5.9）。
- **汇总口径**：按 4.5.8 定版 ㉛ 定义式——净资产 = 全部账户余额 + 借出待收 − 借入待还 − 机构负债；归档账户移出列表但仍计入净资产；金额全部由服务端汇总，前端只渲染。
- **私密流水**：汇总含私密流水；非管理员在汇总位同屏注「含 N 条你无权查看的记录」，N 由服务端下发；账户行不展开私密流水明细。
- **默认账户唯一**：每家庭至多一个默认账户，列表只在它的行上挂「默认」；**默认账户只有管理员能改**，成人成员看不到「设为默认」；归档账户不带默认标记。
- **归档语义**：归档账户移出默认账户位与账户汇总，余额必须为 0；**历史流水仍计入报表、预算与净资产**；归档可逆。
- **分组顺序固定**：现金 → 银行卡 → 信用卡 → 其他 → 已归档；组内按默认账户优先、再按名称；不提供拖动排序。当前家庭无信用卡，信用卡组不占位。
- **金额格式**：支出 / 负债为负、负号在 `¥` 前（`-¥1,000.00`），一律等宽数字与千分位；余额为 0 的账户仍列出，不隐藏。
- **离线**：余额与汇总显示本机缓存并标注时间；归档与恢复在离线时只给排队提示，不假装成功。

## 边界与不做

- 不做滑动归档、长按多选、批量转账；归档与恢复统一在归档页完成。
- 不做物理删除账户；错建账户走归档（余额需为 0），不提供「删除并转移流水」；要彻底清除只能进回收站，且仅管理员可操作。
- 不做账户拖拽排序与自定义分组；分组由类型决定。
- 不在本页改余额、限额、账单日 / 还款日；账单日与还款日只在信用卡 / 负债账户的编辑页出现。
- 不显示私密流水的账户明细；余额是账户级合计，不在这里展开流水。

## 待复核

- 空态下顶栏「归档与恢复」是否隐藏：原型保留入口（可能仍有历史归档），仅隐藏汇总与列表。
- 成人只读时，「新建账户」按钮是隐藏还是置灰：原型按隐藏处理，避免点了才报错。
- 信用卡余额的展示符号：原型按 `-¥1,000.00` 表示待还；当前家庭无信用卡，定版若用正数 +「待还」标签需统一。
