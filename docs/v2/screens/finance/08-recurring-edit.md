## 字段与校验（页面级硬规则）

- **归属**：只有创建人与管理员能进本页；他人规则在列表只读、没有编辑入口。本页不提供改归属人。
- **更新时间必带**：页首展示最后更新时间与修改人；保存、暂停、跳过、删除都以该时间核对是否有人先改过；冲突只给两条出路，不静默重试、不合并字段。
- **金额**：以「分」存储，录入绝对数；展示支出为负、负号在 `¥` 前（−¥4,200.00），收入带 `+`；改金额不回改历史流水，只影响下一期起的自动入账。
- **历史不受影响**：修改、暂停、跳过、删除都不改已生成流水；文案必须写明「照常参与报表、预算与账户余额」。
- **暂停语义**：暂停后不再自动入账、下次生效时间停止推进；恢复后从下一个周期继续；暂停不删除规则、不清历史。
- **跳过这一次**：实例动作，只跳过下一次入账，不改规则本体、不影响后续周期、不删除历史流水；入口只在本页。
- **删除语义**：只删规则本体，不删流水；不可恢复；已生成流水仍在流水列表与报表里。
- **起止条件**：编辑只允许延长或提前结束，不改写历史入账；期数与「最后一笔」由服务端按下一次生效时间推算。
- **分类与账户**：改分类只影响之后的流水统计，已生成流水仍按原分类；账户只能换到未归档账户，归档账户不出现在选择器。
- **离线**：顶栏细条「保存后排队，已入账流水不受影响」；写操作只排队并标「等待联网」，恢复联网后按序提交。

## 边界与不做

- 不做「立即入账 / 补跑上一期」；跳过只作用于下一次，不补记、不顺延后续周期。
- 不做删除后的撤销与回收站：规则删除不可逆，历史流水本身不受影响。
- 不做规则复制、批量暂停、跨账本迁移。
- 不在本页改账户余额或分类字典；也不在弹层里嵌套第二层确认。
- 不显示规则原文与逐期日历；周期只用人话。

## 待复核

- 暂停 / 跳过 / 删除是否也按页首更新时间核对，PRD 只写了编辑保存；原型按全部写操作都核对处理。
- 冲突文案里的金额示例：原型用 ¥4,200.00 对 ¥4,350.00，若服务端只回更新时间，需要补金额对比。
- 「用我的」后更新时间是否一定晚于家里最新，取决于服务端保存顺序，原型按保存成功即刷新展示。
- 跳过这一次是否需要二次确认：原型按实例动作即时完成、只给 toast，减少一次点击。
