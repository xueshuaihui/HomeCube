## 字段与校验（页面级硬规则）

- **口径（定版 ㉛）**：**净资产 = 全部账户余额汇总 + 借出待收（资产端）− 借入待还（负债端）**；借出待收 = `Loan` 中 `type = 借出` 的未还余额，借入待还 = `Loan` 中 `type = 借入` 的未还余额 + `Liability` 余额；同一笔往来在 `Loan` 与 `Liability` 只登记一次，两处同时挂账即判双计缺陷（4.5.6、4.5.8）。
- **同源**：本页与首页财务格共用同一份账户汇总与同一时间戳；任一处不得二次累加或另行舍入，避免两处数字不一致（4.5.8 / 18.2）。
- **占比**：资产占比以总资产为分母，负债占比以总负债为分母；展示一位小数，各项之和按最大项补差到 100.0%，不出现 99.9% 或 100.1%。
- **归档账户余额计入净资产**：归档只影响记账默认位与账户汇总列表，**不指净资产的定义式汇总**；历史流水照常统计（4.5.9、19.3#10）。
- **私密流水计入合计**：净资产与构成含全部流水；非管理员合计位必须注「含 N 条你无权查看的记录」，N 由服务端随合计下发（4.5.1 ㉛）。
- **趋势**：取每月末账户余额相减，不把当月收支再累加一遍；缺月不插 0，按实际月份连线。
- **错误**：汇总失败时整页进入错误态，不展示部分数字；重试只重发请求，不本地估算。
- **离线**：显示本机缓存的账户汇总，并在头图注明截止时间；缓存过期不伪装成实时值。

## 边界与不做

- 不在本页新增、编辑、归档账户；账户操作统一在账户页，避免总览页出现行内表单。
- 不做投资市值、房产估值、贷款剩余本金等资产的自动估值；只汇总已录入的账户余额。
- 不做自定义时间区间、同比环比切换；趋势固定近 6 个月。
- 不做多币种折算与汇率换算；币种随家庭设置，原型为 CNY。

## 待复核

- 归档账户余额是否计入净资产：**已闭合**——计入（4.5.8 第 3 条、㉛）；「不计入」只指账户汇总列表与记账默认位。
- 无负债态需与默认态读同一份汇总整体刷新，不只改头图三数。
- 趋势为 5–10 月的演示数据，月末取数与「较上月」的基准日未在 PRD 写死。
- 首页财务格跳转本页的入口未在本批改动（M1 首页不在范围），M2 收口时需挂同源链接。
