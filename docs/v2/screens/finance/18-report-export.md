**一屏说清**：导出只有一个页面、三个参数——**范围（days）、格式（format）、类型（type）**。三者**全部参与筛选**：任一改动，核对行「将导出 N 行，与当前筛选结果一致」立即重算；格式只改编码与后缀，不改行数。0 行时导出按钮禁用并说明原因，不生成空文件。

## 字段与校验（页面级硬规则）

- **三参数全生效**：导出行数 = f(`range`, `type`)，`format` 只决定编码与后缀；核对行与成功卡都同时写出范围、格式、类型，用户一眼看到三者都在起作用。
- **行数一致**：同筛选条件下导出行数必须等于页面查询行数（19.3#7）；核对句固定为「将导出 N 行，与当前筛选结果一致」。
- **0 行不导出**：0 行时禁用按钮并不生成空文件，也不落一条「导出成功」审计；错误面板给可执行建议。
- **列口径**：日期、类型、金额、分类、账户、成员、备注、附件标记；金额负号在 `¥` 前；支出为负、收入为正。
- **转账**：按转出 / 转入两笔分列，不计入支出或收入合计，避免虚增收支。
- **私密与层级**：他人私密流水不导出金额与分类；L3 内容不进默认导出；覆盖家庭全部成员，不只本人创建。
- **文件名**：单月 `finance-2026-10.csv`；近 3 月 `finance-2026-08_2026-10.csv`；扩展名随格式为 `.csv` / `.xlsx`。
- **离线**：导出需联网，页首离线条提示「恢复后自动开始」；离线不排队生成半成品文件。

## 边界与不做

- 不做 PDF、图片或打印版导出；不做定时导出与邮件推送。
- 不做「只导当前可见页」的分页导出，一次导出即整个筛选结果。
- 不做列自定义（列集合固定为八类），也不做附件打包下载。
- 不在本页改筛选条件本身（分类、成员、账户筛选回流水页）。

## 待复核

- 自定义范围跨度上限：原型按 2 年，超限时是否截断还是报错未定（原型不演示超限）。
- 「近 3 月」是否含本月：原型含，为 `08-01 至 10-31`。
- 0 行以外的失败（超时、权限变化）是否复用同一错误面板并给「重试」：原型只演示 0 行，文字待补。
- 导出记录的保留期与审计入口：本页不展示，归「账户与设置」。
