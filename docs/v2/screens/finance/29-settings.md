**一屏说清**：这是财务面二级 Tab 的末位，只维护**本面对象**：账户与分类的入口、记账默认项（默认账户 / 默认账本 / 默认类型）、预算预警阈值（默认 80%）与附件限额（只读）。**不放时间窗条、不放底部五项、不放家庭切换器**；也**不复制 HomeOS「我的」的任何入口**——账号、家庭、成员、权限、导出、隐私都不在这里，页面底部只用一句「账号、家庭与导出在首页 → 我的」指路。

## 字段与校验（页面级硬规则）

- **维护范围**：本页只维护账户入口、分类入口、记账默认项、预算预警阈值、附件限额；**账号、家庭、成员、角色权限、数据导出、隐私、外观主题一律不在这里**（18.3 / 18.5）。
- **默认账户唯一**：每家庭至多一个默认账户，选项只列未归档账户；改动只影响「记一笔」的预选，不改余额、不搬家已有流水。
- **默认账本**：选项为当前可用的账本；文案必须写「分组，不是隔离」，不得出现「私有空间」「成员看不到」。
- **默认类型**：支出 / 收入 / 转账三选一，只决定「记一笔」初始 Tab；转账仍按成对流水生成。
- **预警阈值**：70% / 80% / 90%，默认 80%；超支（100%）提醒不受阈值影响；提醒由 HomeOS 在预算用量变化时下发，**本面不跑定时器**；改阈值不补发历史提醒。
- **附件限额只读**：≤3 张 / 单张 ≤5MB / jpg·png·webp，与流水详情、账单详情同一口径；限额由服务端执行，超限直接失败。
- **保存与离线**：默认项改动是可撤销的脏态，保存才落库；离线时保存排队并标注「保存需联网」，不显示已保存。
- **角色**：非管理员整组只读，不出现「保存」按钮；权限判定由服务端兜底。

## 边界与不做

- **不放任何 HomeOS「我的」的入口**：账号资料、家庭成员、角色权限、导出、隐私、关于、主题设置都不在本页；只在底部用一句指路，且不复制二级入口。
- 不放时间窗条（月/季/年只属流水、报表、预算三页），不放底部五项，不放面切换器。
- 不在本页改账户余额、归档账户、增删分类、排序分类：分别去账户页与分类页。
- 不做阈值任意百分比输入与按分类设阈值：P1 只给 70 / 80 / 90 三档，分类级预警属预算页。
- 不做附件白名单自定义、存储配额、清理缓存；不做通知渠道开关（属 HomeOS 通知设置）。
- 不做「重置全部设置」这类破坏性批量动作。

## 待复核

- 阈值口径冲突：任务写「预算预警默认 80%」，但页面清单 `finance/budget/create` 记「阈值默认 100%，可设 80% 预警」；原型按 80% 默认呈现，定版需与预算创建页统一（谁持有默认值）。
- 成人成员能否改记账默认项：16.3 财务行是「M 写」，家庭级配置不属「本人的」，原型按只读；若产品希望「各自默认项」，需落成员级偏好字段。
- 附件限额是否家庭可配：当前按平台统一值只读；若允许管理员调整，要新增配额校验与审计。
- 「默认账本」与账本页的「当前账本」是否同一个状态：原型按两个概念处理（默认归组 vs 当前筛选），需确认不会互相改写。
- 非管理员是否应隐藏账户 / 分类入口：原型保留可查看，写操作在对应页面判权。
