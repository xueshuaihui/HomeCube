# 29 · 账户与设置

| 项 | 值 |
|---|---|
| 路由 | `finance/settings/index` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 记账默认项、预算预警阈值、附件限额、「允许成员导出」仅管理员可改；成人成员只读（16.3 财务行：家庭级配置无「本人的」语义）；账户 / 分类 / 标签可查看，新建与改名成员也能做，删除与合并仅管理员；儿童、访客不进财务面 |

**一屏说清**：这是财务面二级 Tab 的末位，只维护**本面对象**：账户 / 分类 / 标签三个入口、记账默认项（默认账户 / 默认账本 / 默认类型）、预算预警阈值、附件限额、「允许成员导出」家庭级开关。**不放时间窗条、不放底部五项、不放家庭切换器，也没有模板分组**；也**不复制 HomeOS「我的」的任何入口**——账号、家庭、成员、权限、导出、隐私都不在这里，页面底部只用一句「账号、家庭与导出在首页 → 我的」指路。管理员身份**逐行写进卡片**（行名旁「仅管理员」标签 + 分组说明），不靠整页一句提示。

## 字段与校验（页面级硬规则）

- **维护范围**：本页只维护账户 / 分类 / 标签入口、记账默认项、预算预警阈值、附件限额、允许成员导出；**账号、家庭、成员、角色权限、数据导出、隐私、外观主题一律不在这里**（18.3 / 18.5）。
- **管理员门禁逐行落地**：默认账户、默认账本、默认类型、预算预警阈值、附件限额、允许成员导出六项，行名旁必须有「仅管理员」标签或分组说明；成员态置灰且点击只提示，不假装可改；权限判定由服务端兜底。
- **默认账户唯一**：每家庭至多一个默认账户，选项只列未归档账户；改动只影响「记一笔」的预选，不改余额、不搬家已有流水。
- **默认账本**：选项为当前可用的账本（日常 / 旅行 / 装修）；文案必须写「分组，不是权限边界」，不得出现「私有空间」「成员看不到」「多账本切换」。
- **默认类型**：支出 / 收入 / 转账三选一，只决定「记一笔」初始 Tab；转账仍按成对流水生成。
- **预警阈值**：70% / 80% / 90%，默认 80%；超支（100%）提醒不受阈值影响；选定即保存，不需要再点底部保存；提醒由 HomeOS 在预算用量变化时下发，本面不跑定时器；改阈值不补发历史提醒。
- **附件限额**：数量 1 / 3 / 5 张、单张 2 / 5 / 10MB，选定即保存；格式固定 jpg · png · webp 只读；与流水详情、账单详情同一口径（默认 3 张 / 5MB）；限额由服务端在新上传时执行，改小不影响已上传附件。
- **允许成员导出**：家庭级开关，默认关；只改导出资格，不改可见范围；与 HomeOS「数据导出」不是同一入口，本页只做开关。
- **保存与离线**：默认项改动是可撤销的脏态，保存才落库；阈值与附件限额是即时保存；离线一律排队并标注，不显示已保存。
- **文案口径**：用户可见处不出现「权限」「角色矩阵」「配置项」「is_archived」等工程词，统一说「仅管理员可改」「成员也能做」。

## 边界与不做

- **不放任何 HomeOS「我的」的入口**：账号资料、家庭成员、角色权限、导出、隐私、关于、主题设置都不在本页；只在底部用一句指路，且不复制二级入口。
- **不做模板分组**：P1-M1 不提供「记账模板」分组或模板管理，本页不出现该分组。
- 不放时间窗条（月/季/年只属流水、报表、预算三页），不放底部五项，不放面切换器。
- 不在本页改账户余额、归档账户、增删分类、排序分类：分别去账户页与分类页。
- 不做阈值任意百分比输入与按分类设阈值：P1 只给 70 / 80 / 90 三档，分类级预警属预算页。
- 不做附件白名单自定义、存储配额、清理缓存；不做通知渠道开关（属 HomeOS 通知设置）。
- 不做「重置全部设置」这类破坏性批量动作。

## 待复核

- 阈值口径冲突：任务写「预算预警默认 80%」，但页面清单 `finance/budget/create` 记「阈值默认 100%，可设 80% 预警」；原型按 80% 默认呈现，定版需与预算创建页统一（谁持有默认值）。
- 成人成员能否改记账默认项：16.3 财务行是「M 写」，家庭级配置不属「本人的」，原型按只读；若产品希望「各自默认项」，需落成员级偏好字段。
- 附件限额由只读改为可配后，是否需要配额校验与变更审计（当前只有服务端执行 + toast）。
- 「默认账本」与账本页的「当前账本」是否同一个状态：原型按两个概念处理（默认归组 vs 当前筛选），需确认不会互相改写。
- 成员态是否应隐藏账户 / 分类 / 标签入口：原型保留可查看，写操作在对应页面判权。
