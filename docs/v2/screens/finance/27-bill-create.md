| 项 | 值 |

| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员可建；成人成员可建本人账单（16.3 财务行「M 写」）；儿童、访客不进财务面 |

| 状态帧 | [默认](../../prototypes/finance-bill-create.html) · [一次性](../../prototypes/finance-bill-create.html?state=once) · [校验失败](../../prototypes/finance-bill-create.html?state=error) · [保存失败](../../prototypes/finance-bill-create.html?state=fail) · [保存中](../../prototypes/finance-bill-create.html?state=loading) · [离线](../../prototypes/finance-bill-create.html?state=offline) |

**一屏说清**：新建账单只回答「交什么、多少钱、哪天到期、从哪个账户出、要不要重复、什么时候提醒」。字段：名称、金额、到期日、来源账户、重复（一次性 / 每月）、提醒提前量、自动扣款标记与备注。到期日**只选到天，不选钟点**，副行写「保存后注册到到期中心」；提醒只有「当天 / 提前 3 天」两档，可多选。顶部与底部各有一处**明确表态**：保存后只是提交到期注册，**日历里可能稍晚出现，本页不承诺立刻上日历**；超过几分钟没出现，可在详情页重新提交。

## 字段与校验（页面级硬规则）

- **名称**：必填、≤30 字、只裁首尾空白；同名不拦（靠账户与到期日区分）；错误只做行内，不弹全局层。
- **金额**：必填、`amount > 0`、≤2 位小数、以「分」存；账单按支出记账，列表与详情显示 `-¥680.00`；不做四舍五入与自动补零。
- **到期日只到天**：必填自然日，不设钟点；`due_at` 不得早于今天；每月账单按「同一日号」逐期生成，月末按当月最后一天。
- **来源账户**：必选且只能选未归档账户；默认值取账户与设置里的默认账户；账户归档后新账单不能再选它。
- **重复**：一次性 / 每月二选一，默认每月；每月不是一条无限重复的提醒，而是逐期生成待缴并逐期注册；不自动扣款，仍需手动标记已缴。
- **提醒提前量**：只有当天 / 提前 3 天两档，可多选、默认都选；只按天提醒，不出现小时或分钟选项；触发与投递交给日历面与家庭消息，财务面不自建定时器。
- **自动扣款**：默认关；只是账单上的标记，不接资金通道；开关文案必须写明「家立方不会替你扣钱」。
- **到期注册**：保存是「写账单 + 提交注册」一个动作，重复提交不会产生两个到期项；页面文案只到「已提交」为止，不说「已上日历」。
- **离线性**：离线时保存先入本机队列并标注「联网再提交注册」，不显示已成功。
- **文案口径**：用户可见处不出现「幂等键」「事件码」「投影」等工程词；注册说明只写「注册到家庭日历的到期中心，可能稍晚出现」。

## 边界与不做

- 不做草稿、不做「保存并再建一条」、不做模板与批量导入。
- 不做真正的自动扣款：不接银行或支付通道，自动扣款只是标记（4.5.5）。
- 不在本页选分类：账单的分类由来源账户与名称推导（详情显示「居住 · 物业费」），P1 不给账单挂自定义分类。
- 不做发票信息、附件上传（附件在详情页补）、不做提前还款或部分金额。
- 不承诺「保存后立刻出现在日历」；不给「去日历看看」的跨面按钮（切面只能回首页矩阵）。

## 待复核

- 校验失败态弹的是「还有 1 项需要补全」，而名称与金额同时清空时会命中两项；顶部计数是否需要按实际错误项数动态变化，原型按单条示例处理。
- 「到期日早于今天」的判定基准（家庭时区的今天 00:00 还是当天结束）未定；原型按自然日比较。
- 提醒默认两档都选是否偏吵：定版若只留一档，需同步改详情页与编辑页的默认值。
- 一次性账单缴完后是否从列表消失（当前归入已缴组），原型未区分「结束」与「已缴」。
