# 27 · 新建账单

| 项 | 值 |
|---|---|
| 路由 | `finance/bill/create` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员可建；成人成员可建本人账单（16.3 财务行「M 写」）；儿童、访客不进财务面 |
| 原型 | [finance-bill-create.html](../../prototypes/finance-bill-create.html) |
| 状态帧 | [默认](../../prototypes/finance-bill-create.html) · [每月](../../prototypes/finance-bill-create.html?state=repeat) · [校验失败](../../prototypes/finance-bill-create.html?state=error) |

**一屏说清**：新建账单只回答「交什么、多少钱、哪天到期、从哪个账户出」。七个字段：名称、金额、到期日（`due_at`）、来源账户、重复（一次性 / 每月）、提醒提前量与备注。顶部与底部各有一处**明确表态**：保存后只是提交到期注册，**日历显示可能稍晚，本页不承诺即时上日历**——账单先落财务面，日历面消费注册后才出现在家庭日历与到期中心，超过 5 分钟未出现可在详情页重新提交。

## 字段与校验（页面级硬规则）

- **名称**：必填、≤30 字、只裁首尾空白；同名不拦（靠账户与到期日区分）；错误只做行内，不弹全局层。
- **金额**：必填、`amount > 0`、≤2 位小数、以「分」存；账单按支出记账，列表与详情显示 `-¥380.00`；不做四舍五入与自动补零。
- **到期日**：必填自然日，时刻固定当天 20:00（家庭时区）；`due_at` 不得早于今天；每月账单按「同一日号」逐期生成，月末按当月最后一天（31 日 → 2 月 28/29 日）。
- **来源账户**：必选且只能选未归档账户；默认值取记账默认账户；账户归档后新账单不能再选它。
- **重复**：一次性 / 每月二选一，默认一次性；每月不是一条无限重复的提醒，而是逐期生成待缴并逐期注册；不自动扣款，仍需手动确认已缴。
- **提醒提前量**：当天 / 1 / 3 / 7 天四选一，默认 3 天；只影响日历提醒时刻，不改 `due_at`。
- **到期注册**：保存是「写账单 + 提交 `{code}.due.registered`」一个动作；幂等键 `(source_system, source_id, kind)` 防重复注册；页面文案只到「已提交」为止。
- **离线性**：离线时保存先入本地队列并标注「联网再提交注册」，不显示已成功。

## 边界与不做

- 不做草稿、不做「保存并再建一条」、不做模板与批量导入。
- 不做自动扣款开关与自动扣款日；「自动扣款标记」仅人工确认（4.5.5），本页不出现。
- 不在本页选分类：账单的分类由来源账户与名称推导（详情显示「居住 · 物业费」），P1 不给账单挂自定义分类。
- 不做发票信息、附件上传（附件在详情页补）、不做提前还款或部分金额。
- 不承诺「保存后立刻出现在日历」；不给「去日历看看」的跨面按钮（切面只能回首页矩阵）。

## 待复核

- `Bill` 数据模型含 `auto_pay`（4.5.5「自动扣款标记仅人工确认」），本页未放该字段；若定版要建，应加一个只读说明型开关并写清「不会自动扣款」。
- 账单是否允许「不重复但分期」与「每季度 / 每年」：任务只要求一次性 / 每月，原型据此收敛；4.5.5 未列其他周期。
- 「到期日早于今天」的判定基准（家庭时区的今天 00:00 还是 20:00）未定；原型按自然日比较。
- 提醒提前量与详情页注册卡里的「提前 3 天与当天」是同一字段还是两个字段，原型按同一字段（当天固定再提醒一次）。
