**一屏说清**：流水是财务面的一级页，也是整个面的默认落点——五个 L2 Tab 常驻、不带底部五项、不放面切换器。一屏只做三件事：按月/季/年窗看按日分组的流水、用六个 chip 收敛列表、点行进单笔详情；长按多选只是本页的一个状态帧，不成新页面。金额以「分」整数存、按家庭币种显示、负号在货币符号之前；转账是成对的转出 / 转入，不计入收支小计。**本月合计、累计余额、每个日组小计与筛选摘要都按全量流水算（含私密行）；他人私密行不下发、不出现在明细里、也不能被筛出来，读不到的金额由合计旁那句「含 N 条你无权查看的记录」交代**（㉛）。

## 字段与校验（页面级硬规则）

- **金额**：以「分」整数存储，展示按家庭币种；支出为负、负号在货币符号之前（`-¥128.00`），收入带 `+` 并走 success 色；一律等宽数字。
- **笔数口径**：一笔流水算一笔。本月 186 笔，其中私密 4 笔合计 ¥860.00；非管理员可见 182 笔的明细，合计与累计余额仍按 186 笔的全量算。成对转账在列表里并成一行显示、标「成对」，但计 2 笔。
- **日分组不随档位变**：分组小标题（按日）是列表自己的呈现参数，不随时间窗变，也不写回时间窗；时间窗只有月 / 季 / 年三档，不出现「周」「全部」。
- **游标分页**：只按 cursor 追加、不提供页码；已加载的日组不重拉；首屏 50 条渲染 P95 ≤300ms（19.3#2）。本页样例月 186 笔、首屏 50 笔，加载更多只追加。
- **转账**：成对（同一笔转账的转出与转入），行内标「成对」、金额不带正负收支语义，不计入收支小计与预算；进出两侧账户余额各变动一次（㉛ 账实相符）。
- **私密行进合计**：命中私密标记的流水**计入本月收入、支出、结余、累计余额与统计四视图的总量**，一律按本时间窗的全量流水算、不排除私密行；私密行的排除范围只有 AA 分摊与跨面归集，不含本面合计与报表总量（㉛）。
- **合计位注记**：每一个呈现合计的位置（顶部本月汇总、每个日组小计、筛选摘要、报表与统计总量）都必须在同一屏注明「含 N 条你无权查看的记录」，N = 该窗口内命中私密标记且当前读者无权读取的行数，由服务端随合计一并下发、判定时点 = 该屏渲染；客户端不自行估算或反推，读者可读全部时 N=0、该注记不显示，管理员视图不显示该注记。注记缺失、N 与服务端行数不符、或用「无权限」字样代替注记的都不合格。
- **明细按可读范围裁剪**：他人私密行**不下发、不可见、不可筛出**，不是「留占位」；明细里根本不出现这一行。除私密行以外的家庭流水按角色正常返回。
- **账本是筛选器不是切换器**：列表顶部的账本筛选只影响当前视图，不改变流水归属、不改变可见范围；全 App 不设多账本切换器，文案不得出现「切换账本」「私有空间」「成员看不到」等措辞。
- **删除即软删**：单个与批量删除都进回收站，30 天内可由作者或管理员恢复；不在本页提供「彻底删除」。删除与恢复都会重算账户余额与本月合计（㉛），批量删除的确认层给「N 笔将退回这些账户」的影响摘要。
- **待同步**：断网期保存的记账先落本机队列，在列表首行以带「待同步」标的行呈现；**回执落库前它不进本月合计、日组小计、账户余额、预算与报表**（合计仍显示服务端最后一次回执的口径，并注一句「另有 N 笔待同步，不计入上面的合计」）；判定时点 = 服务端回执落库那一次请求，落库后立即计入并去掉该标；重放冲突的处置在记一笔页（`finance/tx/create`）的离线口径里定义，本页只呈现结果。
- **可见性**：家庭流水全员可见、作者唯一可改；私密行只对作者与管理员可读。本页不判断权限，收到什么渲染什么。
- **不建定时器**：预算超支由 HomeOS 下发家庭消息通知，本面只展示与筛选，不自建提醒。

## 边界与不做

- 不做面切换器、不叠底部五项；Tab 只有五个、不加第六个。
- 不把多选操作态做成独立路由，也不做侧滑删除（删除统一走多选或详情页）。
- 不做「按周 / 全部」时间档，不做把时间窗档位写回列表分组的联动。
- 不在本页做导出参数的二次选择；导出在报表页，本页「更多」只给入口。
- 不做 AA 分账、借贷、报销（② 及以后），也不在本页出现这些类型。
- 停用分类不出现在记账选择器，但历史流水仍可筛选、可统计（19.3#10）。
- 不做下拉刷新与无限滚动的双实现：只保留「加载更多」一个入口。
- 不给私密行留「锁图标占位」：对无权读者，这一行不下发也不出现，只在合计位注明 N。
