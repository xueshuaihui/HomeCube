**一屏说清**：流水是财务面的一级页，也是整个面的默认落点——五个 L2 Tab 常驻、不带底部五项、不放面切换器。一屏只做三件事：按月/季/年窗看按日分组的流水、用六个 chip 收敛列表、点行进单笔详情；长按多选只是本页的一个状态帧，不成新页面。金额以「分」整数存、按家庭币种显示、负号在货币符号之前；转账是成对的转出 / 转入，不计入收支小计；私密行只对作者与管理员可读，他人视角不下发金额与分类。

## 字段与校验（页面级硬规则）

- **金额**：以「分」整数存储（`amount_cents`），展示按家庭币种；支出为负、负号在货币符号之前（`-¥128.00`），收入带 `+` 并走 success 色；一律 `.amount` / `.num` 等宽数字。
- **日分组不随档位变**：分组小标题（按日）是列表自己的呈现参数，不随 `period` 变，也不写回 `period`；`period` 只有月 / 季 / 年三档，不出现「周」「全部」。
- **游标分页**：只按 cursor 追加、不提供页码；已加载的日组不重拉；首屏 50 条渲染 P95 ≤300ms（19.3#2）。
- **转账**：成对（同 `transfer_group`），行内标「成对」、金额不带正负收支语义，不计入收支小计与预算。
- **私密行**：仅作者与管理员可读；他人视角下金额、分类、备注与附件一律不下发（行只留「私密」占位），且不参与 AA 分摊与跨面归集。
- **账本是分组不是隔离域**：换账本只改报表归集，文案不得出现「私有空间」「成员看不到」等隔离措辞。
- **删除即软删**：单个与批量删除都进回收站，30 天内可由作者或管理员恢复；不在本页提供「彻底删除」。
- **可见性**：家庭流水全员可见、作者唯一可改；本页不判断权限，收到什么渲染什么，被裁掉的行不返回、不占位。
- **不建定时器**：预算超支由 HomeOS 下发家庭消息通知，本面只展示与筛选，不自建提醒。

## 边界与不做

- 不做面切换器、不叠底部五项；Tab 只有五个、不加第六个。
- 不把多选操作态做成独立路由，也不做侧滑删除（删除统一走多选或详情页）。
- 不做「按周 / 全部」时间档，不做把时间窗档位写回列表分组的联动。
- 不在本页做导出参数的二次选择；导出在报表页，本页「更多」只给入口。
- 不做 AA 分账、借贷、报销（② 及以后），也不在本页出现这些类型。
- 停用分类不出现在记账选择器，但历史流水仍可筛选、可统计（19.3#10）。
- 不做下拉刷新与无限滚动的双实现：只保留「加载更多」一个入口。
