| 项 | 值 |
|---|---|
| 路由 | `finance/category/create` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员与成人成员都能新建；小孩不可进入。分类是家庭共有配置，新建后全家的记账选择器都会出现 |

**一屏说清**：分类只由四项决定——**名称、父级、图标、颜色**，外加一个支出/收入类型。名称与父级决定它在树里的位置（两级封顶），图标与颜色只决定它长什么样，两者都只能从统一集合里选，**不支持 emoji，也不支持自定义色值**。成人成员都能建，建完全家一起用。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 直接丢弃未保存的输入回分类管理，不弹「是否放弃」（四项重填成本低） | `finance/category/index` |
| ② | 名称 | 输入 | 1-10 字符，首尾空格自动去掉，只输空格按空处理；与同一父级下的分类重名即报错，**不给「仍然创建」** | 留在本页 |
| ③ | 父级 | 点 chip | 「无（一级）」或任一**未停用**的一级分类；选父级后预览行改显「二级」；收入分类只列收入的一级；一级被全部停用时，候选位换成「先去启用」的提示 | 留在本页 |
| ④ | 图标 | 点「更换图标」/ 点某枚图标 | 就地展开 18 枚统一图标网格，选中项高亮，预览同步换图标；不发请求、不跳页 | 留在本页 |
| ⑤ | 颜色 | 点色块 | 八枚令牌色任选，不提供色值输入框；选中项加环，亮暗两套值都由令牌给 | 留在本页 |
| ⑥ | 类型 | 点分段 | 支出 / 收入二选一，决定分类出现在记账选择器的哪个页签，父级候选随之切换；**建好后不可改类型** | 留在本页 |
| ⑦ | 创建 | 点击底部按钮 | 校验通过才写入；成功回分类管理并展开其父级（一级则置顶新行）；重名时停在重名态、按钮不生效；离线时先排队并提示「联网后自动创建」 | `finance/category/index` |
| ⑧ | 重试 | 加载失败态点击 | 重新载入表单与父级候选，不写入任何内容；仍失败保持整页失败态 | 留在本页 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 名称空、父级「无（一级）」、图标收起为已选一枚、颜色默认暖橙、类型默认支出；预览行「未命名分类 · 一级 · 支出 · -¥0.00」 |
| 图标选择展开 | 点「更换图标」 | 图标网格在表单内就地展开（不弹层、不跳页），按钮变「收起图标」；当前图标高亮 |
| 重名 | 名称与同一父级下已有分类相同 | 名称框转错误态 + 行内错误「支出下已有同名分类『餐饮』……」，创建按钮不生效；把父级换成别的分类可继续 |
| 无父级可选 | 该类型的一级分类都被停用 | 父级 chip 行收起，原位显示「一级分类都被停用了……先到分类管理启用」，仍可直接创建一级分类；不因缺父级卡住页面 |
| 加载中 | 首次进入 / 重试后 | 表单位置显示骨架（字段行 + 图标块 + 色板块），底部「取消 / 创建」暂不出现，避免空表单被提交 |
| 加载失败 | 表单或父级候选读取失败 | 整页失败态：标题「页面没有加载出来」+ 说明 + 「重试」；已填内容不写入、不弹 toast |
| 离线 | 无网络 | 顶部离线条「当前离线 · 新建后先排队，联网会自动提交」；点创建把记录收进本机队列，联网后自动提交，提交成功再出现在分类管理 |

## 字段与校验（页面级硬规则）

- **名称**：必填、1-10 字符、去首尾空格；唯一性范围是**同一父级 + 同一类型**（一级对一级，同一父级下的二级互为同级）；重名只提示改名或换父级，**不提供强制创建**。
- **父级**：只能选一个或「无」；只列**未停用**的同类型一级分类；两级封顶，选中二级不能作为父级。父级后来被停用，已建的二级照常保留、照常统计。
- **类型**：建好后不可改；要换只能另建一条并停用旧项（停用不影响历史流水）。
- **图标**：只存图标集名称，不存 emoji 或图片；18 枚是 P1 常用子集。颜色只存令牌名，不存色值，页面不得出现 `#hex`。
- **写入口**：`POST /api/finance/categories`，带 `client_request_id`；离线先排队，联网自动提交；重复提交不产生两条分类。
- **预览行**：名称、层级、类型、金额符号随输入实时变；金额固定 `-¥0.00` / `+¥0.00`，不代表真实余额。

## 边界与不做

- 不在本页建第三级分类，也不做「批量新建」。
- 不做「分类模板 / 从别家复制」，不做 emoji 输入与自定义色值。
- 不在本页设预算，也不在本页删除或合并分类（都在编辑页，且仅管理员）。
- 不因重名、超长、空名称自动改写用户输入，只做行内提示。

## 待复核

- 图标集全集数量与命名：本原型取 18 枚常用并只写中文名，权威清单待图标集定版。
- 「同级重名」是否跨支出/收入也拦：本原型按「同父级 + 同类型」判重，收入与支出可同名。
- 创建成功后回列表还是直接进记一笔：本原型按**回列表并展开父级**。
