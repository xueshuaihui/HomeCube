**一屏说清**：归档页一屏分两段——上方「已归档」（可恢复），下方「可归档账户」（余额为 0 才能归档）。页首常驻「**归档不等于删除**」：**归档账户不出现在默认账户位，也不进账户汇总，但历史流水仍计入报表与净资产**；归档可逆，随时可以恢复。点「归档」先弹**二次确认 + 影响说明**；余额非 0 时确认后由服务端拒绝，就地提示先转账或记调整流水，前端不把余额清零。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 回账户列表；归档与恢复都不改历史流水，返回后列表与汇总按最新状态重算 | `finance/account/index` |

## 字段与校验（页面级硬规则）

- **归档前置条件**：余额必须为 0；非 0 时服务端拒绝，页面就地说明「请先把余额转到其他账户，或记一笔调整流水调为 0」（4.5.9、19.3#10）；前端不得把余额清零或伪造可归档。
- **二次确认**：所有归档都要经过确认层，逐条说明影响；确认前不写数据，取消无副作用。
- **归档后的口径**：已归档账户移出默认账户位与账户汇总、移出记账选择器；**历史流水仍计入报表与净资产**；归档不影响历史归属。
- **余额与恢复**：恢复不改余额、不重算历史；余额按流水重新呈现，不重复累计；恢复不自动恢复默认标记。
- **没有物理删除**：账户只归档不删除；误建账户也走归档（余额需为 0），要彻底清除只能进回收站，且仅管理员可操作。
- **列表分两段**：已归档（按归档时间倒序，显示归档日期与余额）与可归档（列出全部未归档账户）；余额非 0 的仍可点归档以看到拒绝原因，不把按钮藏起来。
- **金额**：一律等宽数字，负数在 `¥` 前（`-¥1,000.00`）；归档账户余额恒为 ¥0.00。
- **离线**：归档与恢复需联网确认，只提示不排队成功；返回列表时以服务端状态为准。

## 边界与不做

- 不做物理删除账户，也不做「归档并清零」；余额问题必须先转账或记调整流水。
- 不做批量归档 / 批量恢复，也不做滑动操作。
- 不在本页做转账或调整流水；只给文案与入口提示，实际记账在记一笔里完成。
- 不做归档账户的详情页；需要改名等操作先恢复，再回列表编辑。
- 不提供「归档后自动取消默认」的显式开关：默认标记的处理由服务端保证唯一。

## 待复核

- 默认账户能否直接归档：PRD 只要求余额为 0，未说默认位，原型未拦截；若定版要求先取消默认需补拦截。
- 归档 / 恢复失败的业务错误码与文案未定版，原型用「归档被拒绝 · 余额不为 0」示例。
- 空态是否保留「可归档账户」段：原型保留（仍有候选），只把已归档段置空。
- 余额非 0 的账户是「可点但确认后被拒」还是「按钮直接禁用」：原型按前者，保证二次确认与影响说明始终可达。
