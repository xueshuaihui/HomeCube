**一屏说清**：详情回答「借给谁、本金多少、已还 / 未还各多少、每一期什么时候还」。头部给对手方（可非成员）、本金、已还与未还，进度按已还期次算；中部是**逐期还款计划**，每期四件套（期次、应还日、金额、已还 / 待还 / 逾期），点待还或逾期期次会打开还款弹层并预填该期；底部「登记还款」打开同一弹层（金额、日期、账户），确认后在所选账户生成一条流水。**逾期不会自动扣款，已结清不再接受登记**；相关流水只读，改流水不回退进度。

## 字段与校验（页面级硬规则）

- **头部口径**：本金为原始本金；已还 = 所有已还期次金额之和；未还 = 本金 − 已还；三个数由服务端算，**已还 + 未还必须等于本金**；结清后未还为 0，不显示负数。
- **还款计划**：每期含期次、`due_at`、`amount`、`status`；状态只有已还 / 待还 / 逾期三种；逾期由「待还且 `due_at < 今天`」推导，不单独存人工状态；已还期次不可再登记。
- **登记还款**：金额以「分」存储，`> 0` 且不超过所选期未还；允许小于本期应还，差额留在该期继续待还；日期不早于借贷日、不晚于今天；账户必选且只能选未归档账户。
- **流水生成**：借出收回记为收入类「收回借款」，借入归还记为支出类「归还借款」，落在所选账户；一笔登记只生成一条流水；幂等键保证重复提交不生成第二条。
- **结清**：全部期次已还即结清，不再计入待收 / 待还、不再提醒；记录保留可回看，不允许恢复成进行中。
- **逾期**：只影响本笔提示与报表口径，**不从账户自动扣款**；逾期天数为家庭时区自然日差，不因重新打开页面而重置。
- **日历回写**：登记后本地立即置已还，到期注册的撤销 / 完成回写提交给日历面；跨服务收敛可能稍晚，页面不显示「已撤销」这种未完成结果。
- **版本**：`版本 3` 与还款登记的幂等 / 乐观锁同源；冲突时提示刷新后重试，不在前端合并两笔还款。
- **离线**：还款登记先入队并带幂等键；离线时只提示排队，不把该期先改成已还。

## 边界与不做

- 不在本页改本金、期数、首期日或对手方；也没有借贷编辑入口（见「待复核」）。
- 不做一键结清、提前结清、展期、改期、减免与利息 / 违约金计算；结清只能逐期登记。
- 不做直接切换期次状态，不提供「撤销已还」按钮；错登的冲正路径未定。
- 不做一笔还款跨多期自动分摊，也不做多笔合并还款。
- 不做还款凭证上传、对方确认、催收消息或对外收款链接。
- 不展示 `loan_id`、`plan_id`、幂等键等技术字段。
- 不提供从本页跳日历查看注册项；到期提醒由家庭日历负责。

## 待复核

- **部分还款的归属**：原型按「所选期次递减、差额留在该期」处理；若产品要求先冲最早逾期期或跨期分摊，需改弹层与计划行文案。
- **超额还款**：原型限制不超过该期未还；若允许超额并自动结清后续期次，需补分摊规则与展示。
- **已还的撤销 / 冲正**：原型没有入口，且流水删除不回退进度；正式需一条「冲正还款」或「删除流水并回退」的路径，否则错登无法纠正。
- **还款账户与币种**：账户币种与借贷币种不一致时如何处理（拒绝 / 换算）未定义，原型不做换算。
- **逾期天数边界**：按自然日差计算，是否把到期当天算作逾期第 0 天、次日算第 1 天，需与 19.3 的边界值统一。
- **成人成员权限**：原型按「涉及自己」可登记还款；若借贷为家庭共有，需放开到全部。
- **热区可见性**：已结清帧底部 ④ 已移除、弹层 ⑤ 无法到达；验收热区时以默认 / 逾期帧为准。
