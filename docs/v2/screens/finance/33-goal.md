## 字段与校验（页面级硬规则）

- **汇总口径**：只统计进行中的目标；已达成与已归档**都不进分子与分母**；已存合计、目标合计、还差金额、总进度同源，由服务端汇总，前端不二次累加；还差 = 目标合计 − 已存合计，不为负。
- **单卡进度**：`已存 ÷ 目标`，四舍五入到整数百分比；进度环按 `2πr`（r = 25）取弧长，78% / 63% / 36% / 100% 分别对应 `122` / `99` / `57` / `157`；已存大于目标时环满格、百分比封顶 100%。
- **预计达成日**：按「剩余金额 ÷ 当前节奏」估算到月，当前节奏取自动存入的每月金额；没有自动存入规则时取近 3 个月手动存入的平均值（原型第 3 张卡按此展示）；预计晚于目标日期时用 warning 标出，文案写明「仅供参照，实际以每次存入为准」。
- **分组与排序**：进行中一组，按目标日期由近到远；已达成单独一组，按达成时间倒序；已归档不出现在本页；不提供拖动排序。
- **已达成**：进度 100%，自动存入自动停用，不再生成新记录；目标与记录保留，直到被归档；达成后仍可进详情看全部存入记录。
- **自动存入的合规边界**：它只是周期记账规则，到日生成一条记账记录；**不对接银行、支付宝或微信，不自动扣款、不做真实划转**；本页顶部与空态都必须出现这句说明，不能只在新建页写。
- **金额格式**：以「分」整数存储，展示千分位 + 两位小数、等宽数字；币种符号在数字前。
- **离线**：已存金额与进度显示本机缓存并标注时间；新建入口保留，保存先排队。

## 边界与不做

- 不在列表直接新建、编辑、归档、存入或取出；这些动作都在新建页 / 详情页。
- 不做真实资金划转、银行或支付通道对接、自动扣款；不做「到期自动把钱转进去」。
- 不做利息、收益、理财建议或达成概率预测。
- 不做按成员拆分出资比例、家庭共同目标的份额与结算（M2 只做家庭共同目标本身）。
- 不做每日 / 每周 / 按笔凑整的自动存入，只有每月固定日、固定金额。
- 不做目标到期自动关闭、自动归档或自动放弃。
- 不做预测曲线、历史进度图与目标模板。
- 不展示 0% 空卡或假的预计达成日来撑页面。

## 待复核

- **已达成分组的默认可见性**：原型在默认帧只显示进行中，`achieved` 帧才展开「已达成」组；正式是否默认收起、还是常驻一组，需定版。
- **汇总是否含已达成**：原型按「只算 3 个进行中的目标」处理（已达成不计入），与 PRD 未写明的口径需确认；若含已达成，分子分母与 47% 都要改。
- **无自动存入目标的预计达成日**：原型按近 3 个月手动存入均值估算；若产品只允许按自动规则估算，这类目标应显示「未设自动存入，无法估算」。
- **成人成员权限**：16.3 为「M 写」，而 PRD 有「家庭共同目标」；原型按「自己创建的可维护、全家可读」处理，家庭共同目标是否允许双方存入 / 改规则待定。
- **入口位置**：原型从「账户与设置」返回，正式收口需在设置的对象维护区补「储蓄目标」入口。
- **目标期限**：新建页允许不填期限；无期限目标的排序与预计达成展示未定义。
