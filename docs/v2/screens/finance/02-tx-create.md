# 02 · 记一笔

| 项 | 值 |
|---|---|
| 路由 | `finance/tx/create` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员 A；成人成员 M（记自己的流水）；儿童账号需管理员逐面开放写权限；无账号成员被记录、不写；访客不进财务面（16.3 财务行） |

| 状态帧 | [默认](../../prototypes/finance-tx-create.html) · [转账](../../prototypes/finance-tx-create.html?state=transfer) · [OCR 结果](../../prototypes/finance-tx-create.html?state=ocr-result) · [保存中](../../prototypes/finance-tx-create.html?state=saving) · [缺必填](../../prototypes/finance-tx-create.html?state=error) |

**一屏说清**：记一笔是财务面唯一的**新建写入页**（二级页，navbar 返回，不带 L2 Tab 与底部五项）。它把一次记账压到 3 步：填金额 → 选分类 → 点右上角「保存」；账户、日期、成员、账本都有默认值，不需要逐项填。类型三选（支出 / 收入 / 转账）同页切换，切到转账时分类区换成「从 / 到」两个账户并生成成对流水；OCR 与语音只**预填并逐项确认**，识别失败原地回落手输、不新增页面也不增加步骤。

## 字段与校验（页面级硬规则）

- **金额**：必填，以「分」整数存（`amount_cents`），显示按家庭币种；支出为负、负号在货币符号之前（`-¥128.00`），收入为正并带 `+`，转账不带收支符号；最多两位小数。
- **幂等写**：每次保存带 `client_request_id`，超时重试与断网重放都只落一条流水（转账落一对），不产生第二笔。
- **类型口径**：支出 / 收入进收支小计与预算；转账进两个账户余额、不进收支小计与预算；P1 不做借入 / 借出 / 报销。
- **账户口径**：只列未归档账户；归档只影响今后能不能选，历史流水仍计入统计与净资产；转账的「从」与「到」不能相同，P1 跨币种提示暂不支持自动换算。
- **时间口径**：日期默认今天，可补记过去日期；按家庭时区归日，补记不改变时间窗 `period`，只影响这一笔的归属期间。
- **归属口径**：成员默认本人，代记时归属被记录成员；账本默认「日常」，是报表分组、不是隔离域；标签多选、取交集用于筛选。
- **附件口径**：最多 3 张、单张 ≤5MB、只收 jpg / png / webp；附件归属家庭文件，流水只存 `file_id` 引用；不新增财务自己的附件表。
- **步数与时效**：从流水页悬浮按钮进入共 3 步、端到端 ≤5 秒（19.3#1）；保存后 5 秒内流水首行可见（本地乐观插入 + 服务端回执校正）。
- **识别降级**：OCR 与语音只做预填，识别失败原地手输，不新增步骤、不弹错误页；页内不出现「识别失败请重试」这类阻断文案。

## 边界与不做

- 不画数字键盘（系统键盘接管），不做自定义金额键盘。
- 不在本页新建分类或账户；分类与账户维护在「账户与设置」，本页只给选择器。
- 不做多币种换算与汇率（②），币种口径跟随家庭设置。
- 不做「借入 / 借出 / 报销」类型（② 及以后）。
- 不做草稿：返回即丢弃，不写本地草稿、不进同步队列。
- 不做 AI 归类与智能建议（P6），本页只做识别结果确认。
- 不在本页做私密开关的完整权限说明；私密标记与可见性口径在详情页与流水页呈现，本页只提示「标记为私密后只有作者与管理员能读」。
