**一屏说清**：记一笔是财务面唯一的**新建写入页**（二级页，navbar 返回，不带 L2 Tab 与底部五项）。它把一次记账压到 3 步：填金额 → 选分类 → 点右上角「保存」；账户、日期、成员、账本都有默认值。支出 / 收入 / 转账同页互改，改类型、换账户或改金额时先给**余额影响预览**；借入 / 借出 / 报销由对应对象联动生成，本页不提供。OCR 与语音只**预填并逐项确认**，识别失败原地回落手输。保存成功**回流水列表并只提示一次「已保存」**，不停在空白新建页。

## 字段与硬规则

- **金额**：必填，以「分」整数存储，显示按家庭币种；支出为负、负号在货币符号之前，收入为正并带 `+`，转账不带收支符号；最多两位小数。
- **保存反馈只一次**：成功只由流水列表弹一次「已保存」并高亮新行；本页不弹成功横幅、不再叠加 toast。返回不回详情、不停在空白新建页。
- **类型转换**：支出 / 收入 / 转账可互改，改前先看余额影响预览；借入 / 借出 / 报销由借贷与报销对象联动生成，普通交易不得转成这三类。
- **余额影响预览**：选账户、改金额、改类型时同步更新；支出与收入显示一个账户保存后的余额，转账显示转出与转入两个账户；预览不写库，保存成功后才变动。
- **私密口径**：私密是行级可见性，不是新账本；私密交易计入家庭本月收入、支出、结余与统计总量，只从 AA 分摊与跨面归集里排除。其他成员连这一行都收不到，也无法筛选到它；管理员视图不受影响。
- **账户口径**：只列未归档账户；归档只影响今后能不能选，历史流水仍计入统计与净资产；转账的「从」与「到」不能相同，跨币种提示暂不支持自动换算。
- **时间口径**：日期默认今天，可补记过去日期；按家庭时区归日，补记不改变列表时间窗，只影响这一笔的归属期间。
- **归属口径**：成员默认本人，代记时归属被记录成员；账本默认「日常」，是报表分组、不是隔离域；标签多选、家庭共享，用于筛选与报表归集。
- **附件口径**：最多 3 张、单张 ≤5MB、只收 jpg / png / webp；附件归属家庭文件，流水只引用它；不新增财务自己的附件表。
- **步数与时效**：从流水页悬浮按钮进入共 3 步、端到端 ≤5 秒（19.3#1）；保存后 5 秒内流水首行可见（本地先插入 + 服务端回执校正）。
- **识别降级**：OCR 与语音只做预填，识别失败原地手输，不新增步骤、不弹错误页。

## 边界与不做

- 不画数字键盘（系统键盘接管），不做自定义金额键盘。
- 不在本页新建分类或账户；分类与账户维护在「账户与设置」，本页只给选择器。
- 不做多币种换算与汇率（②），币种口径跟随家庭设置。
- 不做「借入 / 借出 / 报销」入口（由借贷与报销对象联动生成，② 及以后）。
- 不做草稿：返回即丢弃；但保存失败时保留本次输入并提供重试，两者不冲突。
- 不做 AI 归类与智能建议（P6），本页只做识别结果确认。
- 不在流水页之外提供账本切换；本页账本只是这笔的归属分组。

## 待复核

- 币种固定人民币、账户余额展示到分，为原型假设；多币种在 ②。
- 日期是否允许未来日期未写明，原型只允许今天与过去。
- 转账跨币种「暂不支持自动换算」的提示文案与降级路径依赖 20.2 的汇率口径，定版前按提示不阻断保存处理。
