**一屏说清**：编辑页带最近修改信息（版本号只在提交与冲突判定用，不上界面），回答「改这一期还是改以后」。字段与新建一致，但多三条硬规则：**改到期日会重新提交到期注册**（保存时按同一条账单重发，旧的到期项被换掉、不会多出一条，页面只提示「日历可能稍晚」）；**删除会连注册一起撤销**，已缴生成的流水不删、余额不动；**暂停只是把提醒从日历与到期中心撤下来**，账单和流水都还在，随时能恢复。保存带版本号，版本落后只弹「这条记录已被修改」，给「查看最新 / 用我的」两条出路，不会悄悄替掉家人的修改。

## 字段与校验（页面级硬规则）

- **版本号**：保存必须带进入时的版本；服务端判定版本落后时只弹冲突层，不自动重试、不悄悄替掉家人的修改；「用我的」写成新版本并重发注册。
- **改期即重发注册**：按同一条账单重新提交，旧到期项被换掉、不产生第二条；只提示「日历可能稍晚」，不给「已生效」的确定答复。
- **改期的边界**：只影响未缴的当前期与之后期次，**已缴过的那一期不跟着改**；已缴流水仍按原日期与原金额。
- **重复互改**：一次性 ↔ 每月只影响之后；已生成的待缴与流水保留；改成一次性后不再排新的到期。
- **提醒提前量**：只有当天 / 提前 3 天两档，可多选、默认都选；改它同样触发注册重发；只按天，不出现小时或分钟选项。
- **暂停**：只撤提醒、不停账单；不生成新一期，恢复后重新注册；文案必须写清「流水与余额不受影响」。
- **删除**：删除账单 + 撤销注册是一个动作；已缴流水与账户余额不受影响；删除不可恢复，不提供回收站；删除层必须指向「暂停账单」这个更轻的选择。
- **金额**：以「分」存储，展示两位小数；改金额不追溯已生成的流水。
- **离线**：保存先入队列并标注「联网再提交注册」，不显示已成功。
- **文案口径**：冲突层与页脚不出现「覆盖」；用户可见处不出现「幂等」「版本号冲突」「状态机」等工程词，统一说「家人刚改过」「查看最新 / 用我的」。

## 边界与不做

- 不做「只改这一期」的例外编辑（分期级编辑属 M2）；本页改的是账单规则，对未缴期次统一生效。
- 不做删除回收站与批量删除；删除走确认弹层，一次一条。
- 不做「重新提交注册」的独立按钮：注册随保存或改期自动重发，详情页只给未注册态的重试入口。
- 不在本页改来源账户的余额，也不做账户归档；账户编辑在账户域。
- 不做字段级历史对比与撤销：冲突层只给「查看最新 / 用我的」。

## 待复核

- 已缴后改金额 / 到期日是否要锁：原型允许改且不追溯已生成流水；若定版要求锁定，本页需对已缴记录置灰这两个字段并给说明。
- 冲突层「用我的」是否要二次确认：金额型数据风险高，原型未加第二层。
- 改期后旧到期项的撤销与新注册是否必须在同一动作内完成（避免短暂出现两个到期项），17.4 未写明，原型按同一条账单重发处理。
- 暂停语义 PRD 未写（4.5.5 只有删除与完成），本页按「撤提醒、留账单」呈现，需产品确认是否保留；若不保留，删除层里的指引要同步改掉。
- 删除是否要保留软删记录供审计（19.3 要求删除与撤销同时成立），原型按不可恢复呈现。
