**一屏说清**：预算页是财务面第三个二级 Tab（流水 / 报表 / **预算** / 账本 / 账户与设置），回答「这个时间窗还能花多少」：顶部进度环与总预算 `¥8,000.00`、已用 `¥6,240.00`、剩余 `¥1,760.00`（78%），下面分「固定与周期」3 项与「日常分类」3 项，行内是图标、名称、已用 / 预算、进度条、百分比与剩余。**已用由服务端按 `period` 汇总，不在前端二次累加**；累计支出**严格大于**阈值才挂「已超支」（默认 100%，可设 80% 预警），刚好用满不算超支。**时间窗切到季或年而只设了月度预算时，整页显「未设该周期预算」，不乘 3、不乘 12（⑬ 红线）**；超支提醒由 HomeOS 家庭消息下发，本页不自建定时器。

## 字段与校验（页面级硬规则）

- **超支判定**：累计支出 **>** 阈值才算超支，`= 100%` 是「用满」不是超支（19.3#4 的边界值样本）；默认 100%，可选 80% 预警，到 100% 再提醒一次。
- **按周期归零**：`used` 的归零语义在 `BudgetPeriod` 周期行上，不在 `Budget` 上；本页只渲染 `used` 与 remaining，不回算、不预扣。
- **同一预算同一周期只提醒一次**：删流水导致回退后不补发、不重复提醒（19.3#4）；提醒走 `finance.budget.exceeded` → HomeOS 的 `budget_alert` 分型，本面不持有推送通道（3.4.2、17.4）。
- **⑬ 红线**：季 / 年档无该周期预算时，`GET /api/finance/budgets` 返回「未设该周期预算」标记，页面不得用月度金额乘 3 / 乘 12 造进度；分类预算与固定预算同一处理。
- **未分配额度**：分类预算合计 ¥7,529.00 与总预算 ¥8,000.00 的差额 ¥471.00 只在 hero 说明里单列，不摊进任何分类行、也不折算成百分比。
- **固定 / 周期预算**：按周期自动带出、计入总预算，用满 100% 不挂「已超支」；只影响进度与提醒，**不锁定记账**（超支后照常能记）。
- **金额**：以「分」整数存储、千分位 + 两位小数、等宽数字；负号在 `¥` 前（`-¥329.00`）。
- **离线**：进度与本机缓存标注「进度显示本机缓存」；新建 / 编辑只排队，不假装成功。

## 边界与不做

- 不做季度 / 年度预算与结转（②）；不做预算模板（②）。
- 不做成员预算：4.5.2 列出该形态，P1 基线只含总预算 / 分类预算 / 固定预算，排期待定。
- 不把总预算按比例摊到分类，也不自动补足未分配额度。
- 不做「预计超支」之类的进度预测（属 P6 的预测能力），本页只报已发生。
- 不在本页通过改流水来「降超支」，也不提供超支确认 / 静音；免打扰在消息与设置侧。
- 不做拖拽调额、不做批量设预算；调额统一进编辑页。

## 待复核

- **删除预算的接口未在 4.8 登记**：4.8 只有 `POST /api/finance/budgets` 与 `GET` / `PUT`，而页面清单要求「删除走弹层」——需补 `DELETE /api/finance/budgets/{id}`，或改为 `PUT is_active=false` 并在文档里改口径。
- 成人成员的删除权：16.3 财务行「M 写」不含删（A 含删），原型按可建可改呈现，删除由服务端拒绝兜底，屏卡未做按角色隐藏。
- 空态一套文案同时覆盖「本周期零预算」与「季 / 年不支持」两种成因，靠时间窗日期与解释区分；是否拆成两套待定。
- 「未分配额度」是否要独立成行：原型只在 hero 说明里列数。
- 固定预算与分类预算是否允许同一分类各一条：原型按「一个分类至多一条预算」处理。
