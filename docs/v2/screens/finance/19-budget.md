## 字段与校验（页面级硬规则）

- **三类预算**：总预算（每月一条）、分类预算（一级分类，二级随父级）、固定 / 周期预算（房租、宽带、物业等按周期自动带出）。分类预算合计 + 未分配 = 总预算，未分配单列，不摊进分类行。
- **金额口径**：总额、已用、剩余一律取服务端，前端不二次累加；负号在货币符号前（`-¥480.00`）。已用超过 100% 时剩余显示负数，写「超 ¥400.00」而不是「剩余 -400」。
- **私密流水**：已用含私密流水，非管理员在已用与总预算同屏注「含 N 条你无权查看的记录」，N 由服务端下发；分类行不展开私密明细。
- **阈值**：提醒线默认 80%，超支线固定 100%；**只有管理员能改提醒线**，其他人看到的阈值只读。刚好 100% 算「用满」，不算超支。
- **超支提醒**：由 HomeOS 家庭消息发出，财务面不自建推送、不设定时器、不重复弹窗；页面只说明「提醒已发出」。
- **周期**：预算按周期归零，结转属后续版本；切季 / 年没有对应预算时给空态，不做任何折算。
- **停用分类**：已设预算的分类被停用后，预算行保留并标注，历史支出照常计入；不静默删预算。
- **金额格式**：一律两位小数、等宽数字；百分比取整显示。

## 边界与不做

- 不做预算结转、不做预算滚存、不做多币种预算。
- 不在本页直接改金额，改金额一律进编辑页。
- 不做「按上月自动生成预算」，也不做「按流水自动调预算」。
- 不在本页推送通知或弹系统通知，超支只留页内说明 + HomeOS 家庭消息。
- 不把「未设该周期预算」显示成「预算 0 元」。

## 待复核

- 固定 / 周期预算与分类预算是否允许同一分类重复设：原型按**一个分类一条**处理，固定项单独成组。
- 总预算小于分类预算合计时是否拦截：原型按**保存时提示、允许管理员确认后保存**，不做硬拦截。
- 非管理员能否新建分类预算：原型按**成人可建**，提醒线仍只有管理员能改。
