# 31 · 登记借出 / 借入

| 项 | 值 |
|---|---|
| 路由 | `finance/loan/create` |
| 期 | ② |
| 面 | 财务 |
| 权限 | 管理员与成人成员可登记（16.3 财务行「M 写」）；儿童、访客不进财务面 |
| 原型 | [finance-loan-create.html](../../prototypes/finance-loan-create.html) |
| 状态帧 | [默认](../../prototypes/finance-loan-create.html) · [分期](../../prototypes/finance-loan-create.html?state=installment) · [校验错](../../prototypes/finance-loan-create.html?state=error) |

**一屏说清**：登记页只做一件事——把一笔家庭外往来写成借贷台账，并生成还款计划。**类型**（借出 / 借入）决定这笔之后看「待收」还是「待还」；**对手方**可点家庭成员，也可直接输入外部姓名（保存后挂「非成员」）；**本金**必须大于 0，**借贷日期**不晚于今天；**是否分期**关闭时填一个约定还款日，打开时填期数与首期日，每期 = 本金 ÷ 期数、余数并到末期。**本金只进借贷台账，不扣账户余额、不生成流水；流水在登记还款时按所选账户生成。**

|---|---|---|

## 字段与校验（页面级硬规则）

- **类型不可改**：`direction`（借出 / 借入）在创建时定死，保存后不提供互换；换方向只能重新登记，避免同一笔在待收与待还之间跳。
- **对手方**：必填，去首尾空格后 1–20 字；可从成员 chip 选，也可自由输入。自由输入**不创建成员、不发邀请**，只存显示名；保存后列表与详情挂「非成员」；同名不去重。
- **本金**：以「分」整数存储，必须 `> 0`；上限留给服务端与家庭币种；只进借贷台账，**不改账户余额、不生成流水**，因此本页没有账户字段。
- **借贷日期**：默认今天（Asia/Shanghai），允许补登过去、禁止未来；它只决定台账起算与还款日下限。
- **非分期**：必须有一个「约定还款日」，且晚于借贷日期；生成 1 期还款计划，到期一次还清。
- **分期**：期数 2–36；首期日必须晚于借贷日期；按每月同日排期，遇该月没有对应日取当月最后一天；每期金额按分取整、余数并到末期，总额必须等于本金；重排只影响未还期次。
- **备注**：≤200 字，全家可见；不参与筛选、报表归集与提醒文案，不填可保存。
- **保存**：服务端写台账与 `RepaymentPlan[]` 在同一事务，再按 17.4 提交逐期到期注册；页面只承诺「已提交」，日历显示可能稍晚；超过 5 分钟未出现可在详情重新提交。
- **离线**：保存先入队并带幂等键，联网后提交；离线时**不生成**本地的还款计划与到期注册，避免重试产生重复期次。
- **金额格式**：币种符号在数字前，千分位 + 两位小数、等宽数字；本金输入不带负号。

## 边界与不做

- 不在本页选账户、不生成「借出 / 借入」流水；流水只在登记还款时按所选账户生成。
- 不做利息、手续费、违约金与汇率换算；一笔借贷只有一个币种（家庭币种）。
- 不做附件、合同照片、借条 OCR。
- 不做先还一部分的「首付」字段；首笔还款在详情登记。
- 不做自定义还款周期（只有每月同日）与不等额期次。
- 不做成员邀请、对外分享、催收链接。
- 不保存草稿；取消即丢弃。
- 不做编辑入口；保存后发现错登，本版只能重新登记（纠正路径见「待复核」）。

## 待复核

- **本金与账户**：任务未给账户字段；原型按「本金不动账户、不生成流水」处理，与 4.5.6 的借入 / 借出流水类型如何衔接需定版。
- **单期「约定还款日」是我补的**：任务只写「分期开关（期数 + 首期日）」，但列表存在「不分期 · 约定 11 月 20 日」的行，非分期必须有到期日；原型在开关关闭时就地展开一个日期字段，需确认字段名与是否必填。
- **月末排期**：首期日为 29–31 日时，后续月份缺日按「当月最后一天」处理；PRD 未写，需与 17.4 的到期注册口径对齐。
- **期数上限 36**：原型按 2–36 校验，PRD 未给上限。
- **成人成员权限**：16.3 为「M 写」，原型允许成人登记任意对手方的借贷；若只允许登记与自己相关的，需要补限制。
- **错登纠正**：原型没有编辑 / 删除借贷入口；若允许修改本金或期次，需补编辑页与 `version` 乐观锁。
