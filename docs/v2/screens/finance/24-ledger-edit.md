**一屏说清**：编辑账本只改**分组定义**：名称、类型（共享 / 项目，没有「私有」）、可见范围、说明。页首带**上次修改人**（版本号只在提交与冲突判定用，不上界面），紧跟一条常驻说明 **「改可见范围不改变历史流水归属」**：本账本已有 21 笔、合计 -¥3,180.00，改范围只改「之后这个分组入口对谁出现」，历史流水一条不动、统计口径不变。**删除只解除分组，流水不会被删**——删除确认层把这件事写在第一句；默认账本「日常」不能删除。保存带版本号，遇到家人的改动只给「查看最新 / 用我的」两条出路，不会悄悄替掉别人的修改。

## 字段与校验（页面级硬规则）

- **只改分组定义**：名称、类型、可见范围、说明；**不给任何已记流水改归属**，也不改任何人的流水可见性。
- **可见范围只控入口**：范围决定分组入口对谁出现；未选中的成员只是筛选器里看不到这个分组，照样按角色与单笔可见性看到该看到的流水。
- **类型只有共享 / 项目**：不提供「私有」，也不提供任何「仅本账本成员可见」的开关（那会把分组升级成权限边界）。
- **删除 = 解除分组**：删除后流水 `ledger_id` 置空、**流水不删**，金额仍计入本月支出与报表；删除入口只在编辑页弹层，一次一条、不可恢复（P1 不做回收站）。
- **私密流水**：历史说明卡的「本月 N 笔 · 合计」含私密流水；非管理员在该合计位同屏注「含 N 条你无权查看的记录」，N 由服务端下发，N=0 时不显示注记。
- **默认账本不可删**：「日常」由系统自动创建；该页对默认账本应隐藏或置灰删除行并说明原因（原型以「旅行」为例，删除行脚注写清这条规则）。
- **乐观锁**：保存带进入时的版本号；版本落后返回冲突，只给「查看最新 / 用我的」，不静默重试、不合并字段。
- **离线**：保存先入队并标注「联网再提交」，不显示已保存；冲突判定在联网提交时进行。

## 边界与不做

- 不做账本级可见性开关与「私有」类型。
- 不做跨账本搬运、批量改归属、账本合并；改归属只能在单笔流水详情里逐笔改。
- 不做删除回收站与批量删除。
- 不做账本排序、自定义图标配色、账本嵌套。
- 不做成员权限设置：角色与可见性在 HomeOS。
- 不做 AA 分账与结算配置（②，M2）。

## 待复核

- 默认账本「日常」的编辑页是否整体只读（原型按「可改范围、删除置灰」呈现），需定版。
- 409 冲突层「用我的」是否需要二次确认：原型未加第二层。
- 删除账本后，流水详情里是否要留一句「原分组已解除」的痕迹，原型按流水无感处理。
- 账本是否要保留「已结束项目」状态：原型不设状态字段，结束只靠改名与说明表达。
