**一屏说清**：账本页是财务面第四个二级 Tab，回答「这笔钱归到哪个分组看」。页首常驻一句 **「账本是分组，不是隔离」**——账本只决定流水与报表按什么范围归集，谁能看到什么仍由角色与单笔流水的可见性决定，**切账本不搬动任何已记流水**。下面按共享（3）/ 私有（2）/ 项目（2）三组切换（同页切换、不新增路由），每张卡片是名称与类型、「当前」标记、成员头像排、本月笔数、本月支出与「切换后」影响范围。**本页不放时间窗条**：账本是范围维度，不是时间维度。切换只换过滤范围；新建账本不会把历史流水搬进去。

## 字段与校验（页面级硬规则）

- **账本不是隔离域**：`Ledger` 只存分组定义与成员范围（4.7）；页面任何文案都不得写成「私有空间 / 成员看不到 / 隔离」，私有类型的解释统一为「只归到你自己名下记账」。
- **可见性不由账本决定**：谁能看到哪笔流水，由 16.3 角色矩阵 + 16.4 字段级 / 行级可见性决定；切账本不授予、也不收回任何查看权。
- **切换只换过滤**：切换改的是 `ledger_id` 过滤条件，流水条数与报表分组变、数据一条不动；不搬动 `Transaction.ledger_id`，历史归属不变。
- **当前账本唯一**：「当前」标记只有一个；切换后标签搬走，流水页、报表页与首页财务格读同一个当前账本。
- **成员范围语义**：范围决定「谁可以往这里记账」，不决定「谁能看到」；私有类型的范围为本人。
- **笔数与金额**：本月笔数与本月支出取服务端按当前月汇总的值；合计与各卡片**同源，前端不二次累加**。
- **无时间窗条**：账本页不渲染 `period` 条——账本是范围维度；卡片上的笔数固定标「本月」，切时间窗请去流水 / 报表 / 预算。
- **离线**：笔数显示本机缓存并标注；切换账本在离线时只切本地过滤，不假装服务端已同步。

## 边界与不做

- **不做账本级权限开关**：不提供「仅本账本成员可见」这类勾选，那会把分组升级成权限边界（4.5.1、16.3 明令禁止）。
- 不做跨账本搬运、批量改归属、账本合并；改归属只能在单笔流水详情里逐笔改。
- 不做账本内嵌报表；要看图表切到报表页并带账本过滤。
- 不做账本排序、自定义颜色与图标；图标与配色由 `type` 决定（共享 / 私有 / 项目）。
- 不做 AA 分账与结算中心（②，M2）；本页不出现「谁欠谁」。
- 不做账本删除入口（删除在编辑页的弹层里），也不做归档账本。

## 待复核

- **16.5 与账本语义冲突**：16.5 写「成员退出：其个人偏好与私密账本内容随退出删除」，而 4.5.1 / 16.3 写账本不是隔离域、私有只是分组。需明确退出时删的是「私有分组定义」还是「分组内的流水」，原型按「账本不持有数据、流水归属人不变」呈现。
- **「日常」与「共享」的 AA 边界**：16.3 写「仅标记为共享的账本参与分摊，日常账本不摊」，但日常的类型也是共享。是 `type` 维度还是单独的 `allow_split` 标记，原型未给 AA 开关，需定版。
- 「本月笔数」固定按当前自然月，不跟随 shell 的 `period`：若产品要求跟随时间窗，需先给账本页加时间窗条（当前明确不加）。
- 当前账本是否跨会话记忆、以及是否按成员各自记忆：原型按家庭级一个当前账本呈现。
- 账本数量上限与同名策略：原型允许同名（靠类型与标签区分），未设上限。
- 「本月合计 -¥29,070.40」是否为 7 个账本的支出合计（不含转账与收入）：原型按支出合计呈现，口径待定。
