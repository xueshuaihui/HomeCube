**一屏说清**：编辑账户改的是「账户怎么称呼、算不算负债、是不是默认、备注」，**不改余额**——余额由流水累计，页内明写「余额由流水决定，不能直接改；需要调整请记一笔调整流水」。页首带 `version`（版本 7）与「上次由妈妈修改 · 10 月 12 日」；保存带 `version`，409 时弹「这条记录已被修改」；归档要求余额为 0，否则服务端拒绝并就地给转账说明。**归档后账户不出现在默认账户位，但历史流水仍计入报表与净资产。**

## 字段与校验（页面级硬规则）

- **余额只读**：不提供余额输入；调整走调整流水或转账；避免账户合计与净资产长期不一致（4.5.9）。
- **`version` 必带**：页首展示版本与最后修改人；保存带 `version`；409 只给两条出路，不自动合并。
- **默认账户唯一**：`is_default` 每家庭至多一个；在此打开会自动取消原默认；关闭后记账默认位为空，不自动改选其他账户。
- **改名与改类型**：历史流水按账户 id 归属，不按名称；改类型只影响之后的记账归类与统计分组，不回改历史。
- **归档条件**：余额必须为 0；非 0 时前端禁用确认并说明，服务端同样拒绝（4.5.9、19.3#10）；归档可逆，历史流水仍计入报表与净资产。
- **信用卡字段**：账单日 / 还款日 ②（M2）才可编辑，P1 只读展示，供列表做到期提示。
- **备注**：≤120 字，仅家庭成员可见；不进入记账选择器。
- **离线**：保存先排队并带幂等键与 `version`；冲突在联网后按服务端返回处理，不本地覆盖。

## 边界与不做

- 不做余额直接编辑、余额校准、期初重算；这类操作只能生成调整流水。
- 不做账户删除与合并；清理走归档（余额需为 0）。
- 不在本页完成归档确认：本页只展示条件与入口，确认与恢复在归档页。
- 不做头像 / 颜色 / 排序字段；账户顺序由类型分组与默认标记决定。
- 不把私密流水的明细带进本页；余额是账户级合计。

## 待复核

- 归档入口在余额为 0 时是直接跳归档页还是本页弹确认，原型按跳归档页处理。
- 成人成员对账户的写权：16.3 财务行记「M 写 + R 全家庭读」，账户无归属人语义，原型按管理员专属。
- 409 冲突只比较名称与版本；若同时改类型 / 默认标记，是否逐字段比较未定，原型只展示名称对比。
- 关闭默认账户后是否必须立刻指定另一个默认账户，PRD 未要求，原型允许留空。
