**一屏说清**：新建账本只填四件事——**名称**（必填、≤12 字）、**类型**（共享 / 私有 / 项目）、**成员范围**（多选，就地展开不跳页）、**标签**（多选，可临时新建），另可写一句说明。页首常驻 **「账本是分组，不是隔离」**：它只把流水与报表按范围归到一起，不建权限边界；**成员范围决定谁往这里记账，不决定谁能看到什么**。选「私有」时成员范围自动收敛为本人并把其他人置灰。底部一句写清：**新建账本不会搬动已有流水**，之后记账时选它才会落进来。

## 字段与校验（页面级硬规则）

- **名称**：必填，`1–12` 字，裁首尾空白；同名允许；改名的入口在编辑页，`ledger_id` 不变。
- **类型**：`type` ∈ 共享 / 私有 / 项目；只影响记账入口与分组展示，**不构成权限边界**；选私有 → 成员范围自动收敛为本人并置灰，切回共享 / 项目后需重新勾选（不自动恢复原范围，避免误加人）。
- **成员范围**：至少 1 人（本人恒在）；只决定「谁可以往这里记账」，不决定「谁能看到」；无账号成员按其监护人代管呈现。
- **标签**：复用家庭标签集，不新建第二份标签表；标签不参与权限判断；`新建标签` 在 P1 未交付，只能 toast 说明路径。
- **说明**：≤60 字，仅家庭成员可见，用于区分同名账本；不进入流水正文。
- **不搬历史**：创建只写 `Ledger` 分组定义，不给任何 `Transaction` 改 `ledger_id`；历史流水仍留在原账本。
- **不自动切换**：新建成功只回列表，不把新账本设为当前账本，避免用户以为「记账已经记到新账本」。
- **离线**：保存先排队并带幂等键；账本列表以服务端返回为准。

## 边界与不做

- 不做账本级可见性 / 白名单开关（那会变成隔离域）：不提供「仅本账本成员可见」这类选项。
- 不做新建时直接迁移流水、导入历史、按标签批量归集。
- 不做成员权限设置：成员角色与可见性在 HomeOS，账本只消费成员列表。
- 不做账本嵌套 / 父子分组、不做账本排序与自定义图标配色。
- 不做标签管理（改名 / 合并 / 删除）；本页只有多选与未交付的「新建」。
- 不做 AA 分账与结算配置（②，M2）。

## 待复核

- **私有类型的成员收敛**：切回共享 / 项目时是否恢复原勾选，原型按「不恢复、需重选」处理（防误加人），需定版。
- **至少一名成员**是否要硬校验：原型按「本人恒在」处理，不额外报错。
- **新建标签**的 P1 路径：原型只给 toast，实际入口在记账页；标签集的沉淀规则（何时进家庭标签集）待产品确认。
- **同名账本**允许但列表不易区分：原型靠「类型 + 标签 + 说明」区分，若要求唯一则要加查重与提示。
- 保存后是否跳进新账本：原型不自动切换（保持当前账本），需确认是否给「去这个账本看看」的次级入口。
