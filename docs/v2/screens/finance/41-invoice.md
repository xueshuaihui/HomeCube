**一屏说清**：家庭发票与报销的收件箱。待报销 / 已报销 / 全部三组同页切换，Tab 上带张数；每行给发票抬头、金额、日期、状态与缩略图，未关联流水或 OCR 待复核在副标题里点明。底部「添加发票」是唯一新建入口。

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 停在待报销：3 张（京东 `¥1,198.00` 已关联 / OCR 待复核、中国石化 `¥260.00`、滴滴 `¥46.50`）；汇总 `¥1,504.50` 与本月已报销 `¥370.00`；底部「添加发票」 |
| 已报销 | 切 Tab 或深链 | Tab 停在已报销，只显示 2 张：美团 `¥328.00`、顺丰 `¥42.00`，均带「已报销」与报销日期；点行进详情的已报销态 |
| 空 | 待报销为 0 | Tab 计数改为待报销 0 / 全部 2；隐藏汇总、列表与底部按钮，显示「待报销里没有发票」+ 拍照识别说明 +「添加发票」 |

## 字段与校验（页面级硬规则）

- **状态**：`待报销` → `已报销`（提交生成报销流水）→ 可撤销回待报销；状态只影响记账，不涉及真实打款，也不改发票原件。
- **金额**：以「分」存储，展示两位小数与千分位；发票金额与关联流水金额不一致时提示核对，不自动改票。
- **汇总**：待报销与已报销分列，按票面金额合计；未关联流水的发票仍计入待报销金额与张数，但不允许提交。
- **关联**：一张发票只关联一笔支出流水，一对一同页展示；私密流水不能被关联；删除发票只解除引用，家庭文件里的原件保留。
- **缩略图**：列表给发票缩略图与类型（电子票 / 纸质票）；原件在家庭文件，列表不复制附件。
- **Tab 计数**：计数随状态实时变化；切换 Tab 不改变排序，组内按开票日期倒序，「全部」把两组按日期倒序排在一起。
- **离线**：显示本机缓存的发票与缩略图；新增与报销动作走待同步队列。

## 边界与不做

- 不做真实报销打款、企业报销对接、发票查验接口；报销只是账本里的一笔报销流水。
- 不做同一发票重复录入：以发票号码去重，重复时提示已存在并跳到原票。
- 不在列表做行内提交、行内关联或行内删除；所有动作进详情，避免误触。
- 不支持多币种发票与跨家庭共享；币种随家庭设置。

## 待复核

- 入口：M1 流水顶栏「更多」尚未加入「发票与报销」（本批不改 M1 页面），M2 收口时需补一行次级入口。
- 「全部」只有页内 `data-tab`，没有独立深链；是否需要 `?tab=all` 供外部跳转，待路由规范确认。
- 列表缩略图为统一的票券图标占位，不是真实发票图；正式实现需接家庭文件缩略图与加载失败兜底。
- 待报销汇总是否应排除未关联流水：原型按票面金额全计，若产品要求只计可提交金额，需同步改汇总与文案。
