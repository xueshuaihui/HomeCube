**一屏说清**：这是分类顺序的唯一编辑处。一个顺序**同时供记账选择器、报表图例与筛选使用**，保存一次三处一起变；拖动只改顺序，不动分类归属与历史流水。支出与收入各自排，二级在各父级内部排。停用项保留原位，重新启用不会跳到末尾。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 返回 | 点击 | 有未保存的拖动时先问「放弃这次调整？」，不静默丢弃；没改过直接回分类管理 | `finance/category/index` |
| ② | 拖拽排序行 | 按住行首手柄 200ms 后拖动 | 整行抬起高亮，原位置显示插入条，页首提示落点；松手即重新编号，**不写库**；只改顺序，不改分类归属与历史流水 | 留在本页 |
| ③ | 保存排序 | 点击底部按钮 | 整单一起保存；保存中按钮转菊花、两个列表锁定不可拖；成功后三处一起换顺序，按钮变「已保存」；不出现部分成功 | 留在本页 |

| ⑤ | 重试 | 加载失败态点击 | 只重新读取分类与顺序，不改动任何设置；仍失败保持整页失败态，不拿本机旧顺序拼一份 | 留在本页 |

## 状态矩阵

| 态 | 触发 | 呈现 |
|---|---|---|
| 默认 | 进入本页 | 支出 6 个一级（餐饮 -¥3,240.00 / 居住 -¥4,200.00 / 交通 -¥860.00 / 购物 -¥1,480.00 / 教育 -¥2,100.00 / 医疗 -¥600.00）与收入 2 个一级（工资 +¥16,800.00 / 理财 +¥1,200.00）分两段；行含手柄、图标、名称、预置/自定义标签、二级个数、本月笔数、序号；页首说明三处共用 |
| 拖拽中 | 长按手柄并移动 | 交通被抬起、描边高亮，其余行让位，插入条落在「餐饮」与「居住」之间；页首提示「松手后放到……之间」；松手前新顺序不写库 |
| 保存中 | 点「保存排序」 | 按钮加载态且不可重复点，两个列表变淡且手柄不可拖；提示「整单一起保存，不会只存一半」；不展示部分成功 |
| 已保存 | 保存成功 | 页首绿色提示「记账选择器、报表图例、筛选已一起换成新顺序」；交通落到第 2 位并重新编号 1..N；按钮变「已保存」不可再点，页脚注「已同步到记账、报表与筛选三处」 |
| 被家人改过 | 保存时顺序已被他人调整 | 底部弹层：标题「排序刚被家人调过」，并列对方与我的顺序；按钮「用我的 / 保留对方」，整单处理，不静默写入 |
| 空 | 没有可排序的分类 | 整页空态「还没有可以排序的分类」+ 说明 + 「去新建分类」；不画空编号列表 |
| 加载中 | 首次进入 / 重试后 | 骨架贴合「说明 + 两段列表」形状；底部保存不出现，避免空顺序被提交 |
| 加载失败 | 分类或顺序读取失败 | 整页失败态：标题「分类没有加载出来」+ 说明 + 「重试」；底部保存不出现 |
| 离线 | 无网络 | 顶部离线条「当前离线 · 新顺序先存在本机，联网自动保存」；可拖动并保存到本机队列，联网后自动提交，冲突仍走「保留对方 / 用我的」 |

## 字段与校验（页面级硬规则）

- **只改顺序**：不改分类的归属、类型、启停，因此历史流水、报表归属与预算口径都不变。
- **排序域**：支出与收入各自排序；二级顺序在各父级内部排，不与一级混排。
- **停用项保留位置**：停用分类仍列在本页并占位；重新启用后回到原序号，不自动置末。
- **整单保存**：一次提交整套顺序，不做「部分行已保存」；期间被家人改过就整单交给用户选「保留对方 / 用我的」，不用「覆盖」。
- **离线**：新顺序先存本机，联网自动提交；离线时保存按钮可用但不假装已同步，页脚不显示绿色已保存提示。
- **展示口径**：序号为本段内 1..N、跨段重置；笔数与金额按本月统计，负号在货币符号之前（`-¥4,200.00`），收入用 `+¥`。

## 边界与不做

- 不做跨父级拖动（拖动只改顺序，不搬分类归属）。
- 不做长按多选、批量置顶、「恢复默认顺序」。
- 不在本页新建、改名、停用分类（回分类管理或编辑页）。
- 不在本页展开二级排序，避免与两级结构混淆。

## 待复核

- 拖动触发是「手柄长按」还是「整行长按」：原型按**手柄长按 200ms**，整行保留给滚动。
- 保存失败但不是被家人改过时，是否保留本机新顺序：原型按**保留并提示重试**。
- 停用项是否仍参与连续编号：原型**保留连续编号**，仅置灰并标「已停用」。
