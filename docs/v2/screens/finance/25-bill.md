**一屏说清**：账单是二级页（navbar 返回，不带 L2 Tab 与底部五项），回答「这个月还要交什么、交过什么、哪笔已经晚了」。顶部「本月待缴」只统计**本月到期且未缴**的账单（逾期计入、11 月到期的不计入），下面按 **逾期 / 待缴 / 已缴** 三组列：行内是账单名、金额（`-¥380.00`，负号在 `¥` 前）、到期日与来源账户，逾期行补「逾期 N 天」并走 danger。行内「标记已缴」一步写状态并生成一笔支出流水、提交 `finance.bill.paid` 回写；toast 只说「回写已提交，日历可能稍后同步」，**不承诺日历立刻消失**，也**不做任何账单自动导入与自动扣款**。

## 字段与校验（页面级硬规则）

- **金额**：以「分」整数存储、按家庭币种展示；账单一律按支出呈现，负号在 `¥` 前（`-¥380.00`），等宽数字与千分位。
- **「本月待缴」口径**：按家庭时区取当前自然月内 `due_at` 且 `status=unpaid`；**逾期并入本月待缴**，下月到期单列为「另有 N 笔」，不摊进本月数字；四组数字（汇总 / 逾期 / 待缴 / 已缴）由服务端一次算好，前端只渲染。
- **分组与排序**：逾期 → 待缴 → 已缴；组内按 `due_at` 升序；已缴组按缴纳时间倒序。逾期分组标题、笔数、金额与「逾期 N 天」全部走 danger，其余组用中性色。
- **标记已缴**：写状态与生成流水是同一事务，幂等（同一账单只生成一条支出流水）；按钮点击后立即本地置「已标记 · 同步中」，不等跨服务结果；失败回滚并 toast，不留下假已缴。
- **到期注册**：账单保存时已提交 `{code}.due.registered`，列表只如实写「到期已注册到家庭日历」，触发与投递属日历面与家庭消息，**本面不自建定时器**。
- **不做自动导入 / 自动扣款**：「自动扣款标记」只作人工确认参考，不从银行、支付宝、微信导入任何账单（4.5.5 明确不做）。
- **离线**：缴纳状态显示本机缓存并标注时间；离线点「标记已缴」进本地队列，文案改「联网后提交回写」，不假装已同步。

## 边界与不做

- 不做账单自动导入、自动扣款、批量标记已缴、滑动删除；删除在编辑页的确认层里走 `finance.due.revoked`。
- 不做「发票」筛选与归档：发票属 P1-M2（4.5.5），本期不出现入口。
- 不在列表页内联展开详情、不做下拉刷新与分页加载动画；列表一次给全量分组。
- 不显示注册状态徽标：注册状态只在详情页只读展示，列表页用一句常驻说明覆盖，避免每行都挂一个「同步中」。
- 不提供「撤销已缴」；已缴行的误操作纠正走详情页与流水页，具体路径见 [26 账单详情](./26-bill-detail.md) 待复核。

## 待复核

- 逾期帧的样本口径：为同时展示「逾期分组 + danger」，逾期帧把物业费改按 10 月 26 日到期、并补一笔车险续费（10 月 28 日），两帧数字各自自洽但不要求跨帧相加；定版样本需按同一批账单只推时间。
- 成人成员能否标记**他人创建的**家庭账单已缴：16.3 记「M 写」，按字面只能写本人账单，但家务场景常由任一成人代缴；原型不按作者置灰，需定版。
- 已缴行是否可撤销：原型只读，未给「撤销缴纳」；若允许撤销，需同时撤销 `finance.bill.paid` 回写与生成的流水，风险较高。
- 「本月」的边界（自然月 vs 账单周期）与首页财务格是否同口径：原型按自然月，需与首页格对齐。
