# 10 · 新建账户

| 项 | 值 |
|---|---|
| 路由 | `finance/account/create` |
| 期 | ① |
| 面 | 财务 |
| 权限 | 管理员；成人成员只读（直接访问由服务端拒绝，不显示表单）；儿童、访客不进财务面。默认账户只有管理员能改（16.3 财务行注） |
| 原型 | [finance-account-create.html](../../prototypes/finance-account-create.html) |
| 状态帧 | [默认](../../prototypes/finance-account-create.html) · [负债账户](../../prototypes/finance-account-create.html?state=liability) · [校验错误](../../prototypes/finance-account-create.html?state=error) · [离线](../../prototypes/finance-account-create.html?state=offline) |

**一屏说清**：新建账户只问**名称、类型、负债开关、初始余额、备注**，币种固定家庭币种（多币种 ②（M2））。类型四选一，**选信用卡自动打开「计入负债」**，并出现**账单日与还款日**；初始余额只是起点——**初始余额不产生流水**，保存后余额全靠流水累计，不能在本页或编辑页直接改数。**家里的第一个账户会自动成为默认账户**，之后换默认只有管理员能操作。

## 交互表

| # | 元素 | 触发 | 反馈 | 去向 |
|---|---|---|---|---|
| ① | 取消 | 点击顶栏 | 回账户列表；未保存内容直接丢弃，不落草稿、不入离线队列，也不产生余额变动 | `finance/account/index` |
| ② | 名称 | 输入 | 必填、上限 24 字，只裁剪首尾空白；同名账户允许存在（靠类型与尾号区分）；为空时红框 + 行内「请填写账户名称」，不弹全局错误 | 留在本页 |
| ③ | 类型 | 点现金 / 储蓄卡 / 信用卡 / 其他 | 四选一；选信用卡会自动打开负债开关，并展开账单日与还款日；也可手动关掉负债（例如额度为 0 的副卡），账单日与还款日随之收起；改类型只影响之后的归类，不改历史 | 留在本页 |
| ④ | 负债开关 | 切换 | 打开后余额计入总负债、净资产按「资产 − 负债」算，字段名变「初始待还」，并出现账单日与还款日（1–28 日）；关掉只改统计归属，不删流水，已填的账单日保留但不生效 | 留在本页 |
| ⑤ | 初始余额 | 输入 | 只作账户起点，不产生流水、不改历史报表；可填 0；为空或非数字时红框 + 行内「请填写有效金额，可填 0」；负债账户按正数录入待还金额 | 留在本页 |
| ⑥ | 保存 | 点击底部 | 名称或金额不合法时只标红字段并给行内错误，不弹全局层；成功回账户列表，新账户排在所属分组末尾；家里还没有账户时，这个账户自动成为默认账户 | `finance/account/index` |

## 字段与校验（页面级硬规则）

- **名称**：必填、≤24 字；不做唯一性校验（同名允许），只裁首尾空白；改名不影响流水归属（按账户 id）。
- **类型**：现金 / 储蓄卡 / 信用卡 / 其他，决定分组与图标；选信用卡自动打开负债，也可手动关闭。
- **币种**：P1 只读家庭币种（CNY），不提供切换；多币种账户 ②（M2）；新建账户不改历史流水币种。
- **负债开关**：控制是否计入总负债；打开会计入「总负债」，净资产按资产 − 负债；信用卡的余额按「待还」展示。
- **账单日 / 还款日**：只在负债账户出现，1–28 日；该月没有这一天时，当月不提醒也不自动顺延，不补生成；与周期记账的月末规则一致。
- **初始余额**：以「分」存储，可填 0；**不产生流水**、不改历史报表；信用卡填「初始待还」，正数录入，展示时按负债口径计入。
- **默认账户**：家里的第一个账户保存后自动成为默认账户；后续换默认只有管理员能改，新建页不提供默认开关。
- **备注**：≤120 字，仅家庭成员可见，不出现在记账选择器。
- **保存**：`POST /api/finance/accounts`；创建不产生流水。
- **离线**：保存先排队；名称与金额校验在本地完成，不依赖服务端。

## 边界与不做

- 不做多币种、开户行、卡号字段；尾号等信息写进备注。
- 不做「初始余额记一笔流水」：初始余额只是账户起点，避免与历史混在一起。
- 不做同名冲突拦截，也不做账户复制。
- 不在新建时归档；归档在归档页，余额需为 0。
- 不在新建时手动设默认；第一个账户自动成为默认，之后只有管理员能改。

## 待复核

- 信用卡「初始待还」的符号：原型按正数录入、汇总时计入负债，接口字段是否同为正值待还待确认。
- 新建账户是否允许成人成员操作：16.3 财务行记「M 写」，账户无归属人语义，原型按管理员专属。
- 允许「信用卡 + 负债开关关闭」是否合法（额度为 0 的副卡）：原型允许，未在 PRD 禁止。
- 账单日 / 还款日只到 28 日，是否要允许 29–31 日：原型按 28 日封顶，避免月末无此日时反复解释。
