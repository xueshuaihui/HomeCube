**一屏说清**：报表只有四个视图——**概览、趋势、分类、成员**，同页切换不新增路由。一个时间窗（月 / 季 / 年）同时驱动四视图与全部合计；概览给收入、支出、结余三数与环比，外加累计余额，趋势给分月柱状。本月：收入 ¥18,000.00、支出 ¥12,480.00、结余 ¥5,520.00，共 186 笔；其中私密 4 笔 ¥860.00 **计入全部合计**。P1 不做商户维度，页面里也没有商户入口。

## 字段与校验（页面级硬规则）

- **时间窗口径**：`YYYY-MM` / `YYYY-Qn` / `YYYY` 三档，与流水、预算、首页同源；切档后四视图全部重算，不允许某一视图停在上个周期。
- **私密计入合计**：收入、支出、结余、分类、成员、趋势柱全部包含私密流水；非管理员在每个合计旁看到「含 N 条你无权查看的记录」（N 由服务端给），**不扣减、不展开、不可按私密筛出**。AA 分摊与跨面汇总才排除私密。
- **环比**：对比上一自然期；上期为 0 或无数据时显示「无对比期」，不按 0 做除法，也不显示 100%。
- **累计余额**：服务端逐期累加后下发，前端只画不再加；时间窗切换时按所选粒度重取。
- **分类顺序**：与分类排序页共用同一顺序；二级不单列；停用分类的历史支出照常上榜。
- **成员口径**：按「谁的流水」汇总，代人记账算被记录成员；无账号成员记在代管人名下；访客与儿童按 16.4 裁剪。
- **无商户维度**：P1 不提供商户排行、商户筛选或「按商户看」入口；搜索里也不新增商户聚合。
- **金额**：负号在货币符号前（`-¥12,480.00`），收入用 `+¥`；一律等宽数字。

## 边界与不做

- 不做商户维度、不做自定义报表、不做报表订阅或定时推送。
- 不在报表页直接改流水，只跳转到带筛选的流水页。
- 不在空周期画 0 值图，也不把「没有数据」说成「支出 0 元」。
- 不在本页放预算入口（预算在预算页），也不在报表里推 HomeOS 通知。

## 待复核

- 趋势在季 / 年档是「分季 / 分年柱」还是仍按月聚合：原型按**分季 / 分年**处理。
- 非管理员是否能看到「成员排行」里他人的合计：原型按**能看到合计与占比，但看不到私密明细**。
- 分类排行是否需要「其他」兜底项：六项已覆盖全部支出，暂不设兜底。
