**一屏说清**：财务面一级页，一个路由装四个视图——**概览 / 趋势 / 分类 / 成员**，共用顶部月/季/年时间窗。概览回答「这个月怎么样」（收支三数 + 环比 + 累计余额），后三视图回答「钱花在哪、谁花的」，每一处都能下钻到**流水筛选态**，右上角把当前时间窗带去导出。

## 字段与校验（页面级硬规则）

- **金额口径**：支出为负、负号在 `¥` 之前（`-¥8,632.40`），收入为正（`¥12,480.00`），结余可正可负；一律等宽数字，千分位。
- **环比口径**：上期随粒度走（上月 / 上季 / 上年）；上期为 0 或无数据时显示「无对比期」，不做除法、不显示 ∞ 或 0%。
- **颜色语义**：收入上升、支出下降用 success；支出上升用中性色（花得多不等于「好」）；结余下降或为负用 danger；不允许用颜色单独表意，箭头与百分比必须同时出现。
- **累计余额**：服务端按账户余额逐期累加，前端只画；不在客户端把月度结余再累加一遍（19.3#9）。
- **分类一致性**：图例、排行与筛选 chips 的分类顺序都取 `sort_order`，与排序页同源；停用分类不隐藏、历史照常统计。
- **四视图同路由**：视图切换只改页面状态，不改 URL 路由；深链用 `?state=trend|category|member|empty` 复原。
- **离线**：显示本机缓存报表并标「截至 08:10」，不假装实时；缓存不参与写操作。
- **空周期**：不画 0 值图表、不给伪环比；空态优先于四个视图。

## 边界与不做

- 不做自定义起止日（月/季/年三档；自定义区间只在导出页出现）。
- 不做图表缩放、逐点 tooltip、多账户对比与预算叠加线。
- 不做报表收藏、订阅或周期推送。
- 不导出图片；导出统一走 CSV / Excel 的导出页。
- 不在本页改分类、账户或预算。

## 待复核

- 趋势在季/年档的分季、分年柱：原型只画近 6 个月，切换粒度后不换图，文案已注明。
- 分类排行是否下钻到二级：原型只到一级，二级明细走流水筛选。
- 成员维度是否含儿童与访客：原型列 4 位家庭成员，访客不进财务面（16.3）。
- 累计余额折线的起点：原型从当年 1 月画起，跨年是否改为近 12 个月待定。
