# 跨面 · 验收口径映射（PRD 19.2 / 19.3 / 19.4）

> 本文件把 PRD 十九章的验收口径逐条映射为本仓库的 case 与既有脚本，作为验收追溯矩阵。
> **与 `requirements.md` 的边界**：19.x 是**判定口径**（怎么测），不是需求条目；需求点清单因此不重复登记 19.2 的 14 条与 19.3 的 10 条，只在本文件维护，避免两处漂移。**19.4 日历面（7 条）是例外**——它是新增面的唯一判据来源，已逐条登记为需求点 `R-194-01..07` 并在本文件同时维护映射。
> 本文件的 case 列与 `requirements.md` 的承接关系互为索引：需求点看「该做什么」，本文件看「按什么判」。
> 19.2 = HomeOS 与跨面通用（14 条，底座段 P1-M1 判定）；19.3 = 财务面（10 条，M1 末判 #1-#5/#7-#10、M2 末判整面含 #6）；19.4 = 日历面（7 条，㉚ 新增、随本面在 P1-M1 判定）。
> 本文件 case 前缀 `X-ACC`。性能/可用性类（#13/#14）**不重造 case**，直接指向 `make soak` / `make inject-faults` / `make check-device-lock` / `make restore-drill`。
>
> **判定纪律**：映射到的 case 若状态为 `未实现`，该验收项当前应判 **「未测」而非「通过」**——不得因为「有脚本、有接口」就记为达标。当前受影响：#7（L2/L3 加密未实现）、#14（设备锁未实现）、#4（搜索索引无写入方，端到端拿不到结果）、**19.4 七条全部未测**（`svc-calendar` 与其分包不存在）。
