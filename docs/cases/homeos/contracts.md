## HOM-CT-001 · 跨 schema 直连在数据库账号层即被禁止
- 关联需求：PRD 17.2:2034（只有归属服务可写这些表；他服务读取一律走 17.3 三种方式；**跨 schema 直连在数据库账号层即被禁止，不是靠约定**）、17.6:2106（跨服务外键一律驳回）
- 类型：安全 | 优先级：P0 | 建议归属 Sprint：S1
- 前置条件：两服务使用各自专属账号连接同一 Postgres 集群
- 步骤：
  1. 用 `svc-finance` 账号尝试读 `homeos_*` 表
  2. 用 `svc-homeos` 账号尝试写 `finance_*` 表
  3. 检查是否存在跨 schema 物理外键与共享账号
- 预期结果：
  - 两组越权访问均被数据库拒绝（权限错误，不是应用层拒绝）
  - 跨 schema 外键数 = 0；两服务不共用数据库账号
  - 业务 handler 内无裸 SQL 跨 schema 查询
- 实现现状（快照）：待自动化（需以两个真实账号连库断言；ADMIN 账号下无限权限会掩盖问题）
- 执行状态：未执行

## HOM-CT-002 · 跨面只读接口：超时 ≤300ms、至多重试 1 次、必须有降级
- 关联需求：PRD 17.3:2052（归属服务提供，鉴权走共用 SDK；调用方**必须设超时 ≤300ms、至多重试 1 次、并有降级展示**）
- 类型：异常 | 优先级：P0 | 建议归属 Sprint：S2
- 前置条件：可对被调用服务注入延迟（300ms / 800ms / 超时三档）
- 步骤：
  1. 注入 300ms 延迟，观察调用方行为
  2. 注入 800ms 延迟（超时），统计重试次数与最终表现
  3. 关闭被调用服务，检查降级展示
- 预期结果：
  - 超时阈值 ≤300ms 生效；重试次数 ≤1（不得无限重试或指数放大）
  - 超时/不可达时**返回降级值并标注时效**，不抛 5xx、不白屏
  - 降级发生被计入指标（22.5 跨服务调用失败两侧计数）
- 实现现状（快照）：待自动化（无延迟注入用例）
- 执行状态：未执行
