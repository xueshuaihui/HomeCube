- 关联需求：PRD 18.2:2169（已启用但服务不可达或分包校验失败 → 与可用格同尺寸同结构，去色 + 最后一次值 + 时效「截至 HH:MM」+ 重试位）、18.2:2171（重试的语义是定死的三件事：① 重请求一次 `home/summary`，不是单独打该面接口；② 若因分包缺失同时重走按需加载；③ 失败保持原态与最后值，不弹错误页、不清缓存；重试是读操作，不进幂等键与离线队列）

- 步骤：
  1. 观察格子呈现（尺寸、结构、去色、时效标注、重试位）
  2. 点重试，抓包记录请求

- 预期结果：
  - 格子与可用格**同尺寸同结构**，带「截至 HH:MM」与重试位
  - 重试只发一次 `home/summary`（**不打该面接口**）；分包缺失时同时重走按需加载
