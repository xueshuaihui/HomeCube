## HOM-NAV-001 · 顶栏恒为一行：家庭切换器 + 两个动作位，中段无面切换器
- 关联需求：PRD 17.1:1901-1905（顶栏一行；右侧两个动作位 = 全局搜索 + 消息入口；**中段为空，面切换器已由 ⑫ 移除**；顶栏高度与面的数量无关）、3.5:357
- 类型：功能 | 优先级：P0 | 建议归属 Sprint：S14
- 前置条件：家庭已启用 1 个面与 3 个面两种配置；分别抓包与走查
- 步骤：
  1. 打开首页，记录顶栏结构（左/中/右）
  2. 增开两个面后再次打开，比对顶栏像素级结构
  3. 进入任一面的二级页，检查顶栏是否出现面切换器
- 预期结果：
  - 顶栏左侧 = 家庭切换器；右侧 = 全局搜索 + 消息入口两个动作位；**中段无任何面 chip / 面切换控件**
  - 面数量从 1 变 3，顶栏结构不变（不因新增面改一个像素）
  - 二级页顶栏同样不出现面切换器
- 实现现状（快照）：待自动化（导航结构属 shell 层，需抓包 + 视觉断言；`web/src/pages.json` 现有 12 条路由，无面切换路由）
- 执行状态：未执行

## HOM-NAV-002 · 底部 Tab 恒五项，切面不改 Tab、不清其他面页面栈
- 关联需求：PRD 17.1:1897-1899（底部 Tab 固定五项：首页/动态/＋/消息/我的）、17.1:1913（切换面不改变底部 Tab，也不清空其他面已压入的页面栈）
- 类型：功能 | 优先级：P0 | 建议归属 Sprint：S14
- 前置条件：已启用 ≥2 个面；在面 A 压入二级页
- 步骤：
  1. 记录底部 Tab 项与顺序
  2. 切到面 B，再回面 A 的一级页
  3. 检查面 A 页面栈
- 预期结果：

  - 面 A 的页面栈不被清空（回到面 A 仍落在它的一级页，按 17.1:1913 的会话内保持规则）
  - 「首页」位点一下即回面入口矩阵（唯一切面枢纽）
- 实现现状（快照）：待自动化（需真机/模拟器走查）
- 执行状态：未执行

## HOM-NAV-003 · 面入口唯一：从面内切面恒为 3 步
- 关联需求：PRD 17.1:1902-1903（面入口只有一处 = 首页家庭服务矩阵；面内切面最深路径 = 返回面首页 → D 行「首页」→ 点目标格 = **3 步**）、18.2#9:2074（同批走查断言 ⑫）
- 类型：功能 | 优先级：P1 | 建议归属 Sprint：S14
- 前置条件：已启用 3 个面，停在面 A 的二级页
- 步骤：
  1. 从面 A 二级页尝试切到面 B，记录点击数
  2. 检查面 B 的分包内是否存在任何面入口
- 预期结果：
  - 切面路径恒为 3 步（返回面首页 → 首页 → 点格），**不存在 1 步或 2 步的旁路**
  - 任何面的分包内**不存在第二处面入口**（无面 chip、无面列表、无面切换菜单）
- 实现现状（快照）：待自动化（静态检查 + 走查；分包内控件可用 `grep` 断言无面清单常量）
- 执行状态：未执行

- 关联需求：PRD 17.7:1990（`pages/{code}/{feature}/{action}`；一条路由一个页面一个职责；**不注册原生 tabBar**；一级页无栈替换、二级页压栈返回出栈）
- 类型：功能 | 优先级：P1 | 建议归属 Sprint：S14
- 前置条件：路由清单可读（`web/src/pages.json`）

  2. 检查是否注册了原生 tabBar

## HOM-NAV-005 · 破坏性动作统一走确认弹层，不占路由
- 关联需求：PRD 17.7:1991（删除、撤销、结清、恢复、退出家庭、解散家庭一律走统一破坏性确认弹层：二次确认 + 影响说明 + 需要时填理由 + 落审计；**破坏性动作不占路由**；空态是页面状态而非页面；列表多选是列表页操作态）
- 类型：功能 | 优先级：P1 | 建议归属 Sprint：S14
- 前置条件：可执行六类破坏性动作的家庭
- 步骤：
  1. 逐一对六类动作触发，检查是否弹层而非跳页
  2. 检查弹层是否含二次确认、影响说明、理由输入（需要时）

- 预期结果：

  - 弹层含影响说明；退出/解散需二次确认并落审计

- 前置条件：已部署 Nginx 前缀反代
- 步骤：
