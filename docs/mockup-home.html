HomeCube · 首页效果图 v4 · 米家式卡片语言 + 系统主题 + 顶栏消息红点

从米家借的五点：① 两列大卡，图标在卡内左上、名称与状态句压在下方；② 顶栏用文字 tab + 下划线标当前项，不用胶囊底；③ 今日信息用跨整行大卡 + 横向时间轴小卡；④ 卡片半透明压在主题背景上；⑤ 底部栏当前项加重、消息位带未读。
本轮已定版进文档的三处：⑨ 宫格用固定尺寸卡片自然换行，「C 区占首屏 ≥45%」阈值作废（17.2、导航文档 §12.4）；⑩ 主题三态（跟随系统/亮/暗），一份令牌两套值，分包不得写死色值（17.9、18.2#10）；⑪ 顶栏右侧是两个动作位——搜索 + 消息入口，顶栏只显红点、D 行显红点 + 计数，两处同源于 home/summary.unread、进入消息页同时熄灭（17.1）。
没有借的：不给未启用/未出生的面留任何占位格（17.8 定版）、首页不放「开通更多面」入口、底部仍不是原生 tabBar（门禁 4）。
