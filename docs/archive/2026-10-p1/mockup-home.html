HomeCube · 首页效果图 v5 · 顶栏不放面切换器 + 时间窗三档 + 称谓问候 + 头像排溢出

v4 → v5 改的是四处本轮拍板：⑫ 顶栏移除面切换器——顶栏只剩家庭名与右侧两个动作位（搜索、消息红点），首页 C 区服务矩阵是全 App 唯一能点进别的面地方，代价是面内切面恒定 3 步（返回该面一级页 → D 行「首页」→ 点目标格），红利是面集合的消费者从六处减为五处；⑬ 时间窗三档——月 / 季 / 年 在 P1-M1 全部开放，首页也渲染这条时间窗（period 同时驱动财务格、流水、报表、预算），只有月度预算时季/年档显「未设该周期预算」而不折算；⑭ 问候语带称谓——「早上好，爸爸」的称谓读 homeos.Member.relation，缺值回落成员名，不读未出生的家人面；⑮ 头像排溢出——前 3 个头像 + 虚线圈「+N」，整排点击进成员页，「+N」不是邀请入口。
顺带把全部文字色按 18.2#10 重算了一遍（含角标白字与强调色）：亮态角标底由 #e0361b 调深到 #c92f16（白字 5.4:1），强调橙黄 #a45c07→#995606（压在面色上 4.6:1）。亮态原第三/第四级灰（#8b9099/#a6abb3）对卡片底只有 3.0:1 与 2.3:1，承载 10~11px 的时效标注与相对时间不达标，已统一提到 #666b73（≥4.7:1）；暗态第四级同理提到 #8b95a3。结论是灰阶层数由达标线决定——第四级浅灰只能用于描边与占位图形，不得承载文字。
另外三处按定版口径校正：动态条目左侧改用 registry 面图标（与矩阵同一套，不另建「账/购/长」缩写方块）、C 区标题行右侧只放不可点的纯文案（v4 把「顺序恒为 registry 登记顺序」这类设计注释画进了产品）、顶栏中段留空不是待填位。保留 v4 的米家借法：两列大卡、图标在卡内左上、跨整行今日卡 + 横向时间轴、卡片半透明压在主题背景上、亮暗两态一份令牌。
